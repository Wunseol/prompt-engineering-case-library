## 一、品牌定位

<small style="color:#888">适用场景：新品牌从0到1定位、老品牌重新定位、目标人群细分、差异化价值主张提炼。</small>

<small style="color:#888">提示词：</small>

**你是一位有15年经验的品牌策略总监，擅长从市场空白点切入，为品牌找到独特且可持续的定位。**

**请根据以下信息制定品牌定位策略：**

**品牌名称：{名称}**
**所属行业：{行业}**
**产品/服务：{核心产品描述}**
**价格区间：{定位档次}**
**目标人群初步假设：{画像}**
**主要竞争对手：{1-3个}**
**目前最大障碍：{认知/渠道/产品/资金}**

**请输出完整的品牌定位方案：**

1. **目标人群画像**（3个细分人群，每个含：人口属性、行为特征、核心痛点、消费场景、决策因素）
2. **市场机会分析**（行业趋势、未被满足的需求、竞争空白点）
3. **差异化定位声明**（一句话：为{谁}、解决{什么问题}、提供{什么独特价值}、不同于{谁}）
4. **价值主张**（功能性价值 + 情感性价值 + 社会性价值，三层递进）
5. **品牌原型**（基于12种品牌原型理论：天真者/探险家/智者/英雄/叛逆者/魔法师/凡夫/情人/弄臣/照顾者/创造者/统治者）
6. **品牌金字塔**（顶层：品牌核心价值；中层：品牌个性与利益点；底层：产品属性与事实支撑）
7. **定位验证清单**（5个问题，用于检验定位是否成立）

**约束：**
- 定位必须差异化，避免"高品质、好服务、性价比"等泛泛表述
- 目标人群要具体到可触达，不要"25-35岁都市白领"这种笼统描述
- 价值主张要有支撑点，每个利益点对应一个产品事实
- 品牌原型要和目标人群的心理需求匹配
- 定位要考虑长期可持续性，不只看短期机会

## 二、Slogan 创作

<small style="color:#888">适用场景：品牌主 Slogan、产品线 Slogan、营销活动 Slogan、传播口号等创作。</small>

<small style="color:#888">提示词：</small>

**你是一位顶级文案创意总监，曾服务过多个4A广告公司，擅长用最少的字传递最强的品牌信息。**

**请根据以下信息创作 Slogan：**

**品牌/产品名称：{名称}**
**Slogan 类型：{品牌主Slogan/产品Slogan/活动Slogan/季节限定}**
**品牌定位：{一句话定位}**
**核心卖点：{1-3个}**
**目标人群：{画像}**
**使用场景：{包装/海报/TVC/社交媒体/线下广告}**
**调性要求：{专业/亲切/有趣/酷/温暖}**
**字数限制：{5-12字}**

**请输出10个备选 Slogan，按以下5种策略各2个：**

1. **利益型**（直接说出用户得到什么："怕上火喝王老吉"）
2. **情感型**（触动情感共鸣："Just Do It"）
3. **行动型**（号召行动："让我们 LOHAS"）
4. **场景型**（绑定使用场景："困了累了喝红牛"）
5. **反差型**（制造认知反差："不寻常的寻常"）

**每个 Slogan 附带：**
- 创作思路（为什么这么写）
- 适用的传播场景
- 潜在风险（歧义、文化冲突、负面联想）

**约束：**
- 避免使用"极致、引领、赋能、生态"等空洞词汇
- 避免和知名品牌 Slogan 撞车
- 朗朗上口，念3遍不拗口
- 不能有歧义，避免负面谐音
- 中文 Slogan 避免生僻字和复杂成语
- 国际品牌需提供英文版本并说明文化适配性

## 三、品牌故事

<small style="color:#888">适用场景：品牌创始故事、产品诞生故事、用户使用故事，用于官网、品牌手册、媒体采访等场景。</small>

<small style="color:#888">提示词：</small>

**你是一位品牌叙事专家，擅长把商业事实转化为有情感张力的故事，让品牌从"卖产品"升级为"卖信仰"。**

**请根据以下信息创作品牌故事：**

**品牌名称：{名称}**
**故事类型：{创始故事/产品故事/用户故事/工艺故事/使命故事}**
**品牌定位：{一句话定位}**
**核心事实素材：{提供真实背景信息}**
**目标人群：{画像}**
**使用场景：{官网关于我们/品牌手册/媒体稿件/产品详情页/招商材料}**
**故事目的：{建立信任/引发共鸣/传递价值观/突出工艺}**
**字数要求：{300字/500字/1000字}**

**请按以下结构创作：**

1. **故事开篇**（用一个冲突/悬念/反常识切入，不按时间顺序平铺）
2. **冲突呈现**（描述遇到的问题、困境或质疑）
3. **转折点**（关键的决定、发现或突破）
4. **价值升华**（从产品层面上升到价值观/使命层面）
5. **未来展望**（一句有画面感的愿景收尾）

**附加输出：**
- 一句话版本（30字内，用于社交媒体简介）
- 三句话版本（用于电梯演讲）
- 金句提炼（3句可用于海报/广告的文案）

**约束：**
- 故事必须基于真实素材，不编造虚假情节
- 避免创始人的"天才叙事"，突出团队和用户
- 不用"秉持、始终、致力于"等套话
- 数字要具体（"300次实验"而非"无数次实验"）
- 留有留白，让读者自己感受而非说教
- 适合朗读，节奏感强

## 四、VI 系统

<small style="color:#888">适用场景：Logo 设计描述、品牌色彩系统、字体规范、VI 应用规范制定，配合 Midjourney 等 AI 绘图工具使用。</small>

<small style="color:#888">提示词：</small>

**你是一位品牌视觉设计总监，擅长把品牌策略转化为可视化的视觉系统，熟悉 Midjourney、Stable Diffusion 等 AI 绘图工具的 Prompt 写法。**

**请根据以下信息设计 VI 系统方案：**

**品牌名称：{名称}**
**品牌定位：{一句话定位}**
**品牌个性关键词：{3-5个形容词}**
**行业：{行业}**
**目标人群：{画像}**
**参考品牌风格：{喜欢/讨厌的品牌各2个}**
**应用场景：{线上/线下/包装/空间}**

**请输出完整的 VI 系统方案：**

1. **Logo 设计描述**
   - 标志类型（字标/图标/组合）
   - 设计概念（3个方向，每个含设计思路和视觉元素说明）
   - Midjourney Prompt（英文，可直接用于生成 Logo 概念图）
   - 颜色建议（主色+辅助色 HEX 值）
   - 不适用场景说明

2. **品牌色彩系统**
   - 主色（1个，含 HEX、RGB、CMYK、PANTONE 值及色彩心理含义）
   - 辅助色（2-3个）
   - 中性色（黑灰白阶）
   - 色彩使用比例（70/20/10 原则）
   - 色彩禁忌（哪些颜色组合要避免）

3. **字体系统**
   - 中文字体（标题+正文，含商用授权说明）
   - 英文字体（标题+正文）
   - 字号层级规范（H1-H4、正文、注释）
   - 字重和行距建议

4. **VI 应用规范**
   - 名片设计要点
   - 信封/信纸规范
   - 包装设计原则
   - 社交媒体头像/封面尺寸
   - 线下空间视觉建议
   - 错误使用示例（至少5个 Don't）

**约束：**
- 颜色选择要符合行业属性和品牌个性
- 字体必须可商用，标注授权方式
- Midjourney Prompt 要详细具体，含风格参考
- VI 应用要考虑成本，避免过度设计
- 方案要可执行，落地性强

## 五、品牌升级

<small style="color:#888">适用场景：老品牌焕新、品牌定位调整、Logo 升级、过渡期传播方案设计。</small>

<small style="color:#888">提示词：</small>

**你是一位品牌升级顾问，擅长在不流失老用户的前提下完成品牌年轻化或高端化转型。**

**请根据以下信息制定品牌升级方案：**

**品牌名称：{名称}**
**当前品牌状态：{创立年限、目前定位、市场表现}**
**升级原因：{用户老化/竞争加剧/品类升级/战略转型}**
**升级目标：{年轻化/高端化/国际化/数字化}**
**核心保留：{不能丢的资产，如Logo元素、Slogan、色彩}**
**风险容忍度：{激进/稳健/保守}**
**预算级别：{百万/千万/亿级}**

**请输出完整的品牌升级方案：**

1. **升级诊断**
   - 当前品牌资产盘点（哪些可保留、哪些需淘汰）
   - 用户认知调研要点（如何评估用户对升级的接受度）
   - 风险预警（最可能出问题的3个点）

2. **升级策略**
   - 升级路径选择（渐进式/突变式/双品牌过渡）
   - 升级维度（视觉/定位/产品/沟通 哪些需要变）
   - 升级节奏（3阶段时间表）

3. **过渡方案**
   - 老包装/老物料的消化计划
   - 新旧并存期的视觉处理
   - 经销商/合作伙伴的同步方案
   - 老用户的安抚和告知策略

4. **传播方案**
   - 升级发布会的核心叙事
   - 分阶段传播节奏（预热/发布/延续）
   - 多渠道传播内容（PR稿件/社交媒体/线下广告/KOL）
   - 升级声明文案（200字内）

5. **效果评估**
   - 升级成功的5个量化指标
   - 用户反馈监测机制
   - 应急预案（如果升级翻车怎么办）

**约束：**
- 升级要尊重品牌历史，不否定过去
- 过渡方案要考虑库存和供应链实际
- 传播话术要让老用户感到"被尊重"而非"被抛弃"
- 升级要可量化评估，避免"感觉更好了"这种模糊判断
- 预算分配要务实，避免在视觉上投入过大而忽视产品

## 六、竞品分析

<small style="color:#888">适用场景：品牌定位对比、优劣势分析、差异化机会挖掘、竞争策略制定。</small>

<small style="color:#888">提示词：</small>

**你是一位品牌战略研究员，擅长用结构化方法拆解竞品品牌策略，找出差异化机会。**

**请根据以下信息进行竞品分析：**

**我方品牌：{名称和定位}**
**分析对象：{3-5个竞品品牌}**
**分析目的：{重新定位/产品迭代/营销策略/进入新市场}**
**分析维度偏好：{定位/视觉/传播/产品/渠道}**
**数据来源：{自有调研/公开报告/社交媒体/行业访谈}**

**请输出：**

1. **竞品定位对比矩阵**

| 维度 | 我方 | 竞品A | 竞品B | 竞品C |
|------|------|-------|-------|-------|
| 品牌定位 | | | | |
| 目标人群 | | | | |
| 价格区间 | | | | |
| 核心卖点 | | | | |
| 品牌个性 | | | | |
| 视觉风格 | | | | |
| 主要渠道 | | | | |
| 传播策略 | | | | |
| Slogan | | | | |

2. **优劣势分析**
   - 每个竞品的3个核心优势
   - 每个竞品的3个明显短板
   - 我方相对各竞品的优劣势

3. **差异化机会**
   - 5个潜在差异化方向
   - 每个方向的可行性评估（高/中/低）
   - 每个方向的防御难度（高/中/低）
   - 推荐优先级排序

4. **竞品最佳实践**
   - 值得借鉴的3个策略
   - 借鉴时如何避免同质化

5. **竞品弱点攻击点**
   - 可攻击的3个弱点
   - 攻击的话术建议
   - 攻击的风险评估

6. **战略建议**
   - 短期（3个月）：1-2个可立即执行的动作
   - 中期（6-12个月）：1-2个体系建设动作
   - 长期（1-3年）：品牌护城河构建方向

**约束：**
- 分析基于事实和数据，推测部分要标注
- 避免主观评价（如"品味更好"），用客观标准
- 差异化机会要考虑资源和能力匹配
- 战略建议要可执行，不要"加强品牌建设"这种空话
- 区分"事实"和"推测"，标注信息来源

## 使用技巧

| 技巧 | 说明 |
|------|------|
| 提供品牌资产清单 | 升级时明确列出可保留和必须淘汰的资产，避免误伤 |
| 用对标品牌说话 | "参考Apple的极简、避免小米的年轻化"比抽象描述更准 |
| 分阶段生成 | 先要定位声明→确认后再要 Slogan→最后要故事，层层递进 |
| AI 配合 Midjourney | 用 AI 生成 Logo 描述 Prompt，再喂给 Midjourney 出图 |
| 设定品牌边界 | 明确告诉 AI"不能做什么"，如"不能背叛高端定位" |
| 多版本对比 | 让 AI 生成3-5版定位/Slogan，团队投票决策 |
| 加入用户洞察 | 把真实用户访谈金句喂给 AI，故事更真实 |

## 常见问题 FAQ

| 问题 | 解答 |
|------|------|
| AI 写的 Slogan 都很雷同怎么办？ | 提供3-5个讨厌的 Slogan 反例，要求 AI 必须避开；并指定不同的创作策略分别生成 |
| 品牌定位总是同质化怎么破？ | 强制要求从"未被满足的需求"切入，并要求列出5个差异化方向而非1个 |
| 品牌故事听起来假怎么办？ | 提供真实素材（时间、地点、人物、数字），并加约束"不编造，只基于事实重组" |
| VI 方案中的 Midjourney Prompt 不够精准？ | 补充参考艺术家/风格关键词，如"in the style of Paul Rand, minimalist, geometric" |
| 品牌升级怕翻车怎么办？ | 用渐进式升级，先在子品牌/小范围测试；加约束要求"过渡方案"和"应急预案" |
| 竞品分析数据不足怎么办？ | 明确标注哪些是事实、哪些是推测；让 AI 列出"需补充调研的数据清单" |
