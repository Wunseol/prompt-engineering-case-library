## 一、品牌定位与策划

### 适用场景
新品牌创建、品牌升级、品牌故事撰写。

### 模板
```
你是一位资深品牌策略师，擅长从0到1打造有差异化的品牌。

请为以下产品/服务制定品牌策略：

产品/服务：{描述}
目标人群：{用户画像}
价格区间：{定位}
竞争对手：{列举1-3个}
核心优势：{与竞品的差异}

请提供：
1. 品牌定位声明（一句话说清"为谁、解决什么、为什么选我们"）
2. 品牌口号（3个备选，5-10字）
3. 品牌故事（150字以内，有情感共鸣）
4. 品牌调性关键词（5个）
5. 品牌视觉方向建议（色彩、风格、字体调性）
6. 品牌声音指南（正式/轻松/专业/亲切等）

约束：
- 定位要有差异化，避免"高品质、好服务"等泛泛而谈
- 口号要朗朗上口、容易记住
- 品牌故事要有冲突和转折
- 调性要和目标人群匹配
```

## 二、广告文案撰写

### 适用场景
社交媒体广告、搜索广告、户外广告、短视频广告脚本。

### 模板一：社交媒体广告
```
你是一位顶级广告文案，擅长写出高转化率的社交媒体广告。

产品：{产品名称}
核心卖点：{1-3个}
目标受众：{用户画像}
投放平台：{微信朋友圈/抖音/小红书/微博}
广告目标：{品牌曝光/点击/转化/加粉}
预算级别：{小预算/中等/大预算}

请撰写3版不同风格的广告文案：

约束：
- 每版包含：Hook（抓住注意力）→ Pain（痛点）→ Solution（解决方案）→ CTA（行动号召）
- 版本1：情感驱动型（讲故事、引发共鸣）
- 版本2：理性说服型（数据、对比、逻辑）
- 版本3：社交货币型（让用户想分享）
- 每版控制在平台字数限制内
- CTA 要具体明确（"立即领取"而非"了解更多"）
```

**真实输入→输出示例**：

输入：`产品：极光智能台灯，卖点：护眼无频闪/自动调光/助眠模式，受众：25-35岁职场白领，平台：小红书，目标：点击`

输出：
```
版本1（情感驱动型）：
每天加班到凌晨，眼睛干到发疼？😭
我以前也是这样，直到换了极光台灯——
它知道什么时候该亮一点，什么时候该暗一点，
就像一个懂你的伴读，默默守护你的每一页。
现在熬夜加班，眼睛再也不抗议了 ✨
👉 戳我领100元专属券

版本2（理性说服型）：
为什么你的台灯越看越累？因为频闪在偷走你的专注力。
极光台灯：无频闪认证 + 国AA级照度 + 自动感光调光
对比测试：普通台灯2小时眼疲劳度↑40% vs 极光台灯↑3%
3种模式：专注/阅读/助眠，一键切换
💰 限时直降100 → 立即抢购

版本3（社交货币型）：
工位改造第三弹！这个台灯让全办公室都来问我链接🤫
最绝的是"助眠模式"——睡前30分钟自动渐暗，像日落一样
帮你自然入睡。同事说："这不是台灯，这是生活方式"🥹
你工位上最值得投资的单品 → 点击get同款
```

### 模板二：短视频广告脚本
```
请撰写一个{时长}秒的短视频广告脚本。

产品：{产品名称}
核心卖点：{主卖点}
目标受众：{画像}
投放平台：{抖音/快手/B站/视频号}
调性：{搞笑/温情/炫酷/知识型}

脚本格式：
| 时间段 | 画面描述 | 台词/字幕 | 音效/配乐 | 备注 |
|--------|---------|----------|----------|------|

要求：
- 0-3秒：强Hook（痛点/反常识/悬念）
- 3-{N-5}秒：产品展示+卖点传递
- 最后5秒：强力CTA+优惠信息
- 台词口语化，节奏快
- 至少2次品牌/产品露出
```

## 三、SEO 与内容营销

### 适用场景
关键词策略、SEO文章撰写、内容日历规划。

### 模板一：关键词策略
```
你是一位 SEO 策略师。

网站/产品：{描述}
行业：{行业}
目标市场：{地域和语言}
当前SEO状态：{新站/有一定基础/成熟站点}

请制定关键词策略：
1. 核心关键词（5个，搜索量大、竞争适中）
2. 长尾关键词（15个，搜索量小但转化率高）
3. 问题型关键词（10个，适合FAQ/博客）
4. 竞品关键词差距分析
5. 关键词优先级排序（考虑搜索量/竞争度/商业价值）

约束：
- 区分信息型/导航型/交易型搜索意图
- 标注每个关键词的预估月搜索量和竞争难度
- 给出3个月内可排名的关键词建议
```

### 模板二：SEO 优化文章
```
你是一位 SEO 内容写手，擅长写出既对搜索引擎友好又对读者有价值的文章。

目标关键词：{主关键词}
辅助关键词：{2-3个相关词}
搜索意图：{信息获取/产品对比/购买决策}
目标字数：{字数}
目标读者：{画像}

请撰写文章：
约束：
- 标题包含主关键词，60字符以内，有吸引力
- 前100字出现主关键词
- 小标题包含关键词（自然嵌入，不堆砌）
- 段落简短（每段不超过3句）
- 包含至少1个列表/表格（搜索引擎喜欢结构化内容）
- 自然内链建议：{相关文章主题}
- Meta Description：155字符以内，包含关键词
- 图片 Alt 文本建议
```

## 四、竞品分析

### 适用场景
系统性分析竞争对手的产品、营销、定位策略。

### 模板
```
你是一位商业分析师，擅长竞品研究。

我方产品：{产品名称和描述}
竞争对手：{列出1-5个竞品}
分析目的：{进入新市场/优化产品/调整定价/营销策略}

请进行竞品分析：

1. 产品对比矩阵
| 维度 | 我方 | 竞品A | 竞品B |
|------|------|-------|-------|
| 定位 | | | |
| 核心功能 | | | |
| 定价 | | | |
| 目标用户 | | | |
| 渠道 | | | |
| 优势 | | | |
| 劣势 | | | |

2. 差异化机会
3. 竞品最佳实践（可借鉴）
4. 竞品弱点（我方可攻击的点）
5. 战略建议

约束：
- 分析基于事实，标注信息来源
- 区分"事实"和"推测"
- 给出可执行的建议，不是泛泛而谈
```

## 五、商业计划与策略

### 适用场景
创业商业计划、市场进入策略、增长策略。

### 模板一：商业计划大纲
```
你是一位创业导师和商业计划书专家。

请帮我构建商业计划书大纲：

项目名称：{名称}
行业：{行业}
阶段：{想法阶段/已有MVP/已有收入}
目标：{融资/内部规划/参赛}

请提供商业计划书完整大纲，每个章节包含：
- 该章节需要回答的核心问题
- 投资人最关注的点
- 常见错误提醒

大纲至少包含：
1. 执行摘要
2. 问题与机会
3. 解决方案与产品
4. 市场规模与趋势
5. 商业模式
6. 竞争分析
7. 运营策略
8. 团队
9. 财务预测
10. 融资需求
```

### 模板二：增长策略
```
你是一位增长黑客专家。

产品：{产品描述}
当前阶段：{冷启动/增长期/成熟期/衰退期}
核心指标：{DAU/收入/留存率}
当前数据：{关键指标现状}
增长目标：{3个月内的具体目标}

请设计增长策略：
1. 北极星指标定义
2. 增长漏斗分析（AARRR每个环节的转化率预估）
3. 3个优先级最高的增长实验
4. 每个实验的：假设 → 方案 → 衡量指标 → 预期效果
5. 风险评估

约束：
- 策略要可执行，不要宏大叙事
- 每个实验控制在1-2周内可验证
- 优先选择低成本高杠杆的策略
- 给出"如果失败"的备选方案
```

## 六、用户调研与洞察

### 适用场景
用户访谈大纲、问卷设计、用户画像构建。

### 模板一：用户访谈大纲
```
你是一位用户研究专家。

请设计用户访谈大纲：

产品/服务：{描述}
调研目的：{验证需求/了解痛点/测试概念/了解使用习惯}
目标用户：{画像}
访谈时长：{30min/60min}

请提供：
1. 开场暖场问题（2-3个，建立信任）
2. 核心问题（8-12个，按主题分组）
3. 追问技巧（何时追问、如何追问）
4. 结束语

约束：
- 问题开放性，避免是非题
- 不引导用户回答（避免"你是否觉得..."）
- 按漏斗结构：宽泛 → 具体 → 深挖
- 每个问题标注要了解的假设
```

### 模板二：用户画像
```
请根据以下信息构建用户画像：

产品：{产品描述}
已知信息：{已有调研数据或假设}
目标：{明确营销策略/指导产品设计/内容创作}

请生成 2-3 个典型用户画像，每个包含：
- 姓名、年龄、职业
- 人口统计信息
- 行为特征
- 痛点与需求
- 购买决策因素
- 信息获取渠道
- 一句引用（代表其核心心态）

约束：
- 画像要具体到像真实的人，不要泛泛
- 每个画像之间有明显差异
- 基于已有数据，推测部分标注"推测"
```

## 七、社交媒体运营

### 适用场景
内容日历、社媒文案、互动策略、危机公关。

### 模板一：内容日历
```
请为以下账号制定{时间范围}的内容日历：

平台：{微信公众号/小红书/抖音/微博}
账号定位：{账号的人设和调性}
目标受众：{画像}
内容支柱：{3-5个核心内容方向}
发布频率：{每天/每周N篇}

请提供内容日历，每天包含：
- 主题方向
- 标题/钩子
- 内容形式（图文/视频/直播/投票）
- CTA（引导行动）
- 最佳发布时间

约束：
- 内容支柱交替出现，保持多样性
- 20%内容为引流/转化，80%为价值输出
- 结合热点和节日
- 标注哪些内容需要提前准备素材
```

### 模板二：危机公关回应
```
你是一位公关专家，擅长处理品牌危机。

品牌：{品牌名称}
危机事件：{事件描述}
当前舆论：{正面/中性/负面}
影响范围：{影响的人群和程度}

请起草危机回应声明：

约束：
- 24小时内回应原则
- 态度：真诚、负责、不推诿
- 结构：承认问题 → 表达关切 → 说明措施 → 承诺改进
- 不使用法律术语和公关套话
- 字数控制在200字以内
- 提供2版：简短版（社交媒体）和详细版（官方声明）
```

## 八、使用技巧

| 技巧 | 说明 |
|------|------|
| 提供竞品案例 | 给 AI 看你喜欢的文案风格，让它模仿 |
| 指定品牌调性 | 用3-5个形容词定义品牌声音（如：专业、温暖、简洁） |
| A/B 测试文案 | 让 AI 生成3版不同风格的文案，做A/B测试 |
| 用数据说话 | 要求文案包含具体数字（"提升30%"而非"大幅提升"） |
| 限制字数 | 社媒文案严格控字，超字数会被截断 |
| 加上 CTA | 每个营销文案结尾必须有明确的行动号召 |

## 九、常见问题 FAQ

| 问题 | 解答 |
|------|------|
| AI 写的文案太"AI味"怎么办？ | 加约束："避免使用'极致''引领''赋能'等套话，使用日常口语" |
| 如何保证品牌一致性？ | 创建品牌声音指南，每次对话都附带或引用 |
| AI 能做定价策略吗？ | 可以提供框架和对比，但具体定价需要结合成本和市场数据 |
| 如何避免同质化？ | 强调差异化卖点，给 AI 提供独特的品牌故事角度 |
| 广告文案需要人工审核吗？ | 必须审核，AI 可能生成不合规的绝对化用语或虚假宣传 |
