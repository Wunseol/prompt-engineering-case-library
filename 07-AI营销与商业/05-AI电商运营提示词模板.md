## 一、商品详情页

<small style="color:#888">适用场景：电商商品标题撰写、卖点提炼、详情页文案、参数表设计，适用于淘宝/天猫、京东、拼多多、抖音小店等平台。</small>

<small style="color:#888">提示词：</small>

**你是一位资深电商详情页文案策划，深耕 {品类} 类目5年以上，擅长把产品卖点转化为用户能感知的购买理由。**

**请根据以下信息创作商品详情页内容：**

**商品名称：{产品名}**
**类目：{类目}**
**核心卖点：{3-5个}**
**目标人群：{画像}**
**价格区间：{售价}**
**竞品价格：{竞品价格区间}**
**平台：{淘宝/天猫/京东/拼多多/抖音}**
**详情页目的：{新客转化/老客复购/提升客单价}**

**请输出：**

1. **商品标题**（3个备选，含核心关键词+卖点+使用场景，符合平台搜索权重）
2. **5个核心卖点提炼**（每个卖点按"FAB法则"：Feature属性 → Advantage优势 → Benefit利益）
3. **详情页文案结构**（按顺序：主图钩子→痛点共鸣→产品介绍→卖点详解→使用场景→信任背书→常见问题→行动号召）
4. **详情页正文**（每个模块的文案，每屏200字内，图文配合）
5. **参数表设计**（关键参数的呈现方式）
6. **主图9宫格文案建议**（每张主图的文案和视觉重点）
7. **评价引导话术**（引导用户晒图和写好评的话术）

**约束：**
- 标题必须含核心搜索词，避免堆砌
- 卖点要具体可感知（"充电5分钟用2小时"而非"超长续航"）
- 痛点共鸣要真实，避免虚构用户场景
- 信任背书要有依据（检测报告/销量数据/明星代言/权威认证）
- 严禁使用绝对化用语（"最好、第一、唯一"等违反广告法的词）
- 详情页文案要有节奏，避免大段文字堆砌

## 二、评价回复

<small style="color:#888">适用场景：好评感谢回复、差评危机处理、中评引导转化，适用于店铺日常运营和口碑管理。</small>

<small style="color:#888">提示词：</small>

**你是一位电商客服主管，擅长用得体的回复维护店铺口碑，既能安抚差评用户，又能让好评用户感受到被重视。**

**请根据以下信息生成评价回复：**

**店铺类型：{旗舰店/专卖店/C店}**
**类目：{品类}**
**评价类型：{好评/中评/差评}**
**评价内容：{用户原始评价}**
**用户购买产品：{产品名}**
**问题症结：{物流慢/质量差/包装破损/客服态度/与描述不符}**
**回复目的：{感谢/解释/安抚/引导追评/避免投诉}**
**品牌调性：{亲切/专业/活泼}**

**请输出3版不同策略的回复：**

**版本1：标准官方版**（适合常规好评和中性评价）
**版本2：情感共鸣版**（适合深度互动，建立用户关系）
**版本3：问题解决版**（适合差评，重点解决问题）

**每版回复包含：**
1. 称呼方式
2. 开场感谢
3. 核心回应（针对评价中的具体内容）
4. 解决方案（针对差评，给出明确补偿方案）
5. 引导动作（关注店铺/追评/联系客服）
6. 落款

**约束：**
- 严禁复制粘贴式回复，每条都针对具体评价内容
- 差评回复必须48小时内，态度诚恳不推诿
- 不在评价区暴露用户隐私信息
- 补偿方案要符合店铺政策，不随意承诺
- 避免使用"亲、宝贝"等过度亲昵词（除非品牌调性允许）
- 差评回复要让其他买家看到店家的诚意和负责

## 三、活动策划

<small style="color:#888">适用场景：大促活动、日常促销、新品上市、裂变活动策划，适用于各类电商平台和私域运营。</small>

<small style="color:#888">提示词：</small>

**你是一位电商活动运营专家，擅长设计高转化、高传播的促销活动，熟悉平台规则和用户心理。**

**请根据以下信息策划活动：**

**店铺/品牌：{名称}**
**活动类型：{大促/日常/新品上市/裂变/会员日}**
**活动节点：{双11/618/年货节/品牌日/无节点}**
**活动周期：{预热几天+正式几天}**
**核心目标：{GMV/拉新/复购/清理库存/品牌曝光}**
**目标GMV：{金额}**
**预算：{金额}**
**主推商品：{1-3个}**
**库存深度：{可售库存}**
**目标人群：{新客/老客/沉睡用户}**

**请输出完整的活动方案：**

1. **活动主题与机制**
   - 活动主题（含主标题+副标题，朗朗上口）
   - 核心玩法（满减/秒杀/赠品/抽奖/拼团，1-3种组合）
   - 优惠力度测算（保证毛利底线）

2. **活动节奏表**

| 阶段 | 时间 | 核心动作 | 流量来源 | 关键指标 |
|------|------|---------|---------|---------|
| 预热期 | | | | |
| 蓄水期 | | | | |
| 爆发期 | | | | |
| 返场期 | | | | |

3. **商品策略**
   - 引流款（1-2个，低价冲销量）
   - 利润款（2-3个，承担利润）
   - 形象款（1个，提升品牌调性）
   - 搭配套餐设计（提升客单价）

4. **流量获取**
   - 站内流量（直通车/引力魔方/万相台预算分配）
   - 站外流量（小红书/抖音/KOL种草）
   - 私域流量（社群/朋友圈/会员短信）

5. **转化优化**
   - 详情页升级要点
   - 客服话术重点
   - 逼单策略（倒计时/限量/赠品截止）

6. **风险预案**
   - 库存不足怎么办
   - 物流爆仓怎么办
   - 竞品临时降价怎么办
   - 差评集中爆发怎么办

**约束：**
- 优惠力度要测算毛利，不能"赔本赚吆喝"
- 活动机制要简单易懂，避免"满减+优惠券+积分"复杂叠加
- 预热期不早于7天，避免提前透支消费力
- 每个动作要有明确负责人和时间节点
- 必须有数据复盘方案，避免"做完就完"

## 四、客服话术

<small style="color:#888">适用场景：售前咨询、售后处理、投诉应对，适用于电商客服团队培训和日常接待。</small>

<small style="color:#888">提示词：</small>

**你是一位电商客服培训师，擅长设计高转化、低投诉的客服话术体系，熟悉 {品类} 的常见问题和用户心理。**

**请根据以下信息设计客服话术：**

**店铺/品牌：{名称}**
**类目：{品类}**
**话术类型：{售前咨询/售后处理/投诉应对/催付/复购引导}**
**核心场景：{列出3-5个常见场景}**
**客服水平：{新手/熟练/专家}**
**响应要求：{30秒内首次响应}**
**转化目标：{询单转化率提升/投诉率降低/复购率提升}**

**请输出：**

1. **开场白话术**（3版：标准版/活泼版/专业版）
2. **核心场景应答话术**（每个场景至少3轮话术）

| 用户问题 | 第一轮回复 | 用户追问 | 第二轮回复 | 备注 |
|---------|----------|---------|----------|------|
| | | | | |

3. **异议处理话术**（针对价格/质量/物流/竞品对比等常见异议）
   - 价格异议："有点贵"
   - 质量异议："怕不好用"
   - 物流异议："什么时候到"
   - 竞品异议："XX家更便宜"

4. **逼单话术**（5种：限时/限量/赠品/倒计时/从众）
5. **售后安抚话术**（针对物流慢/包装破损/质量问题）
6. **投诉升级话术**（用户要求经理/威胁差评/要求退款时）
7. **结束语 + 引导动作**（关注店铺/好评/复购）

**约束：**
- 话术要口语化，避免机械模板感
- 每条回复不超过3句话，便于快速响应
- 不夸大产品功效，避免虚假宣传
- 不诋毁竞品
- 涉及售后政策要准确，不随意承诺
- 投诉场景必须给出明确的解决时限

## 五、直播脚本

<small style="color:#888">适用场景：直播开场、产品讲解、逼单话术、收尾转化，适用于抖音/快手/淘宝直播/视频号直播。</small>

<small style="color:#888">提示词：</small>

**你是一位直播脚本编导，深谙直播间流量节奏和转化逻辑，曾操盘过单场 GMV 破千万的直播间。**

**请根据以下信息创作直播脚本：**

**主播人设：{专业买手/品牌创始人/明星达人/工厂老板}**
**平台：{抖音/快手/淘宝直播/视频号}**
**直播时长：{2小时/4小时/6小时}**
**主推商品：{1-3个核心品}**
**直播间客单价目标：{金额}**
**目标GMV：{金额}**
**核心机制：{限时秒杀/买赠/组合套餐/福袋}**
**用户来源：{自然流量/付费投放/私域/短视频引流}**

**请输出完整的直播脚本：**

1. **开场话术**（前5分钟，吸引停留+人设建立+预告福利）

2. **产品讲解脚本**（每个主推品按以下结构）

| 时间 | 环节 | 主播话术要点 | 助播配合 | 上架动作 | 备注说明 |
|------|------|------------|---------|---------|---------|
| 0-2分钟 | 产品介绍 | | | | |
| 2-5分钟 | 卖点演示 | | | | |
| 5-8分钟 | 价格铺垫 | | | | |
| 8-10分钟 | 逼单转化 | | | | |

3. **逼单话术**（10句，按紧迫程度递增）
4. **互动话术**（每隔5分钟一次，引导评论/点赞/关注）
5. **福袋/抽奖话术**（拉动停留和互动）
6. **收尾话术**（最后10分钟，二次转化+预告下次直播）

**附加输出：**
- 直播间标题（3个备选）
- 直播间封面文案
- 直播预告短视频脚本（30秒）

**约束：**
- 话术要口语化、有节奏感，便于主播即兴发挥
- 每10分钟设置一个"小高潮"（赠品/秒杀/福袋）
- 逼单话术要制造真实紧迫感，不虚假宣传
- 价格不能在直播间外提前透露（避免比价）
- 主播和助播要有配合，避免独角戏
- 涉及优惠必须和后台设置一致

## 六、选品分析

<small style="color:#888">适用场景：市场调研、竞品分析、利润测算，适用于电商选品、品类拓展、爆款打造前期调研。</small>

<small style="color:#888">提示词：</small>

**你是一位电商选品专家，擅长用数据驱动选品决策，避免凭感觉选品的常见陷阱。**

**请根据以下信息进行选品分析：**

**店铺类型：{旗舰店/专卖店/C店}**
**现有类目：{当前经营品类}**
**拟拓展品类：{目标品类}**
**资金规模：{可投入资金}**
**供应链资源：{自有工厂/代工/批发/一件代发}**
**团队能力：{运营/设计/客服/仓储}**
**目标平台：{淘宝/京东/拼多多/抖音}**

**请输出完整的选品分析报告：**

1. **市场调研**
   - 品类市场规模（年GMV、增长率）
   - 季节性趋势（哪些月份是旺季）
   - 价格带分布（销量集中区间）
   - 头部品牌格局（CR5集中度）
   - 新品存活率

2. **竞品分析**（选5个对标竞品）

| 项目 | 金额/比例 |
|------|----------|
| 进货成本 | |
| 平台佣金 | |
| 物流仓储 | |
| 推广费用 | |
| 人工成本 | |
| 退货损耗 | |
| 售价 | |

| 净利率 | |
| ROI 盈亏平衡点 | |

4. **选品决策矩阵**
   - 市场需求度（高/中/低）
   - 竞争激烈度（高/中/低）
   - 利润空间（高/中/低）
   - 供应链难度（高/中/低）

**约束：**
- 数据要标注来源或注明"行业估算"
- 利润测算要保守，不乐观估计
- 必须考虑退货率（服装类目退货率可达30-50%）
- 推广费用不能低估，至少占售价的15-30%
- 给出明确的"做/不做"建议，不要模棱两可

## 使用技巧

| 技巧 | 说明 |
|------|------|
| 提供真实竞品数据 | 把竞品的销量、价格、卖点真实数据喂给 AI，分析更准 |
| 分品类调用 | 不同品类的详情页逻辑不同（美妆重效果、数码重参数），分别用 |
| 设置利润底线 | 明确告诉 AI 毛利率不能低于多少，避免方案亏本 |
| 喂入真实评价 | 把店铺真实差评喂给 AI，让它优化话术和详情页 |
| 结合平台规则 | 不同平台规则不同（淘宝禁绝对化用语、抖音禁引导私下交易），明示 |
| 分阶段生成 | 选品分析先要市场调研→确认后再要利润测算→最后要切入策略 |
| 加入客服录音 | 把真实客服录音转文字喂给 AI，找出话术优化点 |

## 常见问题 FAQ

| 问题 | 解答 |
|------|------|
| AI 写的详情页转化率低怎么办？ | 检查卖点是否"FAB法则"清晰、痛点是否真实、信任背书是否充分；提供真实用户差评让 AI 优化 |
| 客服话术太模板化怎么办？ | 加入真实客服对话案例，要求 AI 学习后生成更口语化的版本 |
| 直播脚本主播念不顺怎么办？ | 加约束"话术口语化、单句不超过20字"，并提供主播风格样本让 AI 模仿 |
| 选品分析的利润测算不准怎么办？ | 提供真实的供应链报价、物流费用、推广成本，并要求 AI 标注哪些是估算 |
| 活动方案同质化怎么办？ | 提供3-5个讨厌的活动案例作为反例，要求 AI 必须避开；并指定"创新机制"维度 |
| 评价回复被指复制粘贴怎么办？ | 要求 AI 针对每条评价的具体内容回复，禁止套用模板话术 |
