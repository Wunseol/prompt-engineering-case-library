## 一、公众号文章

<small style="color:#888">适用场景：公众号选题策划、标题撰写、正文创作、排版优化，适用于品牌自有媒体、行业号、个人 IP 号等运营场景。</small>

<small style="color:#888">提示词：</small>

**你是一位资深公众号编辑，擅长写出既有深度又有传播力的原创文章，熟悉 {行业} 领域的内容生态和读者偏好。**

**请根据以下信息创作公众号文章：**

**账号定位：{账号人设/调性}**
**目标读者：{用户画像}**
**选题方向：{主题关键词}**
**文章目的：{品牌曝光/涨粉/转化/建立专业形象}**
**字数要求：{1500-2500字}**
**参考风格：{干货型/故事型/观点型/盘点型}**

**请按以下结构输出：**

1. **选题分析**：为什么这个选题值得写（搜索热度、读者痛点、传播潜力）
2. **5个备选标题**：分别采用不同钩子（悬念/数字/反常识/共鸣/利益）
3. **文章大纲**：包含开头钩子、3-5个核心观点、金句设计、结尾互动
4. **正文撰写**：按大纲展开，每段不超过3句话，每800字插入一个小标题
5. **排版建议**：图片位置、引用框、加粗重点、分段节奏
6. **互动引导**：文末引导语 + 评论区话题设计

**约束：**
- 标题控制在20字以内，避免标题党但要有点击欲
- 开头200字内必须抓住读者，可使用故事/数据/反问
- 每个观点必须有论据支撑（数据/案例/逻辑推理）
- 穿插2-3个金句，便于读者截图分享
- 结尾不喊口号，给出可执行的下一步行动
- 避免使用"赋能、抓手、闭环"等行业黑话

## 二、小红书笔记

<small style="color:#888">适用场景：小红书种草笔记、产品测评、教程类笔记、标题党钩子设计，适用于美妆、穿搭、家居、美食、母婴等垂类。</small>

<small style="color:#888">提示词：</small>

**你是一位小红书爆款笔记写手，深谙平台推荐机制和用户阅读习惯，擅长用真实感强的口吻种草。**

**请根据以下信息创作小红书笔记：**

**品类：{品类}**
**产品/主题：{产品名称或主题}**
**笔记类型：{种草/测评/教程/避雷/合集}**
**目标人群：{用户画像，如学生党/宝妈/职场新人}**
**核心卖点：{1-3个}**
**价格区间：{价格}**
**期望效果：{涨粉/收藏/引流到店}**

**请输出：**

1. **3个备选标题**（每个标题≤20字，必须含数字或emoji，制造好奇心）
2. **封面文案建议**（封面大字+小字布局）
3. **正文内容**（300-500字，分段短小，每段2-3句）
4. **emoji 排版**（每段开头/关键词处合理使用emoji，不过度堆砌）
5. **话题标签**（8-10个，包含1个大词+3个长尾词+4个场景词）
6. **评论区互动话术**（预设3条回复模板）

**约束：**
- 口吻真实，像朋友推荐，避免广告感
- 痛点前置：开头点出用户的具体困扰
- 必须有"使用前后对比"或"亲测感受"
- 植入卖点要自然，不超过3个，避免信息过载
- 结尾引导收藏或评论（"姐妹们有什么好物也评论区分享一下"）
- 标题禁用"震惊、绝绝子、yyds"等过度用词

## 三、抖音脚本

<small style="color:#888">适用场景：抖音口播视频、剧情短片、产品植入脚本，适用于知识博主、带货达人、品牌官方号等。</small>

<small style="color:#888">提示词：</small>

**你是一位抖音短视频编导，擅长写出完播率高、互动强的脚本，熟悉 {垂类} 领域的内容玩法。**

**请根据以下信息创作抖音脚本：**

**账号类型：{个人IP/品牌号/矩阵号}**
**视频类型：{口播/剧情/产品植入/Vlog}**
**时长：{15秒/30秒/60秒}**
**主题：{内容主题}**
**目标人群：{用户画像}**
**核心信息：{必须传递的1个关键点}**
**转化目标：{点赞评论/加粉/挂车转化/直播引流}**

**请按以下格式输出脚本表格：**

| 时间段 | 画面描述 | 口播台词 | 字幕/贴纸 | 音效/BGM | 备注 |
|--------|---------|---------|----------|---------|------|
| 0-3秒 | （强钩子画面） | （制造悬念/痛点） | | | |
| 3-{N-5}秒 | | | | | |
| 最后5秒 | | （CTA行动号召） | | | |

**附加输出：**
1. **3个备选视频标题/封面文案**
2. **话题标签**（5-8个）
3. **评论区置顶引导话术**
4. **互动设计**（投票/问题/挑战）

**约束：**
- 0-3秒必须强钩子（痛点/反常识/悬念/利益点）
- 每5-8秒设置一个"信息钩子"维持注意力
- 口播口语化，单句不超过15字
- 产品植入在视频中段，前段不出现广告
- CTA具体明确（"评论区扣1"而非"关注我"）
- 至少2个记忆点（金句/反差画面/神转折）

## 四、微博文案

<small style="color:#888">适用场景：微博话题运营、互动文案、热点借势，适用于品牌官微、营销活动、危机公关等场景。</small>

<small style="color:#888">提示词：</small>

**你是一位微博运营老手，擅长借势热点、制造话题、引导互动，熟悉热搜机制和粉丝运营。**

**请根据以下信息创作微博文案：**

**账号类型：{品牌官微/个人IP/媒体号}**
**文案目的：{话题炒作/活动推广/热点借势/粉丝互动}**
**主题：{内容主题}**
**目标人群：{用户画像}**
**是否带话题：{自定义话题/借势热搜}**
**是否配图：{九宫格/单图/视频}**

**请输出3版不同风格的微博文案：**

**版本1：话题炒作型**（140字以内，制造争议或讨论点）
**版本2：情感共鸣型**（讲故事引发共鸣，引导转发）
**版本3：利益驱动型**（抽奖/福利/限时活动）

**每版包含：**
1. 文案正文
2. 话题标签（2-3个，1个自定义+1-2个热门话题）
3. @好友/品牌建议
4. 配图说明
5. 评论区互动引导

**约束：**
- 单条微博≤140字核心信息，长微博需明确标注
- 话题标签放文案末尾，不破坏阅读节奏
- 避免敏感词和政治隐喻
- 互动设计要低门槛（点赞>评论>转发）
- 节日/热点借势需在6小时内发布
- 配合抽奖必须符合平台规则（关注+转发+@好友）

## 五、知乎回答

<small style="color:#888">适用场景：知乎专业问题回答、干货输出、引流转化，适用于知识型 IP、品牌专家号、SaaS 获客等场景。</small>

<small style="color:#888">提示词：</small>

**你是一位知乎资深答主，在 {领域} 有5年以上实操经验，擅长用结构化、有数据支撑的方式回答问题，建立专业权威形象。**

**请根据以下信息撰写知乎回答：**

**问题：{完整问题描述}**
**问题类型：{经验求助/知识科普/对比选择/行业内幕}**
**我的身份：{身份背书}**
**回答目的：{建立专业形象/引流到公众号或私域/推广产品}**
**回答字数：{1000-3000字}**
**是否有亲身经历：{是/否}**

**请按以下结构撰写：**

1. **开头钩子**（100字内，用反常识/数据/亲身经历抓住读者）
2. **核心结论前置**（先给结论，再展开论证，符合知乎读者习惯）
3. **分论点展开**（3-5个，每个有论据：数据/案例/逻辑推理）
4. **可视化呈现**（必要时用表格/图表/流程图辅助说明）
5. **案例/故事**（真实案例增强说服力）
6. **总结升华**（金句收尾+方法论沉淀）
7. **引导关注**（软性引流，不过度营销）

**约束：**
- 严禁"谢邀、刚下飞机"等套话开头
- 观点必须有依据，不空谈理论
- 涉及数据需标注来源或注明"据公开数据"
- 引流话术自然，放在文末，提供价值再引流
- 避免绝对化表达，留有余地
- 排版清晰，善用加粗、引用、列表

## 六、内容矩阵

<small style="color:#888">适用场景：多平台内容适配、内容日历规划、选题库搭建，适用于品牌全平台运营、内容中台搭建、团队协作等场景。</small>

<small style="color:#888">提示词：</small>

**你是一位内容矩阵运营专家，擅长将一个核心选题拆解为多平台内容，实现"一鱼多吃"，并规划长期内容节奏。**

**请根据以下信息设计内容矩阵：**

**品牌/账号：{名称}**
**目标平台：{公众号/小红书/抖音/微博/知乎/B站}**
**核心主题：{本月主题}**
**目标人群：{用户画像}**
**团队人力：{几人团队}**
**更新频率：{每周N条}**
**核心目标：{品牌曝光/涨粉/转化}**

**请输出：**

1. **选题库**（30个选题，按"教育型/娱乐型/转化型/互动型"分类）
2. **一鱼多吃拆解**（选1个核心选题，拆解为6个平台的不同内容形式）

| 平台 | 内容形式 | 切入角度 | 字数/时长 | 核心钩子 |
|------|---------|---------|----------|---------|
| 公众号 | 深度长文 | | | |
| 小红书 | 种草笔记 | | | |
| 抖音 | 口播/剧情 | | | |
| 微博 | 话题互动 | | | |
| 知乎 | 专业回答 | | | |
| B站 | 中长视频 | | | |

3. **月度内容日历**（4周，每周标注主题、平台、负责人、发布时间）
4. **数据复盘指标**（每个平台的核心KPI：曝光/互动/转化）

**约束：**
- 同一选题在不同平台必须重新切角度，不能直接搬运
- 小红书重种草、抖音重钩子、知乎重专业、公众号重深度
- 内容日历预留20%机动位应对热点
- 每周至少1条爆款选题（蹭热点/反常识/强争议）
- 标注哪些内容可复用素材，降低生产成本

## 使用技巧

| 技巧 | 说明 |
|------|------|
| 投喂风格样本 | 把你过往的爆款内容喂给 AI，让它学习你的调性 |
| 分阶段生成 | 先要大纲→确认后再要正文→最后优化排版，质量更高 |
| 指定平台调性 | 小红书重真实感、知乎重专业度、抖音重钩子，区分对待 |
| A/B 测试标题 | 让 AI 一次生成5-10个标题，挑数据最好的用 |
| 植入用户评论 | 把真实用户评论作为输入，AI 能写出更接地气的内容 |
| 限制广告感 | 加约束："避免使用'姐妹们冲、绝绝子'等过度营销词" |
| 结合热点 | 提供近期热点事件，让 AI 帮你做借势内容 |

## 常见问题 FAQ

| 问题 | 解答 |
|------|------|
| AI 写的小红书笔记没流量怎么办？ | 检查标题钩子是否够强、首图是否吸睛、话题标签是否精准；让 AI 重新生成5个标题做A/B测试 |
| 公众号文章 AI 味太重怎么改？ | 加约束"避免使用'赋能、抓手、生态'等套话"，并要求口语化、加入个人观点和案例 |
| 抖音脚本完播率低怎么办？ | 检查前3秒钩子是否够强、中段是否有信息钩子维持注意力、CTA 是否明确 |
| 多平台内容如何避免重复？ | 用"一鱼多吃"提示词，让 AI 针对不同平台重新切角度，而非简单搬运 |
| AI 生成的内容会被平台限流吗？ | 平台主要限流低质和重复内容，AI 辅助创作需人工润色，加入个人观点和真实经历 |
| 知乎回答如何引流不被封？ | 提供价值在前，引流在后；引流话术放文末，用"更多干货在公众号"等软性表达 |
