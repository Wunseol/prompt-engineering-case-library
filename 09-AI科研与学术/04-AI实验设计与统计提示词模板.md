## 一、实验设计

<small style="color:#888">适用场景：选择完全随机、随机区组、析因、重复测量等实验设计类型。</small>

<small style="color:#888">提示词：</small>

**你是一位实验设计专家，精通{学科领域}的实证研究方法。**

**请为以下研究问题设计实验方案：**

**研究问题：{RQ}**
**研究假设：{H1, H2...}**
**自变量：{IV及水平数}**
**因变量：{DV及测量方式}**
**控制变量：{需控制的额外变量}**
**被试来源：{样本描述}**
**实验情境：{实验室/现场/在线}**

**请提供：**
1. 推荐的实验设计类型及选择理由
2. 设计示意图（如 2×3 析因设计的单元格）
3. 样本量估算（基于效应量、α、功效）
4. 随机化方案（完全随机/区组/分层）
5. 实验流程（分步骤，含时间节点）
6. 操纵检验与注意力检验方案
7. 内部效度威胁及应对
8. 外部效度评估

**约束：**
- 设计要匹配研究假设，避免"大炮打蚊子"
- 考虑混淆变量和顺序效应
- 标注伦理审查要点
- 提供备选方案（主方案不可行时）

**输出格式：**
## 设计类型
推荐：{完全随机/随机区组/析因/重复测量/混合设计}
理由：{...}

## 设计示意图
| | B1 | B2 | B3 |
|-----|-----|-----|-----|
| A1 | | | |
| A2 | | | |

## 样本量估算
- 效应量：{d/η²/f}
- α = 0.05，功效 = 0.80
- 每组 N = {...}，总 N = {...}

## 实验流程
| 步骤 | 操作 | 时长 | 注意事项 |
|------|------|------|---------|

## 效度评估
| 效度类型 | 威胁因素 | 应对措施 |
|---------|---------|---------|

## 二、统计方法

<small style="color:#888">适用场景：选择 t 检验、ANOVA、回归、非参数检验等统计方法。</small>

<small style="color:#888">提示词：</small>

**你是一位生物统计学家，请为以下数据分析任务推荐并说明统计方法。**

**研究问题：{RQ}**
**研究假设：{H1}**
**自变量：{类型及水平}**
**因变量：{类型及测量}**
**数据特征：{样本量/分布/方差齐性/独立或相关}**
**使用软件：{SPSS/R/Python/STATA}**

**请提供：**
1. 推荐的统计方法及选择理由
2. 方法的前提假设及检验方法
3. 若前提不满足的替代方案（非参数/稳健方法）
4. 具体操作步骤（含软件代码/菜单路径）
5. 事后比较方法（如适用）
6. 结果报告模板

**约束：**
- 方法选择要匹配数据类型和研究设计
- 明确区分独立样本、配对样本、重复测量
- 前提假设检验（正态性、方差齐性、独立性）
- 多重比较需校正（Bonferroni/FDR）
- 标注软件版本

**输出格式：**
## 方法推荐
| 维度 | 选择 |
|------|------|
| 推荐方法 | {如单因素 ANOVA} |
| 理由 | {...} |
| 前提假设 | {正态性/方差齐性/...} |
| 替代方案 | {Kruskal-Wallis} |

## 前提检验
1. 正态性：Shapiro-Wilk / Q-Q图
2. 方差齐性：Levene 检验
3. {代码或菜单路径}

## 主要分析
### R 代码
```r
{代码}
```

### SPSS 操作
1. 分析→比较均值→单因素 ANOVA
2. {后续步骤}

## 三、假设检验

<small style="color:#888">适用场景：设定原假设与备择假设、理解 p 值与显著性、控制错误率。</small>

<small style="color:#888">提示词：</small>

**你是一位统计推断专家，请帮我规范设定假设并解释检验结果。**

**研究情境：{研究问题与设计}**
**关心的效应：{差异/相关/影响}**
**方向性：{双侧/单侧}**
**显著性水平：{α = 0.05/0.01}**
**统计输出：{粘贴分析结果，含统计量、p值}**

**请提供：**
1. 原假设（H₀）与备择假设（H₁）的规范表述
2. 检验统计量及其分布
3. p 值的正确解释（避免常见误读）
4. 统计显著性的判定与决策
5. 第一类/第二类错误分析
6. 功效分析（如未达显著，是否因功效不足）

**约束：**
- 假设要用总体参数表述（μ、ρ、β）
- p 值解释遵循 ASA 规范，不夸大其含义
- 区分统计显著与实际意义
- 标注多重检验情境下的校正

**输出格式：**
## 假设设定
- H₀：{如 μ₁ = μ₂}
- H₁：{如 μ₁ ≠ μ₂}
- 检验类型：{双侧/单侧}

## 结果解释
| 项目 | 内容 |
|------|------|
| 检验统计量 | t/F/χ² = {值} |
| 自由度 | df = {值} |
| p 值 | p = {值} |
| 决策 | {拒绝/不拒绝 H₀} |

## p 值的正确表述
✅ 正确：在 α=0.05 水平下，{...}提供了反对 H₀ 的证据（p = {值}）。
❌ 错误：p 值表示 H₀ 为真的概率。

## 错误分析
| 错误类型 | 含义 | 本次风险 |
|---------|------|---------|
| 第一类（α） | 拒真 | {值} |
| 第二类（β） | 受伪 | {值}，功效 = {1-β} |

## 四、效应量

<small style="color:#888">适用场景：计算与解释 Cohen's d、η²、Odds Ratio、Relative Risk 等效应量。</small>

<small style="color:#888">提示词：</small>

**你是一位统计方法学专家，请帮我计算并解释效应量。**

**分析类型：{组间比较/组内比较/相关/回归/列联表}**
**统计结果：{粘贴统计量、样本量、均值、标准差等}**
**学科领域：{领域，用于判断效应量基准}**

**请提供：**
1. 适用的效应量指标及选择理由
2. 效应量的计算公式与计算过程
3. 效应量的解释（参照领域基准：小/中/大）
4. 效应量的 95% 置信区间
5. 与 p 值的关系（为何要报告效应量）
6. 不同效应量间的换算（如 d ↔ r ↔ η²）

**约束：**
- 效应量必须配合置信区间报告
- 解释基准需标注来源（Cohen 1988 / Field / 领域特定）
- 区分样本效应量和总体效应量
- 多因素设计需报告偏效应量（partial η²）

**输出格式：**
## 效应量选择
| 分析类型 | 推荐效应量 | 理由 |
|---------|-----------|------|
| {类型} | {如 Cohen's d} | {...} |

## 计算过程
- 公式：d = (M₁ - M₂) / S_pooled
- M₁ = {值}, M₂ = {值}, S_pooled = {值}
- d = {计算结果}

## 解释
| 效应量 | 数值 | 大小 | 95% CI | 领域基准 |
|--------|------|------|--------|---------|
| {d/η²/OR/RR} | {值} | {小/中/大} | [{下限}, {上限}] | {基准来源} |

## 效应量换算
- d = {值} → r ≈ {值}
- d = {值} → η² ≈ {值}

## 报告建议
"效应量为 {小/中/大}（d = {值}, 95% CI [{...}]），表明{实际意义}。"

## 五、结果解读

<small style="color:#888">适用场景：区分统计显著与业务显著、解读置信区间、避免过度推断。</small>

<small style="color:#888">提示词：</small>

**你是一位数据分析与解读专家，请帮我解读以下统计结果。**

**研究背景：{研究问题与实践情境}**
**统计结果：{粘贴完整统计输出，含统计量、p值、效应量、CI}**
**业务/实践语境：{该结果的应用场景}**
**决策需求：{基于结果要做什么决策}**

**请提供：**
1. 统计显著性的客观陈述
2. 效应量的实践意义解读（结合领域基准）
3. 置信区间的解读（区间宽度、是否跨越 0/1）
4. 统计显著 vs 实践显著的辨析
5. 结果的不确定性来源
6. 基于结果的决策建议（含谨慎措辞）

**约束：**
- 不夸大因果结论（区分相关与因果）
- 不忽视不显著结果的含义
- 标注结果的适用范围与外推限制
- 区分探索性分析与验证性分析

**输出格式：**
## 客观陈述
{统计结果的客观描述，不含主观判断}

## 实践意义
| 维度 | 解读 |
|------|------|
| 统计显著 | {是/否, p = {值}} |
| 效应量大小 | {小/中/大} |
| 实践意义 | {低/中/高 — 结合领域} |
| CI 解读 | {区间宽度、是否跨越关键值} |

## 显著性辨析
- 统计显著 ≠ 实践重要：{说明}
- 大样本下小效应：{是否本情况}
- 不显著 ≠ 无效应：{说明}

## 决策建议
基于结果，建议{...}，但需注意{不确定性}。

## 局限与外推
- 适用范围：{...}
- 不宜外推至：{...}

**原始数据：{粘贴实验数据/统计输出}**
**图表需求：{N个图、M个表}**
**课程/期刊要求：{格式规范}**

**请按以下结构撰写实验报告：**
1. 实验目的（1-2句）
2. 实验原理（理论基础，含公式）
3. 实验仪器与材料（型号、规格、参数）
4. 实验步骤（分步骤，可复现）
5. 实验数据与结果（表格+图+文字描述）

## 使用技巧

| 技巧 | 说明 |
|------|------|
| 先设计后收集 | 实验设计先于数据收集，避免"先有数据再找问题" |
| 报告效应量 | 仅报告 p 值不够，必须配合效应量和置信区间 |
| 检验前提假设 | 使用参数检验前必须检验正态性、方差齐性 |
| 区分显著与意义 | 统计显著 ≠ 实践重要，大样本易出现微小效应显著 |
| 多重比较校正 | 多次检验需 Bonferroni/FDR 校正，控制家族错误率 |
| 用 AI 写代码 | 让 AI 生成 R/Python 统计代码，但需核对方法适用性 |
| 让 AI 解释结果 | 粘贴统计输出让 AI 解读，但关键结论需人工判断 |
| 预注册分析 | 验证性分析建议预注册，区分探索性与验证性结果 |

## 常见问题 FAQ

| 问题 | 解答 |
|------|------|
| p 值大于 0.05 说明什么？ | 说明在 H₀ 成立时观察到当前结果及更极端结果的概率较高，不"证明"H₀ 为真，仅证据不足以拒绝 |
| 统计显著但效应量很小怎么办？ | 可能是大样本导致，需评估实践意义，谨慎报告效应量和 CI |
| 参数检验前提不满足怎么办？ | 改用非参数检验（Mann-Whitney/Wilcoxon/Kruskal-Wallis）或数据变换 |
| 重复测量和独立样本怎么选？ | 同一被试多次测量用重复测量；不同被试分组用独立样本；混合设计两者兼有 |
| 如何选择效应量指标？ | 组间比较用 d/η²，相关用 r，回归用 R²/f²，列联表用 OR/RR |
| AI 生成的统计代码可靠吗？ | 大部分可靠，但需核对方法适用性、前提假设和参数设置，重要分析建议交叉验证 |
| 实验报告要不要做误差分析？ | 必须做。需区分系统误差和随机误差，定量估计并提改进措施 |
