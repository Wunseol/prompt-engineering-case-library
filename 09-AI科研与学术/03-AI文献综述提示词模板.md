## 一、文献检索

<small style="color:#888">适用场景：构建检索关键词、选择数据库、设计布尔检索式。</small>

<small style="color:#888">提示词：</small>

**你是一位文献检索专家，精通{学科领域}的系统性文献检索。**

**请为以下研究主题构建检索方案：**

**研究主题：{主题}**
**学科领域：{领域}**
**检索目的：{系统综述/快速综述/选题调研/趋势分析}**
**目标数据库：{Web of Science/PubMed/CNKI/Scopus/Google Scholar}**
**时间范围：{近5年/近10年/不限}**
**语言：{中文/英文/中英文}**

**请提供：**
1. 核心概念拆解（PICO/PEO/SPIDER 框架，如适用）
2. 关键词矩阵（每个概念的同义词、近义词、上下位词、缩写）
3. 布尔检索式（AND/OR/NOT 组合，含通配符和截词符）
4. 各数据库的检索式适配（语法差异说明）
5. 预期检索结果量评估与调整策略
6. 灰色文献和补充检索建议（会议、预印本、学位论文）

**约束：**
- 关键词覆盖中英文（如需）
- 检索式可复制即用
- 标注每个数据库的检索语法差异
- 提供检索结果过多/过少时的调整方向
- 不编造数据库特有的字段标签

**输出格式：**
## 概念拆解
| 概念 | 核心词 | 同义词 | 缩写 | MeSH词 |
|------|--------|--------|------|--------|

## 检索式
### Web of Science
`{检索式}`

### PubMed
`{检索式}`

### CNKI
`{检索式}`

## 检索结果调整
| 情况 | 调整策略 |
|------|---------|
| 结果过多（>1000） | 增加限制条件、缩窄概念 |
| 结果过少（<50） | 扩展同义词、放宽时间 |

## 二、文献筛选

<small style="color:#888">适用场景：制定纳入排除标准、质量评价、按 PRISMA 流程筛选文献。</small>

<small style="color:#888">提示词：</small>

**你是一位系统综述方法学专家，熟悉 PRISMA 2020 规范。**

**请为以下综述设计文献筛选方案：**

**综述类型：{系统综述/Meta分析/范围综述/快速综述}**
**研究问题：{PICO/PEO}**
**检索结果：{初步检索到的文献数量}**

**请提供：**
1. 纳入标准（Inclusion Criteria）
2. 排除标准（Exclusion Criteria）
3. 三阶段筛选流程（标题→摘要→全文，含各阶段预期剔除量）
4. 质量评价工具选择（Cochrane ROB/NOS/CASP/JBI 等）
5. PRISMA 流程图数据（识别→筛选→合格→纳入）
6. 双人筛选与分歧解决机制

**约束：**
- 纳入排除标准要可操作、可量化
- 质量评价工具需匹配研究设计类型
- 标注每个标准的操作要点
- 遵循 PRISMA 2020 报告规范

**输出格式：**
## 纳入与排除标准
| 维度 | 纳入标准 | 排除标准 |
|------|---------|---------|
| 研究设计 | | |
| 研究对象 | | |
| 干预/暴露 | | |
| 结局指标 | | |
| 时间 | | |
| 语言 | | |
| 出版类型 | | |

## 质量评价
| 研究设计 | 推荐工具 | 评价维度 |
|---------|---------|---------|

## PRISMA 流程
```
识别（Identification）：{N} 篇
  → 去重后：{N} 篇
筛选（Screening）：标题/摘要剔除 {N} 篇
  → 进入全文：{N} 篇
合格（Eligibility）：全文剔除 {N} 篇
  → 合格：{N} 篇
纳入（Included）：最终纳入 {N} 篇
```

## 三、文献分析

<small style="color:#888">适用场景：对纳入文献进行主题分析、方法对比、结论提取。</small>

<small style="color:#888">提示词：</small>

**你是一位文献分析专家，请对以下文献进行结构化分析。**

**研究主题：{主题}**
**纳入文献：{粘贴文献清单，含作者、年份、方法、主要结论}**
**分析目的：{主题归纳/方法对比/结论综合/研究空白识别}**

**请提供：**
1. 文献信息提取表（作者、年份、设计、样本、方法、主要结论、质量评分）
2. 主题分析（识别共同主题、分歧主题、 emerging themes）
3. 方法对比（研究设计、测量工具、分析方法的异同）
4. 结论综合（一致结论、矛盾结论及可能原因）
5. 研究空白与未来方向
6. 概念关系图（核心概念间的逻辑关系）

**约束：**
- 分析基于文献原文，不臆断
- 区分作者原话和你的解读
- 标注结论的支撑文献数量和一致性程度
- 矛盾结论需分析可能的原因（样本/方法/情境差异）
- 不编造未提供的文献信息

**输出格式：**
## 文献信息提取表
| 作者(年份) | 设计 | 样本 | 方法 | 主要结论 | 质量评分 |
|-----------|------|------|------|---------|---------|

## 主题分析
### 主题一：{主题名}
- 核心观点：{...}
- 支撑文献：{作者A; 作者B}
- 分歧点：{...}

## 结论综合
| 结论 | 一致性 | 支撑文献 | 备注 |
|------|--------|---------|------|
| | 高/中/低 | | |

## 研究空白
1. {空白1}
2. {空白2}

## 四、综述框架

<small style="color:#888">适用场景：选择综述组织方式（主题式/时间式/方法论式），搭建综述骨架。</small>

<small style="color:#888">提示词：</small>

**你是一位综述写作导师，请为以下综述设计框架。**

**研究主题：{主题}**
**综述类型：{叙述性综述/系统综述/理论综述/范围综述}**
**纳入文献量：{N篇}**
**目标读者：{同行专家/研究生/跨学科}**
**目标期刊：{期刊名}**
**篇幅：{字数}**

**请提供：**
1. 推荐的组织方式（主题式/时间式/方法论式/理论框架式）及理由
2. 综述框架大纲（一级、二级标题）
3. 每个章节的核心论点与支撑文献
4. 章节间的逻辑过渡
5. 综述的核心论题（Thesis Statement）
6. 与已有综述的差异化定位

**约束：**
- 框架要服务于研究问题，非简单罗列
- 主题划分要有明确标准（MECE 原则）
- 每个章节要有明确论点，不是文献堆砌
- 标注每个章节建议字数

**输出格式：**
## 组织方式建议
推荐：{方式} — 理由：{...}

## 综述框架
### 1. 引言（{字数}）
- 核心论点：{...}
- 支撑文献：{...}

### 2. 主体
#### 2.1 {主题一}（{字数}）
- 核心论点：{...}
- 支撑文献：{...}
- 过渡到下节：{...}

#### 2.2 {主题二}（{字数}）
...

### 3. 综合讨论与展望（{字数}）

## 核心论题
{一句话概括综述要论证的核心观点}

## 差异化定位
| 已有综述 | 其局限 | 本文创新 |
|---------|--------|---------|

## 五、综述写作

<small style="color:#888">适用场景：撰写综述引言、主体、结论，进行批判性分析。</small>

<small style="color:#888">提示词：</small>

**你是一位学术写作专家，擅长撰写高质量的文献综述。**

**请撰写综述的{引言/主体某节/结论}部分。**

**综述主题：{主题}**
**核心论题：{Thesis}**
**本节论点：{该节要论证的观点}**
**可用文献：{粘贴相关文献信息}**
**字数：{约X字}**
**引用格式：{APA/MLA/GB-T7714}**

**写作要求：**
1. 综合而非罗列：按观点组织，而非按文献逐篇复述
2. 批判性分析：评价方法严谨性、指出矛盾、分析原因
3. 逻辑过渡：段落间有明确逻辑衔接
4. 证据平衡：呈现多方观点，避免 cherry-picking
5. 学术语言：客观、精确、hedging

**约束：**
- 避免"A研究发现…B研究发现…"的流水账式写法
- 每段有明确主题句和论点
- 引用要标注作者观点与你解读的区别
- 矛盾结论需分析可能原因
- 不编造文献，标注需核实的引用

**输出格式：**
## {章节名}
{综述正文，含规范引用}

## 写作说明
| 段落 | 论点 | 引用文献 | 批判性分析要点 |
|------|------|---------|--------------|

## 待核实
- {需到数据库验证的引用}
- {需补充的文献}

## 使用技巧

| 技巧 | 说明 |
|------|------|
| 先检索后筛选 | 检索式宁宽勿漏，通过筛选逐步聚焦 |
| 双人独立筛选 | 系统综述需两人独立筛选，计算 Kappa 一致性 |
| 善用文献管理工具 | Zotero/EndNote 批量管理，避免手动整理 |
| 综合而非罗列 | 综述按观点组织，而非逐篇文献复述 |
| 区分叙述与系统综述 | 叙述性综述主观性强，系统综述需遵循 PRISMA |
| 标注引用可信度 | AI 可能混淆文献，所有引用必须人工核实 |
| 用 AI 辅助提取信息 | 让 AI 提取文献信息表，但需核对原文 |
| 保留检索轨迹 | 记录检索式、检索时间、结果量，保证可复现 |

## 常见问题 FAQ

| 问题 | 解答 |
|------|------|
| AI 能帮我做系统综述吗？ | 可辅助检索式设计、信息提取、初稿写作，但筛选和质量评价需人工完成 |
| 综述要纳入多少篇文献？ | 视综述类型和领域而定，系统综述通常 20-100 篇，范围综述可达数百篇 |
| 叙述性综述和系统综述区别？ | 系统综述有明确方法学（PRISMA）、可复现；叙述性综述主观性强、方法灵活 |
| AI 提取的文献信息可信吗？ | 需逐条核对原文，AI 可能误读方法、样本或结论 |
| 如何处理矛盾结论的文献？ | 分析原因（样本/方法/情境差异），分类呈现，必要时做亚组分析 |
| Zotero 和 EndNote 选哪个？ | Zotero 免费开源、插件丰富、适合协作；EndNote 机构订阅、稳定、适合大批量 |
| 综述写作如何避免抄袭？ | 用自己的话综合观点，规范引用，避免大段复述原文 |
