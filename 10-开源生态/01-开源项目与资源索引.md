### 5.2 三大协议

| 协议 | 定义 | 说明 |
|------|------|------|
| **MCP** (Model Context Protocol) | Agent ↔ 工具 | 标准化模型与外部工具的交互协议 |
| **A2A** (Agent-to-Agent Protocol) | Agent ↔ Agent | 多 Agent 间通信与协作协议 |
| **Agent Skills** | 教 Agent 如何用好能力 | 标准化 Agent 技能描述与调用 |

### 5.3 Harness 工程（2026 核心概念）

> "2025 年 Agent 可以编码。2026 年行业学到 Agent 不是难点——**线束（Harness）才是**。"

**关键洞察 — 约束坍缩**：Vercel 发现移除 80% 可用工具反而提升了 Agent 性能。

## 七、提示词技术速查

| 技术 | 最佳场景 | Token 成本 | 准确率提升 |
|------|---------|-----------|-----------|
| 零样本 | 简单明确任务 | 低 | 基线 |
| 少样本 | 模式匹配任务 | 中 | +5-10% |
| 链式思维 (CoT) | 多步推理 | 中 | +10-18% |
| 思维树 (ToT) | 规划/谜题 | 最高 | +20-70% |
| 自一致性 | 数学/逻辑 | 高(5-10x) | +12-18% |
| Chain of Draft | 简洁推理 | 低(92%↓) | ≈ CoT |
| ReAct | 需要实时数据 | 中-高 | 视场景 |
| 元提示 | 提示优化 | 中 | 间接 |
| 角色提示 | 领域专业任务 | 低 | +5-15% |
| 提示链 | 复杂多步工作流 | 高 | +10-30% |
| 宪法AI | 安全关键输出 | 高 | 安全导向 |
| 结构化输出 | 代码/数据集成 | 低 | 格式可靠性 |
| 系统提示 | 一致行为 | 低 | 一致性 |
| 否定约束 | 排除特定内容 | 低 | 可控性 |
| 迭代优化 | 写作/方案设计 | 中 | 质量+5-25% |
| 自我审查 | 高风险输出 | 中-高 | 可靠性 |
| 任务分解 | 复杂多步骤 | 高 | +10-30% |

## 八、2025-2026 三大趋势

| 趋势 | 说明 |
|------|------|
| **多 Agent 协调** | 从单一 Agent 到多 Agent 协作，MCP/A2A 协议标准化 |
| **Harness 工程** | 约束即能力，减少工具反而提升性能，"约束坍缩"效应 |
| **Agent 安全** | 供应链攻击、目标漂移、推理坍缩成为核心关注点 |
