## 一、专业领域翻译

### 适用场景
法律、医学、金融、技术等专业领域的精准翻译。

### 模板
```
你是一位专业的{领域}翻译专家，精通{源语言}和{目标语言}。

领域：{法律/医学/金融/技术/其他}
源语言：{语言}
目标语言：{语言}

请将以下内容从{源语言}翻译为{目标语言}。

专业术语表（如有）：
{术语原文} → {术语译文}

翻译规则：
1. 准确传达原文含义，不增译、不漏译
2. 专业术语按术语表翻译，无术语表时使用行业标准译法
3. 术语首次出现时标注原文（如：对冲基金（Hedge Fund））
4. 保持原文的格式结构（标题、列表、表格）
5. 数字、日期、货币单位按目标语言习惯转换
6. 法律/合规文本不得意译，保持严格对应
7. 如遇歧义，保留原文并加译者注 [译者注：...]

原文：
{待翻译内容}
```

## 二、技术文档本地化

### 适用场景
API文档、SDK文档、开发者指南、README等的本地化。

### 模板
```
你是一位技术文档翻译专家，精通软件开发的{源语言}和{目标语言}。

请翻译以下技术文档。

翻译规则：
1. 代码块、变量名、函数名、命令行保持英文不变
2. 技术术语首次出现标注英文原文（如：容器编排（Container Orchestration））
3. Markdown 格式完整保留
4. 链接地址不变，如需本地化则替换为目标语言版本
5. 保留原文中的 Note/Warning/Tip 标记
6. 操作步骤编号保持一致
7. 截图占位符标注（如：[截图：{描述}]）

术语表：
{术语列表}

原文：
{待翻译内容}
```

## 三、游戏/App 本地化

### 适用场景
游戏剧情、UI文本、应用界面、配音脚本的本地化。

### 模板一：游戏剧情本地化
```
你是一位游戏本地化专家，擅长将{源语言}游戏剧情翻译为{目标语言}，同时保持游戏的沉浸感和趣味性。

游戏类型：{RPG/策略/休闲/其他}
目标受众：{年龄层/地区}
角色信息：
- {角色1}：{性格/身份/说话风格}
- {角色2}：{性格/身份/说话风格}

翻译规则：
1. 角色对话要体现个性，不同角色的语气要有区分
2. 文言/古风角色用半文言，现代角色用口语
3. 双关语/梗需要本地化为{目标语言}的对应梗，而非直译
4. 尊称/敬语按{目标语言}的文化习惯调整
5. 战斗喊话要短促有力（6字以内）
6. 剧情关键信息不可遗漏
7. 字数控制：对话不超过原文的120%（避免UI溢出）

原文：
{待翻译对话/剧情文本}
```

### 模板二：UI 文本本地化
```
请翻译以下 App UI 文本。

平台：{iOS/Android/Web}
语言方向：{源语言} → {目标语言}

规则：
1. 按平台惯例翻译（iOS用"轻触"，Android用"点击"）
2. 按钮文字简洁（2-4字优先）
3. 错误信息要友好、具体、有解决建议
4. 保持占位符不变（如 {username}、%d、%@）
5. 标注字符数限制（如中文按钮不超过6字）
6. 同一功能在不同页面的翻译保持一致

文本列表：
| Key | 源文本 | 上下文 |
|-----|--------|--------|
| {key1} | {源文本1} | {所在页面} |
| {key2} | {源文本2} | {所在页面} |

输出格式：
| Key | 译文 | 备注 |
|-----|------|------|
```

## 四、文化适配与创译

> **关键概念**：**翻译（Translation）** 追求忠实原文，**创译（Transcreation）** 追求在目标文化中达到相同效果。营销文案、品牌名、游戏剧情等创意内容应优先创译。

### 适用场景
营销文案的跨文化创作、品牌名称本地化、内容本地化。

### 模板一：创译（Transcreation）
```
你是一位跨文化创意总监，擅长将营销信息从一个文化语境"创译"到另一个文化语境。

原文（{源语言}）：
{原文营销文案}

原文文化背景：
{原文的文化语境、双关、梗、价值观}

目标市场：{目标国家/地区}
目标语言：{语言}
目标受众：{画像}

任务不是直译，而是"创译"——在目标文化中找到等效的表达，传达相同的情感和信息。

请提供：
1. 3个创译版本，风格各异
2. 每个版本说明：
   - 创译思路（如何从原文的意图出发，找到目标文化的等效表达）
   - 文化适配点（替换了哪些文化特定元素）
   - 风险评估（是否有潜在的文化敏感问题）

约束：
- 保持品牌核心信息不变
- 优先选择目标受众有共鸣的表达
- 避免文化禁忌和敏感话题
- 如涉及幽默，确保在目标文化中同样有效
```

**真实示例**——将 Nike "Just Do It" 创译为中文：

输入：原文"Just Do It"，文化背景：美国个人主义+行动导向

输出：
```
版本1：想做就做
- 思路：直译核心精神，保持简洁有力
- 文化适配：中文口语化，适合运动场景
- 风险：偏低，可能缺乏品牌识别度

版本2：放手去做
- 思路：强调突破心理障碍的勇气
- 文化适配：更符合中国人"犹豫不决"时的鼓励语境
- 风险：语气偏轻，缺少力量感

版本3：只管去做
- 思路："只管"传达排除万难的决心
- 文化适配：贴合中文习惯的短句节奏
- 风险：低，最接近原意的中文表达

实际品牌选择：耐克在中国大陆使用了"想做就做"和"只管去做"两个版本，
不同时期和活动交替使用。
```

### 模板二：品牌名称本地化
```
请为以下品牌名提供{目标市场}本地化建议：

品牌原名：{品牌名}
品牌含义：{原名的含义/由来}
行业：{行业}
品牌调性：{关键词}
目标市场：{国家/地区}

评估维度：
1. 发音可行性（目标市场消费者能否正确发音）
2. 文化含义（在目标语言中是否有负面含义）
3. 商标可用性（常见的商标冲突风险）
4. 记忆度（是否容易记住）

方案类型：
- 方案A：保留原名（如可行，说明理由）
- 方案B：音译（谐音，保持发音接近）
- 方案C：意译（翻译含义）
- 方案D：全新命名（结合品牌调性创造新名）

每个方案需评估：发音 | 含义 | 风险 | 推荐度（1-5星）
```

## 五、翻译质量评估

### 适用场景
评估翻译质量、进行翻译对比、发现翻译问题。

### 模板
```
你是一位资深翻译审校专家。

请评估以下翻译质量：

原文（{源语言}）：
{原文}

译文（{目标语言}）：
{译文}

评估维度（每项1-5分）：
1. **准确性**：是否准确传达原文含义？有无漏译、误译、增译？
2. **流畅性**：译文是否自然流畅？有无翻译腔？
3. **术语一致性**：专业术语翻译是否一致？
4. **格式保持**：是否保留了原文的格式和结构？
5. **文化适配**：文化特定内容处理是否恰当？

请输出：
| 维度 | 评分 | 问题说明 |
|------|------|---------|

## 具体问题标注
在译文中用以下标记标注问题：
- ❌ 误译
- ⚠️ 欠佳（不自然但不算错）
- ➕ 漏译
- 🔄 建议修改

## 修改建议
{逐条修改建议}
```

## 六、多语言批量翻译

### 适用场景
需要将同一内容翻译为多种语言。

### 模板
```
请将以下内容翻译为多种语言。

源语言：{语言}
目标语言：{语言1}、{语言2}、{语言3}、{语言4}
内容类型：{UI文本/营销文案/产品描述/其他}

规则：
- 每种语言独立翻译，不要互相影响
- 保持格式一致
- 标注每种语言的文化注意事项

原文：
{原文}

输出格式：
| 语言 | 译文 | 文化备注 |
|------|------|---------|
| {语言1} | {译文} | {备注} |
| {语言2} | {译文} | {备注} |
| ... | ... | ... |
```

## 七、字幕翻译

### 适用场景
视频字幕、影视台词、演讲字幕的翻译。

### 模板
```
你是一位字幕翻译专家。

视频类型：{电影/纪录片/教程/演讲/短视频}
源语言：{语言}
目标语言：{语言}
字幕风格：{正式/口语化/幽默}

翻译规则：
1. 每行字幕不超过{目标语言}的字符限制（中文15字/英文42字符）
2. 对话与画面同步，不要翻译画面已展示的信息
3. 口语化表达，符合说话人的语气和身份
4. 文化梗/俚语本地化为目标语言等效表达
5. 如无法本地化，用括号注释含义
6. 保留时间轴标记

原文（含时间轴）：
{字幕内容}

输出格式：
{时间轴}
{译文}
```

## 八、使用技巧

| 技巧 | 说明 |
|------|------|
| 提供术语表 | 翻译前先提供专业术语对照表，一致性提升50%+ |
| 给上下文 | 孤立句子翻译容易出错，提供前后文和场景描述 |
| 指定风格 | 同一内容可要求"正式版"和"口语版"两种风格 |
| 术语首次标注 | 首次出现标注原文，后续统一使用译文 |
| 分段翻译 | 长文档分段翻译，每段附带前文摘要确保连贯 |
| 人工审校 | AI 翻译必须人工审校，尤其是法律/医疗等高风险领域 |

## 九、常见问题 FAQ

| 问题 | 解答 |
|------|------|
| AI 翻译 vs 人工翻译？ | AI 翻译效率高，但创意/文化适配内容仍需人工介入 |
| 如何处理术语不一致？ | 建立术语表，每次翻译都引用；使用少样本提示给2-3个示例 |
| 翻译腔怎么消除？ | 加约束"使用自然的{目标语言}表达，避免翻译腔" |
| 诗歌/歌词能翻译吗？ | AI 可提供意译版，但韵律和音美需要人工再创作 |
| 如何保护隐私？ | 敏感文档使用本地部署模型，或用脱敏数据替代 |
| 多语言项目如何管理一致性？ | 建立多语言术语表，指定一种语言为基准语言 |
