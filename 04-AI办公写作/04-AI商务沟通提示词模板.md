## 一、商务邮件

<small style="color:#888">适用场景：正式商务邮件、项目跟进邮件、致歉邮件、邀请邮件等各类商务邮件撰写。</small>

<small style="color:#888">提示词（正式商务邮件）：</small>

**你是一位资深商务沟通专家，深谙职场邮件礼仪与商务写作规范，擅长撰写专业、得体、高效的商务邮件。**

**请根据以下信息撰写一封正式商务邮件。**

**Role: 资深商务沟通专家，精通跨企业邮件礼仪。**

**发件人身份：**{你的身份与公司}
**收件人身份：**{收件人身份与公司}
**邮件目的：**{邮件要达成的目的}
**关键信息：**{需要传达的核心内容}

**约束：**
- 主题行简洁明确，体现邮件目的，控制在 15 字以内
- 称呼得体，根据关系亲疏选择"姓+职务"或"名"
- 开门见山，首段即说明邮件目的
- 正文分段清晰，每段一个主题
- 如有请求，明确截止日期和期望动作
- 语气专业但不冷漠，避免生硬命令式
- 结尾包含明确的下一步行动
- 控制在 250 字以内

**输出格式：**
```
主题：{{邮件主题}}

{{收件人称呼}}：

{{开头：说明邮件目的}}

{{正文：核心内容，分段展开}}

{{结尾：下一步行动与期待}}

{{发件人署名}}
```

**补充背景：**{如有特殊背景请补充}

<small style="color:#888">提示词（跟进邮件）：</small>

**你是一位商务沟通专家，擅长撰写礼貌但有力度的跟进邮件，既推动事项进展又不显得催促。**

**请根据以下信息撰写一封跟进邮件。**

**Role: 商务沟通专家，擅长推动跨企业协作事项。**

**跟进事项：**{之前沟通的事项}
**上次沟通时间：**{日期}
**当前状态：**{事项进展}
**期望对方动作：**{希望对方做什么}

**约束：**
- 开头提及上次沟通，建立上下文
- 语气友好但明确，避免过度道歉式表达
- 提供对方可能需要的协助，降低对方回复门槛
- 给出明确的回复期限（如"本周五前"）
- 不使用"打扰了""冒昧"等过度谦辞
- 控制在 200 字以内

**输出格式：**
```
主题：跟进：{{事项名称}}

{{收件人称呼}}：

{{提及上次沟通}}

{{当前进展与期望动作}}

{{提供协助与回复期限}}

{{发件人署名}}
```

<small style="color:#888">提示词（道歉邮件）：</small>

**你是一位危机公关与商务沟通专家，擅长撰写诚恳得体、不推诿的道歉邮件，修复商务关系。**

**请根据以下信息撰写一封道歉邮件。**

**Role: 危机沟通专家，擅长商务关系修复。**

**致歉对象：**{收件人身份}
**致歉事由：**{发生的问题}
**影响范围：**{对对方造成的影响}
**补救措施：**{已采取或承诺的措施}

**约束：**
- 直接承认问题，不找借口、不推卸责任
- 真诚表达歉意，避免"如果给您造成不便"等条件式道歉
- 说明问题原因（简短，不展开辩解）
- 明确补救措施和防止再次发生的方案
- 语气诚恳、专业，不卑不亢
- 控制在 300 字以内

**输出格式：**
```
主题：关于{{致歉事由}}的致歉

{{收件人称呼}}：

{{直接致歉并说明事由}}

{{问题原因简述}}

{{补救措施与改进方案}}

{{再次致歉与诚意表达}}

{{发件人署名}}
```

## 二、会议纪要

<small style="color:#888">适用场景：会议记录整理、行动项跟踪、决议事项梳理，适用于跨部门/跨企业商务会议。</small>

<small style="color:#888">提示词：</small>

**你是一位专业会议纪要撰写专家，擅长从零散的会议记录中提炼关键信息，输出结构清晰、行动项明确的商务会议纪要。**

**请根据以下会议记录，整理一份规范的商务会议纪要。**

**Role: 资深商务会议纪要专家，擅长跨国企业会议记录。**

**会议名称：**{会议名称}
**会议时间：**{日期时间}
**参会方：**{参与的公司/部门}
**会议目的：**{会议要达成的目标}

**会议记录素材：**
{粘贴会议记录/语音转录}

**约束：**
- 区分"讨论内容"与"决议结论"
- 行动项必须包含：任务、负责人、截止日期、交付物
- 决议用"会议确认"标注，待决事项用"待定"标注
- 去除寒暄和重复讨论，保留实质性内容
- 标注分歧点和未达成一致的事项
- 控制在 800 字以内

**输出格式：**
```
{{会议名称}}会议纪要

【会议信息】
- 时间：{{时间}}
- 参会方：{{各方代表}}
- 主持人：{{主持人}}

【会议议题】
1. {{议题1}}
2. {{议题2}}

【讨论要点】
### {{议题1}}
- {{要点1}}
- {{要点2}}
- 决议：{{结论/待定}}

### {{议题2}}
- ...

【行动项跟踪】
| 序号 | 任务 | 负责人 | 截止日期 | 交付物 |
|------|------|--------|----------|--------|
| 1 | {{任务}} | {{负责人}} | {{日期}} | {{交付物}} |

【下次会议】
- 时间：{{时间}}
- 议题：{{议题}}
```

## 三、工作汇报

<small style="color:#888">适用场景：口头汇报、书面汇报、项目进展汇报等向上级或客户的工作汇报场景。</small>

<small style="color:#888">提示词（书面工作汇报）：</small>

**你是一位资深职场沟通顾问，擅长将复杂工作进展提炼为清晰、聚焦结果的工作汇报，帮助汇报者高效传递信息。**

**请根据以下素材，撰写一份工作汇报。**

**Role: 资深职场沟通顾问，精通向上汇报技巧。**

**汇报对象：**{上级/客户}
**汇报周期：**{时间范围}
**汇报形式：**{书面/口头}

**工作素材：**
{粘贴工作记录、数据、进展等}

**约束：**
- 采用"结论先行"结构：核心结论→关键进展→风险问题→所需支持
- 数据优先，用具体数字说明进展
- 风险问题附带自己的解决方案，而非只抛问题
- 所需支持具体明确，便于上级决策
- 避免流水账式罗列，提炼关键信息
- 控制在 500 字以内

**输出格式：**
```
{{汇报标题}}

一、核心结论
{{1-2句话概括整体进展}}

二、关键进展
1. {{进展1}}：{{量化成果}}
2. {{进展2}}：{{量化成果}}
3. {{进展3}}：{{量化成果}}

三、风险与应对
| 风险 | 影响 | 应对方案 | 是否需支持 |
|------|------|----------|-----------|
| {{风险}} | {{影响}} | {{方案}} | {{是/否}} |

四、所需支持
- {{支持项1}}
- {{支持项2}}

五、下阶段计划
- {{计划1}}
- {{计划2}}
```

**你是一位高管汇报教练，擅长将书面内容转化为自然流畅的口头汇报话术，帮助汇报者在有限时间内高效传达信息。**

**请根据以下内容，准备一份口头汇报话术。**

**Role: 高管汇报教练，精通口头表达与节奏控制。**

**汇报场合：**{例会/评审/一对一向上级汇报}
**汇报时长：**{时长，如 5 分钟}
**汇报内容：**{核心要点}

**约束：**
- 开场用一句话点明汇报核心结论
- 使用口语化表达，避免书面语
- 关键数据加重语气，便于听众记忆
- 预设 2-3 个可能被追问的问题及应答
- 结尾明确"下一步"和"需要决策的事项"
- 标注停顿和强调位置

**输出格式：**
```
【开场】
"{{一句话结论}}。"

【核心内容】
"{{展开说明，口语化}}……"

【数据强调】（加重语气）
"这里有一个关键数据：{{数据}}。"

【结尾】
"{{下一步与决策事项}}。"

【预设问答】
Q1：{{可能问题}}
A1：{{应答}}

Q2：{{可能问题}}
A2：{{应答}}
```

## 四、商务谈判

<small style="color:#888">适用场景：商务谈判策略制定、谈判话术准备、让步方案设计等谈判前准备与现场应对。</small>

<small style="color:#888">提示词：</small>

**你是一位资深商务谈判顾问，拥有丰富的跨行业谈判经验，深谙博弈策略与双赢谈判技巧，擅长帮助谈判者制定策略和准备话术。**

**请根据以下信息，制定谈判策略并准备话术。**

**Role: 资深商务谈判顾问，精通 BATNA 与利益拆解分析。**

**谈判事项：**{谈判主题，如价格/合作条款}
**我方立场：**{我方诉求与底线}
**对方立场：**{已知对方诉求}
**我方筹码：**{可交换的资源/优势}
**谈判期限：**{时间压力}

**约束：**
- 区分"立场"与"利益"，挖掘双方底层利益
- 制定 BATNA（最佳替代方案）和底线
- 设计 3 套方案：理想方案、折中方案、底线方案
- 话术包含开场、试探、推进、收尾四阶段
- 预判对方可能的 3 种策略及应对
- 让步遵循"小步慢让"原则，每次让步都换取对价
- 语气专业、不卑不亢，避免对抗性表达

**输出格式：**
```
## 谈判形势分析
**我方利益：**{{核心利益}}
**对方利益：**{{推测的对方利益}}
**双方交集：**{{可达成共识的区域}}
**我方 BATNA：**{{最佳替代方案}}
**底线：**{{不可让步的底线}}

## 三套方案
| 方案 | 我方条件 | 让出项 | 换取项 |
|------|----------|--------|--------|
| 理想方案 | {{条件}} | {{让出}} | {{换取}} |
| 折中方案 | {{条件}} | {{让出}} | {{换取}} |
| 底线方案 | {{条件}} | {{让出}} | {{换取}} |

## 四阶段话术
### 开场（建立基调）
"{{话术}}"

### 试探（探明对方底线）
"{{话术}}"

### 推进（交换与让步）
"{{话术}}"

### 收尾（确认与锁定）
"{{话术}}"

## 对方策略应对
| 对方可能策略 | 我方应对 | 参考话术 |
|-------------|----------|----------|
| {{策略1}} | {{应对}} | "{{话术}}" |
| {{策略2}} | {{应对}} | "{{话术}}" |

## 让步路线图
1. 第一步让步：{{让出什么，换取什么}}
2. 第二步让步：{{让出什么，换取什么}}
3. 底线前止步：{{止损信号}}
```

## 五、客户沟通

<small style="color:#888">适用场景：客户回访、投诉处理、需求确认等客户触达与关系维护场景。</small>

<small style="color:#888">提示词（客户投诉处理）：</small>

**你是一位资深客户成功与客诉处理专家，擅长在投诉场景中安抚客户情绪、快速定位问题、给出令客户满意的解决方案。**

**请根据以下信息，制定客户投诉应对方案与沟通话术。**

**Role: 资深客户成功专家，精通投诉转化与关系修复。**

**客户类型：**{客户级别与特征}
**投诉问题：**{客户投诉的具体问题}
**客户情绪：**{愤怒/失望/焦虑}
**问题原因：**{已知原因}
**可提供的方案：**{可补救的措施}

**约束：**
- 首先共情情绪，再处理问题（先情绪后事情）
- 不辩解、不推责，承认问题客观存在
- 给出明确的解决时间线和负责人
- 方案要超出客户最低预期（适当补偿）
- 话术分"安抚→调查→解决→回访"四步
- 语气诚恳、专业，避免模板化套话
- 标注话术中需要根据客户反应灵活调整的部分

**输出格式：**
```
## 投诉分级
**严重程度：**{{高/中/低}}
**影响范围：**{{影响评估}}
**升级条件：**{{何时需升级处理}}

## 四步处理话术
### 第一步：情绪安抚
"{{共情+致歉话术}}"

### 第二步：问题调查
"{{了解细节话术}}"

### 第三步：解决方案
"{{方案说明话术}}"

### 第四步：主动回访
"{{回访话术}}"

## 补偿方案
- 方案 A（推荐）：{{方案与话术}}
- 方案 B（备选）：{{方案与话术}}

## 后续改进
- {{改进措施1}}
- {{改进措施2}}
```

## 使用技巧

| 技巧 | 说明 |

| 明确沟通对象 | 提示词中交代收件人/汇报对象的身份和关系，AI 才能调整语气和措辞 |

## 常见问题 FAQ

| 问题 | 解答 |
|------|------|
| 商务邮件主题怎么写更好？ | 简洁明确，体现目的，可用"[行动]+事项"格式，如"请确认：Q3 合作方案" |
| 跟进邮件多久发一次合适？ | 一般上次沟通后 3-5 个工作日跟进，避免频繁催促造成反感 |
| 道歉邮件要避免什么？ | 避免条件式道歉（"如果给您造成不便"）、避免推责、避免过度解释 |
| 会议纪要行动项没人执行怎么办？ | 纪要发出后主动跟踪，设立截止日期前 1 天的提醒机制，必要时升级 |
| 向上级汇报被说"抓不住重点"怎么办？ | 采用结论先行结构，先说核心结论再展开支撑，控制篇幅在 1 页内 |
| 谈判中对方一直压价怎么办？ | 不在价格上纠缠，转向价值拆解，用条件交换代替单向让步 |
| 处理客诉时客户情绪激动怎么办？ | 先共情安抚情绪，不打断、不辩解，等客户情绪平复再谈解决方案 |
| 跨文化沟通最容易踩什么坑？ | 高语境文化（如日本）需读懂言外之意，低语境文化（如美国）需直接表达，混用易生误解 |
