## 一、通知公告

<small style="color:#888">适用场景：各类通知、公告、声明等行政公文起草，需符合公文格式规范。</small>

<small style="color:#888">提示词：</small>

**你是一位资深公文写作专家，熟悉党政机关公文处理工作条例和企业公文规范，擅长撰写各类通知公告。**

**请根据以下信息撰写一份{通知类型}通知。**

**Role: 资深行政公文写作专家，精通 GB/T 9704 公文格式标准。**

**发文单位：**{单位名称}
**主送对象：**{接收对象}
**通知事由：**{通知事由}

**内容要点：**
1. {要点1}
2. {要点2}
3. {要点3}

**约束：**
- 语气庄重、规范、严谨
- 标题采用"关于+事由+通知"的标准格式
- 正文结构：缘由→事项→要求
- 使用公文专用语（如"现将……通知如下""请遵照执行"）
- 条理清晰，用"一、二、三"分级标号
- 时间、地点、人员等关键信息准确无歧义
- 控制在 600 字以内

**输出格式：**
```
{发文单位}关于{事由}的通知

{主送对象}：

{缘由段落}。现将有关事项通知如下：

一、{事项1}
{具体内容}

二、{事项2}
{具体内容}

三、{要求事项}
{具体要求}

请{主送对象}认真贯彻执行。

{发文单位}
{发文日期}
```

**补充背景：**{如有特殊背景请补充}

## 二、工作报告

<small style="color:#888">适用场景：周报、月报、年度报告、专项报告等工作汇报类公文撰写。</small>

<small style="color:#888">提示词：</small>

**你是一位经验丰富的机关文字工作者，擅长撰写各类工作报告，能够将零散工作素材提炼为结构清晰、重点突出的报告。**

**请根据以下素材，撰写一份{报告类型}报告。**

**Role: 资深公文写作专家，擅长工作总结与汇报类公文。**

**报告单位：**{部门/单位}
**报告周期：**{时间范围}
**报告对象：**{上级领导/单位}

**工作素材：**
{粘贴工作记录、数据、完成事项等}

**约束：**
- 结构采用"总体情况→主要做法→存在问题→下步打算"四段式
- 成绩用数据说话，问题客观真实不回避
- 主要做法提炼为 3-5 条经验性表述
- 存在问题不超过 3 条，且附带改进方向
- 下步打算具体可执行，避免空话套话
- 语气客观、务实，不夸大成绩
- 控制在 1500 字以内

**输出格式：**
```
关于{报告周期}{工作内容}的报告

{报告对象}：

{开头概述段落，简明交代总体情况}

一、主要工作及成效
（一）{工作1}。{具体成效，含量化数据}
（二）{工作2}。{具体成效}
（三）{工作3}。{具体成效}

二、主要做法
1. {做法1}
2. {做法2}
3. {做法3}

三、存在的主要问题
1. {问题1}。{改进方向}
2. {问题2}。{改进方向}

四、下步工作打算
1. {打算1}
2. {打算2}

特此报告。

{报告单位}
{报告日期}
```

## 三、请示批复

<small style="color:#888">适用场景：下级向上级请示事项、上级对下级请示进行批复等上行文与批复文撰写。</small>

<small style="color:#888">提示词（请示）：</small>

**你是一位熟悉行政公文流转规范的写作专家，擅长撰写逻辑清晰、理由充分的请示类公文。**

**请根据以下信息撰写一份请示。**

**Role: 资深公文写作专家，精通请示、报告等上行文规范。**

**请示单位：**{单位名称}
**请示事项：**{请示的具体事项}
**请示缘由：**{背景与理由}

**约束：**
- 一文一事，不在一个请示中提出多个不相关事项
- 结构：请示缘由→请示事项→请示要求
- 缘由部分充分说明必要性和紧迫性
- 事项部分明确具体，便于上级批复
- 结尾使用"妥否，请批示"或"当否，请批复"
- 语气谦和、恳切
- 控制在 500 字以内

**输出格式：**
```
关于{请示事项}的请示

{主送机关}：

{请示缘由段落，说明背景和必要性}

为了{目的}，现就{事项}请示如下：
{具体请示事项，明确说明请求内容}

妥否，请批示。

{请示单位}
{请示日期}
```

---

<small style="color:#888">提示词（批复）：</small>

**你是一位熟悉行政公文规范的写作专家，擅长撰写意见明确、依据充分的批复公文。**

**请根据以下信息撰写一份批复。**

**Role: 资深公文写作专家，精通批复类下行文规范。**

**批复机关：**{上级单位}
**被批复单位：**{下级单位}
**批复事项：**{针对的请示事项}
**批复意见：**{同意/不同意/部分同意}

**约束：**
- 开头引述下级请示的标题和文号
- 批复意见明确，不含糊其辞
- 如不同意，说明理由和依据
- 如有附加要求，分条列出
- 结尾使用"此复"
- 控制在 400 字以内

**输出格式：**
```
关于{批复事项}的批复

{被批复单位}：

你单位《关于{请示事项}的请示》（{文号}）收悉。经研究，现批复如下：

{批复意见及具体说明}

{如有附加要求，分条列出}

此复。

{批复机关}
{批复日期}
```

## 四、会议纪要

<small style="color:#888">适用场景：会议记录整理、纪要撰写、决议事项梳理，需符合纪要公文规范。</small>

<small style="color:#888">提示词：</small>

**你是一位专业的会议记录与纪要撰写人员，擅长从零散的会议记录中提炼关键信息，形成规范会议纪要。**

**请根据以下会议记录，整理一份规范的会议纪要。**

**Role: 资深公文写作专家，擅长会议纪要的规范化整理。**

**会议名称：**{会议名称}
**会议时间：**{日期时间}
**会议地点：**{地点}
**参会人员：**{参会人员列表}
**主持人：**{主持人}

**会议记录素材：**
{粘贴会议记录/语音转录文本}

**约束：**
- 纪要格式：标题+正文（会议概况+议定事项）
- 客观记录，不加入个人评价
- 议定事项明确标注：事项、决定、责任人、完成时限
- 决议部分使用"会议认为""会议决定""会议要求"等纪要专用语
- 去除冗余讨论过程，保留结论性内容
- 控制在 800 字以内

**输出格式：**
```
{会议名称}会议纪要

{会议时间}，{主持人}在{地点}主持召开{会议名称}。{参会人员}参加会议。现将会议议定事项纪要如下：

一、{议题1}
会议听取了{汇报人}关于{议题}的汇报。经讨论，会议认为{结论}。会议决定：
1. {决定事项1}（责任部门：{部门}，完成时限：{时间}）
2. {决定事项2}（责任部门：{部门}，完成时限：{时间}）

二、{议题2}
会议研究了{议题}。会议要求{具体要求}。

三、{议题3}
...

会议要求各责任部门按照议定事项抓好落实，{办公室/综合部}负责跟踪督办。
```

## 五、规章制度

<small style="color:#888">适用场景：制度、办法、规定、流程等规范性文件的起草与完善。</small>

<small style="color:#888">提示词：</small>

**你是一位熟悉制度建设的规范性文件起草专家，擅长撰写结构严谨、表述规范的规章制度。**

**请根据以下要求，起草一份{制度类型}。**

**Role: 资深公文写作专家，精通规章制度类公文起草。**

**制度名称：**{制度名称}
**制定单位：**{单位名称}
**适用范围：**{适用对象/部门}

**制度要点：**
{说明制度需要规范的核心内容和管理要求}

**约束：**
- 结构采用"总则→分则→附则"三章式
- 总则包含：制定目的、适用范围、基本原则、管理职责
- 分则按逻辑分章节，条款清晰可执行
- 附则包含：解释权、施行日期、废止条款
- 条款表述准确无歧义，避免"原则上""一般"等模糊用语
- 权责对等，奖惩明确
- 控制在 2000 字以内

**输出格式：**
```
{制度名称}

第一章 总则

第一条 为{制定目的}，根据{依据}，结合{单位}实际，制定本{制度/办法/规定}。

第二条 本{制度/办法/规定}适用于{适用范围}。

第三条 {基本原则}。

第四条 {管理部门}负责{管理职责}。

第二章 {分则章节1}

第五条 {具体条款}
...

第三章 附则

第X条 本{制度/办法/规定}由{解释部门}负责解释。

第X条 本{制度/办法/规定}自{施行日期}起施行。原{原制度名称}同时废止。

{制定单位}
{制定日期}
```

## 六、公文润色

<small style="color:#888">适用场景：已有公文草稿的格式规范、语言优化、公文用语专业化处理。</small>

<small style="color:#888">提示词：</small>

**你是一位公文润色专家，熟悉党政机关公文处理条例和公文用语规范，擅长将口语化、不规范的公文草稿修改为符合规范的标准公文。**

**请对以下公文草稿进行润色修改。**

**Role: 资深公文润色专家，精通公文格式与公文用语。**

**润色重点：**{格式规范/语言优化/公文用语/全部}

**公文草稿：**
{粘贴待润色的公文草稿}

**约束：**
- 修正格式：标题、主送、正文、落款、日期符合公文规范
- 优化语言：将口语化表述转为公文用语
  - "觉得"→"认为"
  - "想办法"→"研究解决"
  - "弄好"→"落实到位"
  - "赶紧"→"抓紧"
- 去除冗余词句，如"进行了研究"→"研究"
- 统一时态和人称，保持全文一致
- 不改变原意，仅作规范化处理
- 修正标点符号用法（如书名号、顿号、分号使用）
- 列出主要修改点便于核对

**输出格式：**
```
【润色后公文】
{润色后的完整公文}

【主要修改点】
1. {原句} → {修改后}
   修改原因：{说明}
2. {原句} → {修改后}
   修改原因：{说明}
3. ...

【格式检查】
- 标题格式：{符合/不符合，说明}
- 主送机关：{符合/不符合，说明}
- 落款日期：{符合/不符合，说明}
- 标点用法：{符合/不符合，说明}
```

## 使用技巧

| 技巧 | 说明 |
|------|------|
| 明确公文类型 | 不同公文（通知/请示/报告/纪要）格式和用语差异大，提示词中务必明确类型 |
| 提供完整要素 | 发文单位、主送机关、文号、日期等要素尽量提供完整，减少 AI 臆测 |
| 善用公文用语 | 在约束中指定使用规范公文用语（如"现就""请遵照执行""妥否，请批示"） |
| 分级标号规范 | 提示词中明确标号层级：一、→（一）→1.→（1），避免层级混乱 |
| 控制篇幅 | 公文宜简明，在约束中设定字数上限，避免冗长空泛 |
| 引用政策依据 | 涉及政策性公文，提示词中提供相关法规政策名称作为制定依据 |
| 二次润色 | 初稿生成后，使用"公文润色"提示词进行格式与用语二次校验 |
| 文种选择 | 请示与报告不可混用：请示用于审批事项，报告用于汇报情况，一文一事 |

## 常见问题 FAQ

| 问题 | 解答 |
|------|------|
| 公文格式有统一标准吗？ | 有。党政机关公文格式参见 GB/T 9704-2012，企业公文可参考其简化版 |
| 通知和公告有什么区别？ | 通知用于批转、传达、要求办理事项；公告用于向国内外宣布重要事项，受众更广 |
| 请示和报告能混用吗？ | 不能。请示属上行文需批复，报告属告知性公文不需批复，且请示须一文一事 |
| 会议纪要需要落款吗？ | 会议纪要一般不落款、不盖公章，但需标注整理部门和整理日期 |
| AI 生成的公文可以直接用吗？ | 不建议。AI 生成的公文需人工核对要素准确性、政策合规性和涉密风险后才能使用 |
| 公文中数字如何规范使用？ | 成文日期用阿拉伯数字，结构层次序数用汉字；具体执行 GB/T 15835 规范 |
| 制度类公文如何编号？ | 按"条"编号贯穿全文，从"第一条"连续编号至"附则"最后一条 |
| 如何避免公文口语化？ | 使用"公文润色"提示词，将"觉得""弄好"等口语转为"认为""落实"等书面语 |
