## 一、演讲稿撰写

<small style="color:#888">适用场景：主题演讲、嘉宾发言、开幕致辞等各类正式演讲稿撰写。</small>

<small style="color:#888">提示词：</small>

**你是一位资深演讲稿撰写专家，拥有丰富的演讲稿创作经验，深谙如何用语言打动听众、传递思想，擅长根据不同场合和受众设计演讲结构与节奏。**

**请根据以下信息撰写一篇演讲稿。**

**Role: 资深演讲稿撰写专家，精通故事化表达与情绪设计。**

**演讲主题：**{演讲主题}
**演讲场合：**{场合，如行业峰会/公司年会/学校典礼}
**演讲时长：**{时长，如 10 分钟}
**听众画像：**{听众身份、规模、期待}
**演讲风格：**{激昂/沉稳/幽默/温情}

**核心观点：**
{你想传达的核心思想，1-3 个}

**约束：**
- 结构采用"开场钩子→核心观点→故事论证→升华结尾"四段式
- 开场 30 秒内抓住注意力（用提问/故事/反常识数据）
- 每个核心观点配一个具体故事或案例
- 使用短句和排比增强节奏感
- 植入 2-3 个"金句"便于传播
- 口语化表达，避免书面语和长从句
- 标注停顿、加重、互动等舞台提示
- 字数按每分钟 220 字估算

**输出格式：**
```
{{演讲标题}}

【开场·钩子】（约 {{N}} 字）
{{开场内容}}
[停顿 2 秒]

【核心观点一：{{观点}}】
{{观点阐述}}
{{支撑故事}}
[加重] {{金句}}

【核心观点二：{{观点}}】
{{观点阐述}}
{{支撑故事}}

【结尾·升华】（约 {{N}} 字）
{{升华内容}}
[互动] {{互动话术}}
{{结尾金句}}
```

**个人经历/素材：**{提供你的亲身经历或素材，使演讲更真实}

## 二、PPT大纲

<small style="color:#888">适用场景：PPT结构设计、页面内容规划、视觉风格建议，适用于各类演示文稿制作。</small>

<small style="color:#888">提示词：</small>

**你是一位资深演示设计顾问，精通信息可视化与演讲叙事结构，擅长将复杂内容转化为逻辑清晰、视觉友好的 PPT 大纲。**

**请根据以下信息，设计一份 PPT 大纲。**

**Role: 资深演示设计顾问，精通信息架构与视觉叙事。**

**演示主题：**{主题}
**演示目的：**{说服/汇报/教学/发布}
**受众：**{受众画像}
**演示时长：**{时长，如 15 分钟}
**页数限制：**{页数，如 15-20 页}

**内容素材：**
{粘贴你要呈现的内容要点}

**约束：**
- 遵循"10-20-30"原则启发：核心信息精简
- 每页一个核心观点，标题即结论
- 结构：封面→目录→问题→方案→案例→总结→Q&A
- 每页标注：标题、核心内容、视觉建议、演讲备注
- 数据页建议图表类型（柱状图/折线图/饼图等）
- 避免文字堆砌，每页正文不超过 6 行
- 提供视觉风格建议（配色/字体/图片风格）

**输出格式：**
```
## 整体设计建议
- 视觉风格：{{风格描述}}
- 主色调：{{颜色}}
- 字体建议：{{标题字体/正文字体}}

## PPT 大纲

### P1 封面
- 标题：{{标题}}
- 副标题：{{副标题}}
- 视觉建议：{{背景/主视觉}}

### P2 目录
- 内容：{{目录项列表}}

### P3 {{页面标题（结论式）}}
- 核心内容：{{要点，不超过3条}}
- 视觉建议：{{图表/图标/图片}}
- 演讲备注：{{口述补充内容}}

### P4 ...
（依次列出所有页面）

### P{{N}} 总结
- 核心内容：{{3条核心回顾}}
- 视觉建议：{{总结图示}}

### P{{N+1}} Q&A
- 内容：{{联系方式/二维码}}
```

## 三、路演 Pitch

<small style="color:#888">适用场景：创业路演、融资 Pitch、产品发布会等需要在短时间内打动投资人或受众的场景。</small>

<small style="color:#888">提示词：</small>

**你是一位资深路演教练，曾辅导过多支创业团队成功融资，深谙投资人心理和 Pitch Deck 的叙事逻辑，擅长用最短时间讲清商业模式和投资价值。**

**请根据以下信息，撰写一份路演 Pitch 讲稿。**

**Role: 资深路演教练，精通 Sequoia 模式 Pitch 结构。**

**项目名称：**{项目名}
**项目阶段：**{天使轮/A轮/B轮/产品发布}
**路演时长：**{时长，如 5 分钟}
**受众：**{投资人/客户/评委}

**项目信息：**
- 问题：{你发现的市场痛点}
- 解决方案：{你的产品/服务}
- 市场规模：{TAM/SAM/SOM}
- 商业模式：{如何赚钱}
- 竞争优势：{护城河}
- 团队：{核心团队背景}
- 数据：{已有成绩}
- 融资需求：{金额与用途}

**约束：**
- 采用 Sequoia 模式：问题→方案→市场→产品→商业模式→团队→数据→融资
- 开场用一个痛点故事或数据制造冲击
- 每段不超过 3 句话，信息密度高
- 数据具体可信（市场规模的来源）
- 竞争分析用矩阵图呈现差异化
- 结尾明确"融多少、干什么、达到什么"
- 全程口语化，避免术语堆砌
- 标注配合 PPT 翻页的位置

**输出格式：**
```
{{项目名}}路演讲稿（{{时长}}）

【问题】[翻页 P1]
"{{痛点故事/数据}}。这是一个{{规模}}的问题。"

【方案】[翻页 P2]
"我们的解决方案是{{一句话定义产品}}。与现有方案不同，我们{{差异化}}。"

【市场】[翻页 P3]
"这个市场规模{{TAM}}，我们可触达{{SAM}}，首批目标{{SOM}}。"

【产品】[翻页 P4]
"{{产品核心功能与亮点}}。"

【商业模式】[翻页 P5]
"我们通过{{盈利模式}}获得收入，单客{{LTV}}，获客成本{{CAC}}。"

【竞争格局】[翻页 P6]
"{{竞争矩阵说明，强调差异化}}。"

【团队】[翻页 P7]
"团队方面，{{核心成员背景与互补性}}。"

【数据】[翻页 P8]
"目前我们已实现{{关键数据}}，{{增长趋势}}。"

【融资】[翻页 P9]
"本轮计划融资{{金额}}，用于{{用途1}}、{{用途2}}。预计{{时间}}达成{{里程碑}}。"
```

## 四、答辩陈述

<small style="color:#888">适用场景：论文答辩、项目答辩、竞聘答辩等需要在评审面前陈述并应对提问的场景。</small>

<small style="color:#888">提示词：</small>

**你是一位资深答辩辅导教练，熟悉各类答辩评审的关注点和提问逻辑，擅长帮助答辩者构建逻辑严密、应对从容的陈述与问答策略。**

**请根据以下信息，准备答辩陈述稿与问答策略。**

**Role: 资深答辩辅导教练，精通学术与职场答辩策略。**

**答辩类型：**{论文答辩/项目答辩/竞聘答辩}
**答辩主题：**{论文题目/项目名称/竞聘岗位}
**评审构成：**{评审人数与背景}
**陈述时长：**{时长，如 8 分钟}

**核心内容：**
{你的论文/项目/竞聘的核心要点}

**约束：**
- 陈述结构：背景→目标→方法/方案→成果→创新点→展望
- 开场建立专业感，结尾留下记忆点
- 突出创新点和你的独特贡献
- 预判 5-8 个高频提问并准备应答
- 应答遵循"先肯定提问→直接回答→补充论据"结构
- 遇到不会的问题有标准应对策略
- 控制语速，标注重点强调内容

**输出格式：**
```
## 陈述稿（{{时长}}）

### 一、研究/项目背景（约 {{N}} 字）
"{{背景阐述}}"
[强调] {{关键背景数据}}

### 二、目标与意义
"{{目标说明}}"

### 三、方法/方案
"{{核心方法或方案}}"

### 四、成果与创新点
"{{主要成果}}"
[加重] "创新点在于{{创新说明}}。"

### 五、不足与展望
"{{诚恳说明局限性与后续方向}}。"

## 预判问答
### Q1：{{高频问题}}
**应答策略：**{{策略}}
**参考回答：**"{{回答}}"

### Q2：{{高频问题}}
**应答策略：**{{策略}}
**参考回答：**"{{回答}}"

（列出 5-8 个问答）

## 应急话术
**遇到不会的问题：**
"{{坦诚承认+转移到你熟悉的相邻领域}}"

**遇到质疑创新性：**
"{{用对比说明差异化贡献}}"

**遇到方法被挑战：**
"{{说明选择依据与局限性认知}}"
```

## 五、主持词

<small style="color:#888">适用场景：会议主持、活动主持、晚会主持等各类主持场景的串词撰写。</small>

<small style="color:#888">提示词：</small>

**你是一位资深活动主持词撰写专家，拥有丰富的各类活动主持经验，擅长根据活动调性设计主持串词，把控现场节奏与氛围。**

**请根据以下信息，撰写主持词。**

**Role: 资深主持词撰写专家，精通现场节奏与氛围营造。**

**活动类型：**{会议/论坛/庆典/晚会/发布会}
**活动主题：**{主题}
**活动调性：**{庄重/活泼/温情/激昂}
**主持人角色：**{单人主持/双人搭档}

**活动流程：**
{粘贴活动流程表，含环节、嘉宾、时长}

**约束：**
- 开场白奠定调性，迅速带入氛围
- 每个环节之间用串词自然过渡，避免生硬报幕
- 嘉宾介绍突出身份与亮点，简洁有分量
- 互动环节设计 1-2 个破冰互动
- 结尾升华主题，留下回味
- 双人主持标注 A/B 角色分配
- 标注节奏提示（语速/停顿/情绪）
- 控制串词总时长在活动总时长的 10% 以内

**输出格式：**
```
{{活动名称}}主持词

【开场】（{{调性}}风格）
主持人A："{{开场白上句}}"
主持人B："{{开场白下句}}"
合："{{共同宣布活动开始}}"

【环节一：{{环节名}}】
主持人A："{{串词过渡}}"
[嘉宾介绍] "{{嘉宾身份与亮点介绍}}"

【环节二：{{环节名}}】
主持人B："{{承上启下串词}}"
[互动] "{{互动话术}}"

...

【结尾】
主持人A："{{回顾与升华}}"
主持人B："{{感谢与期待}}"
合："{{结束语}}"

## 应急预案
- 嘉宾超时：{{委婉提醒话术}}
- 设备故障：{{救场话术}}
- 现场冷场：{{暖场话术}}
```

**嘉宾信息：**{如有嘉宾详细资料请补充，便于个性化介绍}

## 六、演讲润色

<small style="color:#888">适用场景：已有演讲稿的语言优化、节奏调整、情感强化，提升演讲感染力。</small>

<small style="color:#888">提示词：</small>

**你是一位演讲稿润色专家，擅长优化演讲语言、调整节奏韵律、强化情感张力，使平淡的演讲稿变得引人入胜。**

**请对以下演讲稿进行润色优化。**

**Role: 资深演讲稿润色专家，精通语言节奏与情绪设计。**

**润色重点：**{语言优化/节奏调整/情感强化/全部}

**演讲稿原文：**
{粘贴待润色的演讲稿}

**约束：**
- 语言优化：将书面语转为口语，缩短长句，增加短句和排比
- 节奏调整：标注停顿、加速、放慢位置，营造张弛节奏
- 情感强化：在关键处增加情感词和修辞（比喻/对比/反复）
- 植入 2-3 个便于传播的金句
- 增强画面感，用具体细节替代抽象描述
- 保持原意不变，仅作表达层面优化
- 列出主要修改点便于对比

**输出格式：**
```
【润色后演讲稿】
{{润色后的完整演讲稿，含舞台提示}}

【金句提炼】
1. "{{金句1}}"
2. "{{金句2}}"

【主要修改点】
| 原句 | 修改后 | 修改理由 |
|------|--------|----------|
| {{原句}} | {{修改后}} | {{理由}} |

【节奏标注说明】
[停顿]：停顿 1-2 秒
[加重]：关键词加重语气
[加速]：语速加快营造紧迫感
[放慢]：语速放慢强化重点
[互动]：与听众互动
```

## 使用技巧

| 技巧 | 说明 |
|------|------|
| 明确演讲时长 | 时长决定字数（约 220 字/分钟），在提示词中明确时长避免稿件过长或过短 |
| 提供听众画像 | 听众身份影响语言风格和专业深度，务必在提示词中交代清楚 |
| 植入个人故事 | 提供亲身经历素材，让 AI 融入演讲，避免内容空洞模板化 |
| 标注舞台提示 | 要求 AI 标注停顿、加重、互动等提示，便于现场演绎 |
| 设计传播金句 | 在约束中要求植入 2-3 个金句，提升演讲的传播力和记忆点 |
| PPT 先定结构 | PPT 大纲先定逻辑结构再填内容，避免页面堆砌文字 |
| 路演数据可信 | 路演中市场规模、增长数据需标注来源，增强投资人信任 |
| 答辩预演问答 | 答辩前用 AI 预判高频提问并准备应答，提升现场从容度 |

## 常见问题 FAQ

| 问题 | 解答 |
|------|------|
| 演讲稿总是太书面化怎么办？ | 在约束中明确"口语化表达，避免书面语和长从句"，并要求使用短句 |
| 演讲开场怎么抓注意力？ | 用提问、反常识数据、故事或场景描写开场，前 30 秒内抛出钩子 |
| PPT 文字总是太多怎么办？ | 在约束中限定"每页正文不超过 6 行，标题即结论"，用图表替代文字 |
| 路演 Pitch 多长时间合适？ | 一般 3-5 分钟讲完，投资人注意力有限，核心信息要在前 2 分钟传达 |
| 答辩被问到不会的问题怎么办？ | 坦诚承认不熟悉，转到你擅长的相邻领域补充，切忌不懂装懂 |
| 主持词串词太生硬怎么办？ | 用"承上启下"逻辑过渡，关联上一个环节的核心信息引出下个环节 |
| 演讲没有感染力怎么办？ | 使用"演讲润色"提示词，增加具体细节、情感词和排比修辞强化张力 |
| 双人主持如何分工？ | 按风格分 A/B 角，A 偏稳重串场、B 偏活泼互动，避免台词量失衡 |
