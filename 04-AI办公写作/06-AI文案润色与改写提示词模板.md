## 一、文案润色

<small style="color:#888">适用场景：语法修正、用词优化、表达提升，使文案更准确、流畅、专业。</small>

<small style="color:#888">提示词：</small>

**你是一位资深文字编辑，拥有敏锐的语言直觉和丰富的润色经验，擅长在不改变原意的前提下优化文案的语法、用词和表达，使文字更专业、流畅、有感染力。**

**请对以下文案进行润色。**

**Role: 资深文字编辑，精通中文语法与修辞。**

**润色重点：**{语法修正/用词优化/表达提升/全部}
**目标风格：**{专业/通俗/精炼/生动}
**目标读者：**{读者画像}

**待润色文案：**
{粘贴待润色的文案}

**约束：**
- 修正语法错误、标点误用、错别字
- 优化用词：将口语化/重复/模糊的词替换为精准表达
- 提升表达：调整句式，避免冗长从句和欧化句式
- 保持原意不变，不增删核心信息
- 统一术语和人称，保持全文一致
- 列出主要修改点便于核对
- 标注存疑处请人工确认

**输出格式：**
```
【润色后文案】
{{润色后的完整文案}}

【主要修改点】
| 序号 | 原文 | 修改后 | 修改类型 | 修改理由 |
|------|------|--------|----------|----------|
| 1 | {{原文}} | {{修改后}} | {{语法/用词/表达}} | {{理由}} |
| 2 | ... | ... | ... | ... |

【存疑提示】
- {{存疑处}}：{{说明}}，请确认
```

## 二、风格转换

<small style="color:#888">适用场景：将文案在不同风格间转换，如口语化、书面化、学术化、商务化等。</small>

<small style="color:#888">提示词：</small>

**你是一位资深文案风格转换专家，深谙不同文体的语言特征和表达惯例，擅长将同一段内容转换为不同风格，适配不同场景和受众。**

**请将以下文案转换为指定风格。**

**Role: 资深文案风格转换专家，精通多文体写作。**

**原始文案：**
{粘贴原始文案}

**目标风格：**{口语化/书面化/学术化/商务化/文学化/新媒体化}
**转换目的：**{说明为什么要转换风格，如"用于社交媒体发布"}

**约束：**
- 保留核心信息和逻辑结构
- 根据目标风格调整：
  - 口语化：用短句、语气词、生活化比喻，像聊天
  - 书面化：用规范句式、正式用词，逻辑严密
  - 学术化：用专业术语、客观表述、引用规范
  - 商务化：用商务术语、结论先行、数据支撑
  - 文学化：用修辞手法、意象描写、情感渲染
  - 新媒体化：用网感表达、emoji、短段落、标题党
- 标注风格转换的关键调整点
- 提供风格特征对照便于理解差异

**输出格式：**
```
【风格转换后文案】
{{转换后的完整文案}}

【风格特征对照】
| 维度 | 原始风格特征 | 目标风格特征 |
|------|------------|------------|
| 句式 | {{特征}} | {{特征}} |
| 用词 | {{特征}} | {{特征}} |
| 语气 | {{特征}} | {{特征}} |

【关键调整点】
1. {{调整1：原→新，理由}}
2. {{调整2：原→新，理由}}
3. ...
```

## 三、摘要生成

<small style="color:#888">适用场景：文章摘要、会议摘要、文献摘要等各类长文本的精简概括。</small>

<small style="color:#888">提示词：</small>

**你是一位资深信息提炼专家，擅长从冗长文本中快速提取核心信息，生成结构清晰、信息密度高的摘要，符合不同场景的摘要规范。**

**请根据以下内容生成摘要。**

**Role: 资深信息提炼专家，精通各类摘要规范。**

**摘要类型：**{文章摘要/会议摘要/文献摘要/执行摘要}
**目标长度：**{字数，如 200 字/3 句话/1 段}
**目标读者：**{读者画像}

**原文内容：**
{粘贴长文本}

**约束：**
- 文章摘要：概括背景、核心观点、结论
- 会议摘要：参会方、议题、决议、行动项
- 文献摘要：研究目的、方法、结果、结论（结构化）
- 执行摘要：面向决策者，突出关键发现和建议
- 保留关键数据和专有名词
- 不添加原文没有的信息和评价
- 用最精炼的语言，去除冗余修饰
- 按目标长度严格控制

**输出格式：**
```
【{{摘要类型}}】

{{摘要正文}}

【关键词】
{{3-5个关键词}}
```

## 四、扩写续写

<small style="color:#888">适用场景：内容扩展、故事续写、细节补充，将简短内容丰富为完整文本。</small>

<small style="color:#888">提示词（内容扩写）：</small>

**你是一位资深内容创作专家，擅长在不改变核心信息的前提下，通过补充细节、例证、背景使简短内容丰富饱满，保持逻辑连贯。**

**请对以下内容进行扩写。**

**Role: 资深内容创作专家，擅长细节铺陈与逻辑扩展。**

**目标字数：**{从 X 字扩写到 Y 字}
**扩写方向：**{补充细节/增加例证/丰富背景/全部}
**风格要求：**{保持原风格/调整为指定风格}

**原始内容：**
{粘贴待扩写的简短内容}

**约束：**
- 保持原意和核心信息不变
- 扩写内容与原文逻辑连贯，不突兀
- 补充的细节、例证须合理且服务于核心信息
- 避免注水式扩写（如重复、堆砌形容词）
- 扩写后文风统一，无明显拼接痕迹
- 标注扩写了哪些部分

**输出格式：**
```
【扩写后内容】
{{扩写后的完整内容}}

【扩写说明】
- 补充的细节：{{说明}}
- 增加的例证：{{说明}}
- 丰富的背景：{{说明}}
```

**请根据以下故事开头进行续写。**

**Role: 资深故事创作者，精通叙事结构与人物塑造。**

**故事开头：**
{粘贴已有的故事内容}

**续写要求：**
- 续写长度：{字数}
- 故事走向：{大团圆/开放式/反转/悲剧}
- 风格基调：{与原文一致/悬疑/温情/幽默}
- 必含元素：{需要出现的情节或元素}

**约束：**
- 保持人物性格和说话方式一致
- 情节发展符合逻辑，无突兀转折
- 延续原文叙事视角和时态
- 对话自然，符合人物身份
- 节奏张弛有度，避免流水账
- 续写与原文衔接自然，无明显分界

**输出格式：**

## 五、降重改写

<small style="color:#888">适用场景：论文降重、原创改写、同义替换，在保持原意的前提下降低文本相似度。</small>

<small style="color:#888">提示词：</small>

**你是一位资深学术写作与改写专家，深谙学术规范和查重机制，擅长通过句式重构、同义替换、语序调整等方法在保持原意的前提下有效降低文本重复率。**

**请对以下内容进行降重改写。**

**Role: 资深学术改写专家，精通查重规避与同义表达。**

**降重目标：**{降低重复率至 X% 以下}
**改写程度：**{轻度/中度/深度}
**保持要素：**{专业术语/核心观点/数据}

**待改写内容：**
{粘贴需要降重的文本}

**约束：**
- 保持原意和核心观点不变
- 改写手段：
  - 同义词替换（如"研究"→"探讨""考察"）
  - 句式转换（主动↔被动、陈述↔疑问）
  - 语序调整（主谓宾重新排列）
  - 长句拆分或短句合并
  - 表述方式转换（肯定↔双重否定）
- 专业术语和数据保持不变（术语不可替换）
- 改写后语句通顺，无生硬感
- 不引入新的观点或信息
- 标注主要改写点便于核对

**输出格式：**
```
【降重后内容】
{{改写后的完整内容}}

【改写对照】
| 序号 | 原文 | 改写后 | 改写方法 |
|------|------|--------|----------|
| 1 | {{原文}} | {{改写}} | {{同义替换/句式转换/语序调整}} |
| 2 | ... | ... | ... |

【降重说明】
- 改写程度：{{轻度/中度/深度}}
- 保持不变的术语：{{术语列表}}
- 预计降重效果：{{说明}}
```

## 六、多语言改写

<small style="color:#888">适用场景：中英互译改写、多语言适配，不仅翻译更进行本地化表达改写。</small>

<small style="color:#888">提示词：</small>

**你是一位资深跨语言改写专家，精通中英文及多语言表达差异，擅长在语言转换时进行本地化改写，使译文符合目标语言的表达习惯而非逐字翻译。**

**请将以下内容进行多语言改写。**

**Role: 资深跨语言改写专家，精通本地化表达。**

**源语言：**{中文/英文}
**目标语言：**{英文/中文/其他}
**改写类型：**{直译改写/本地化改写/意译改写}
**目标受众：**{受众文化与背景}

**原始内容：**
{粘贴原始内容}

**约束：**
- 不仅翻译，更进行表达习惯适配
- 处理文化特定表达：
  - 成语/俚语：替换为目标语言的对等表达，而非直译
  - 习语/典故：转换为目标文化可理解的表述
  - 量词/敬语：按目标语言习惯调整
- 保持专业术语准确（必要时附原文）
- 调整句式结构以符合目标语言习惯
  - 中文重意合→英文重形合（补充连接词）
  - 英文长句→中文短句（拆分）
- 语气和正式程度与原文匹配
- 提供改写说明，解释关键调整

**输出格式：**
```
【{{目标语言}}改写】
{{改写后的内容}}

【关键改写说明】
| 原文表达 | 目标语言表达 | 改写说明 |
|----------|------------|----------|
| {{原文}} | {{译文}} | {{为何这样改写}} |

【文化适配点】
- {{适配1：原文→目标表达，理由}}
- {{适配2：原文→目标表达，理由}}

【术语对照】
| 源语言术语 | 目标语言术语 | 说明 |
|-----------|------------|------|
| {{术语}} | {{术语}} | {{备注}} |
```

## 使用技巧

| 技巧 | 说明 |
|------|------|
| 明确润色重点 | 不同文案问题不同，在提示词中指定"语法/用词/表达"重点，避免大改失原味 |
| 提供目标读者 | 读者画像影响用词和风格，务必告知 AI 目标读者是谁 |
| 风格转换给范例 | 提供目标风格的范例文本，AI 能更准确把握风格特征 |
| 摘要控制长度 | 明确字数或句数限制，避免摘要过长失去精简意义 |
| 扩写避免注水 | 在约束中明确"避免重复和堆砌形容词"，要求扩写服务于核心信息 |
| 续写提供走向 | 故事续写时明确走向和必含元素，避免 AI 跑偏 |
| 降重保护术语 | 专业术语和数据不可替换，在"保持要素"中明确列出 |
| 多语言需文化适配 | 翻译改写重点在文化适配，成语俚语用对等表达而非直译 |

## 常见问题 FAQ

| 问题 | 解答 |
|------|------|
| 润色后风格变了怎么办？ | 在约束中明确"保持原风格"，并提供目标风格说明，要求 AI 仅优化不改变风格 |
| 风格转换后读着别扭怎么办？ | 提供目标风格的范例文本，并在约束中要求"自然不生硬" |
| 摘要总是漏掉关键信息怎么办？ | 在提示词中列出必须保留的核心信息点，要求 AI 逐条覆盖 |
| 扩写后内容空洞怎么办？ | 要求"补充具体细节和例证"，禁止"重复和堆砌形容词"，并指定扩写方向 |
| 降重后语句不通顺怎么办？ | 改写程度选择"中度"而非"深度"，并要求"语句通顺，无生硬感" |
| 降重会影响专业术语吗？ | 不会。在"保持要素"中明确列出不可替换的专业术语，AI 会保留 |
| 中英互译总是翻译腔怎么办？ | 选择"本地化改写"而非"直译"，要求按目标语言表达习惯调整句式 |
| AI 改写后还能保留我的语气吗？ | 在提示词中说明你的个人语气特征（如幽默/严谨），要求 AI 保持 |
