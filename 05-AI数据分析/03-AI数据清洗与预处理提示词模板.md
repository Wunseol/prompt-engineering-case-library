### {字段1}

## 执行代码
```python
import pandas as pd
import numpy as np
from sklearn.ensemble import IsolationForest

df = pd.read_csv('{file_path}')

# 方法1：IQR 检测
def detect_iqr(series, k=1.5):
    q1, q3 = series.quantile([0.25, 0.75])
    iqr = q3 - q1
    lower, upper = q1 - k*iqr, q3 + k*iqr
    return (series < lower) | (series > upper)

# 方法2：Z-score 检测
def detect_zscore(series, threshold=3):
    z = (series - series.mean()) / series.std()
    return np.abs(z) > threshold

# 方法3：孤立森林（多变量）
iso = IsolationForest(contamination=0.05, random_state=42)
df['anomaly'] = iso.fit_predict(df[['{字段1}','{字段2}']])
```

### 2.1 异常检测方法对比

| 方法 | 适用场景 | 优点 | 局限 | 假设 |
|------|---------|------|------|------|
| IQR | 单变量，偏态分布 | 稳健，不依赖分布 | 无法检测多变量异常 | 无 |
| Z-score | 单变量，正态分布 | 简单直观 | 对极端值敏感 | 近似正态 |
| 3σ 原则 | 单变量，正态分布 | 业务易理解 | 仅适用正态 | 严格正态 |
| 孤立森林 | 多变量，大数据 | 无需分布假设 | 需调参 | 无 |
| DBSCAN | 多变量聚类异常 | 可发现簇外点 | 高维效果差 | 密度可分 |
| LOF | 多变量局部异常 | 检测局部异常 | 计算量大 | 无 |

### 3.1 数值变换方法选择

```python
import pandas as pd

print(f"合并前: {len(df1_dedup)}, 合并后: {len(merged)}")

```

```python
# 可复用的校验规则
def check_completeness(df, field):
    return df[field].isnull().mean()

def check_uniqueness(df, key):
    return 1 - df.duplicated(key).mean()

def check_validity(df, field, rule):
    return df[field].apply(rule).mean()
```

## 使用技巧

| 技巧 | 说明 |
|------|------|
| 先备份再清洗 | 清洗前保存原始数据副本，所有操作可回滚 |
| 先评估后处理 | 先做质量评估报告，明确问题再动手，避免盲目清洗 |
| 保留缺失标记 | 填充缺失值时新增 `_was_missing` 布尔列，保留缺失信息 |
| 区分业务极值 | 异常值检测后必须人工复核，避免删除真实业务极值 |
| 防止数据泄露 | 标准化/编码器仅在训练集拟合，再 transform 测试集 |
| 流水线可审计 | 每步输出变更日志（影响行数、变更类型），便于追溯 |
| 增量优先 | 大数据量优先增量清洗，避免全量重跑的耗时与风险 |

## 常见问题 FAQ

| 问题 | 解答 |
|------|------|
| 缺失值该删除还是填充？ | 看缺失率与含义：采集失败的空可填充，业务意义的空应标记保留；高缺失率字段考虑删除 |
| 异常值要不要直接删除？ | 不要。先区分数据错误与业务极值，业务极值（如大额批发）应保留 |
| 标准化和归一化用哪个？ | 线性模型/SVM/NN 用标准化，距离类算法用归一化，树模型通常不需要 |
| 高基数类别怎么编码？ | OneHot 适用于基数≤20；超过用 Target 编码或频率编码，避免维度爆炸 |
| 多表合并键不一致怎么办？ | 先做键标准化（去空格/统一大小写/格式对齐），仍不一致考虑模糊匹配 |
| 清洗后数据量大幅减少正常吗？ | 不正常。检查是否有过度删除，正常清洗损失率应控制在 5% 以内 |
| 如何保证清洗可复现？ | 固定随机种子、保存中间快照、用脚本而非手动操作，版本化清洗代码 |
