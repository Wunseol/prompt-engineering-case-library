**字段详情：**

|------|------|--------|---------|

**业务约束：{如"线上特征必须实时可算"/"不可使用未来信息"}**
**工具：{scikit-learn / XGBoost / PyTorch}**

## 执行代码
```python
from sklearn.model_selection import TimeSeriesSplit
from xgboost import XGBClassifier
from sklearn.metrics import classification_report

tscv = TimeSeriesSplit(n_splits=5)
model = XGBClassifier(
    scale_pos_weight={正负比},
    eval_metric='auc',
    early_stopping_rounds=50
)

for train_idx, val_idx in tscv.split(X):
    X_train, X_val = X.iloc[train_idx], X.iloc[val_idx]
    model.fit(X_train, y_train, eval_set=[(X_val, y_val)], verbose=False)
    print(classification_report(y_val, model.predict(X_val)))
```

### 3.1 不平衡数据处理方法

| 方法 | 适用场景 | 优点 | 风险 |
|------|---------|------|------|
| class_weight | 各类样本足 | 不丢信息 | 可能欠拟合少数类 |
| 过采样(SMOTE) | 少数类极少 | 增强少数类 | 可能过拟合 |
| 欠采样 | 多数类冗余 | 加速训练 | 丢失信息 |
| 组合采样 | 极端不平衡 | 平衡效果 | 复杂度高 |
| 阈值调整 | 评估阶段 | 灵活调 Precision/Recall | 不改模型 |

import optuna
from sklearn.model_selection import cross_val_score
from xgboost import XGBClassifier

def objective(trial):
    params = {
        'n_estimators': trial.suggest_int('n_estimators', 100, 500),
        'max_depth': trial.suggest_int('max_depth', 3, 10),
        'learning_rate': trial.suggest_float('learning_rate', 0.01, 0.3, log=True),
        'subsample': trial.suggest_float('subsample', 0.6, 1.0),
    }
    model = XGBClassifier(
        n_estimators=params['n_estimators'],
        max_depth=params['max_depth'],
        learning_rate=params['learning_rate'],
        subsample=params['subsample']
    )
    return cross_val_score(model, X, y, scoring='roc_auc', cv=5).mean()

study = optuna.create_study(direction='maximize')

## 使用技巧

| 技巧 | 说明 |
|------|------|
| 先建基线再优化 | 先用简单模型（逻辑回归）建基线，复杂模型必须显著超越才有价值 |
| 防数据泄露 | 时序数据严格按时间划分，特征工程禁用未来信息 |
| 类不平衡看 PR | 极不平衡场景 ROC 容易虚高，优先看 PR 曲线与 Recall |
| 调参抓重点 | 优先调高影响参数（learning_rate/max_depth），低影响参数后微调 |
| 解释要双向 | 既看特征重要性，也看作用方向，避免误判 |
| 线上线下一致 | 特征工程逻辑必须线上线下可复现，避免训练-服务偏差 |
| 监控漂移 | 上线后持续监控特征分布与效果漂移，建立再训练机制 |

## 常见问题 FAQ

| 问题 | 解答 |
|------|------|
| 特征工程怎么避免数据泄露？ | 严格按时间划分，聚合特征只用历史窗口，禁用含未来信息的字段 |
| 类别极不平衡怎么处理？ | 用 class_weight 或 SMOTE，评估看 PR-AUC 和 Recall，不盲目追 Accuracy |
| 模型效果不如预期怎么办？ | 先检查数据质量与特征工程，再调模型；通常特征 > 模型 > 调参 |
| 超参调优用哪种方法？ | 数据小用网格，数据大用随机，计算够用贝叶斯优化（Optuna） |
| SHAP 值怎么解读？ | 正值推向正类预测，负值推向负类，基准值是训练集平均预测 |
| 模型上线后效果下降？ | 检查特征漂移、数据分布变化、线上线下特征一致性 |
| 树模型需要特征标准化吗？ | 不需要，树模型对单调变换不敏感；线性模型与神经网络需要 |
