## 一、报告框架

<small style="color:#888">适用场景：设计周报、月报、季度报告的标准结构，确保报告内容完整、层次清晰、可复用。</small>

<small style="color:#888">提示词：</small>

**你是一位数据报告架构专家，擅长设计标准化、可复用的报告框架，平衡完整性与可读性。**

**请为以下需求设计报告框架：**

**报告类型：{日报 / 周报 / 月报 / 季度报告 / 年度复盘 / 专题分析}**
**业务领域：{电商 / SaaS / 内容 / 金融 / 运营 / 其他}**
**报告受众：{高管 / 业务负责人 / 运营团队 / 跨部门}**
**核心目标：{告知进度 / 预警风险 / 推动决策 / 复盘改进}**
**关键指标：{列出需要覆盖的指标}**
**交付形式：{邮件 / PPT / 在线文档 / 自动化推送}**
**篇幅限制：{1 页 / 3 页 / 10 页}**

**请提供：**
1. 报告整体结构（章节顺序与占比）
2. 每个章节的内容要点
3. 固定模块与动态模块区分
4. 报告模板（含占位符）
5. 自动化适配建议

**约束：**
- 结构遵循"结论先行 → 数据支撑 → 风险建议"
- 篇幅分配：摘要 10%、核心指标 20%、分析 40%、建议 20%、附录 10%
- 区分固定结构（每次都有）与动态内容（按需出现）
- 模板用 `{变量名}` 标记可填充字段
- 支持自动化渲染

**输出格式：**

| 章节 | 内容 | 占比 | 类型 | 频率 |
|------|------|------|------|------|

| 风险建议 | 行动项 | 20% | 动态 | 按需 |

## 二、数据摘要

<small style="color:#888">适用场景：自动生成关键指标摘要、对比数据、达成率分析，快速呈现报告核心数据。</small>

<small style="color:#888">提示词：</small>

**你是一位数据摘要生成专家，擅长从原始数据中提炼关键指标、对比与达成情况。**

**请为以下数据生成摘要：**

**报告周期：{如 2024年6月}**
**业务背景：{业务说明}**
**原始数据：**
| 指标 | 本期值 | 上期值 | 去年同期 | 目标值 |
|------|--------|--------|---------|--------|
| {指标} | {值} | {值} | {值} | {值} |

**对比维度：{环比 / 同比 / 目标达成 / 行业基准}**
**关键指标定义：{口径说明}**
**受众：{高管 / 运营}**
**输出形式：{表格 / 文字 / 看板}**

**请提供：**
1. 关键指标摘要表（含对比与达成率）
2. 指标分级标注（达标/预警/未达标）
3. 数据亮点与痛点
4. 一句话核心概括
5. 异常指标标注

**约束：**
- 指标口径必须一致，避免不同定义混淆
- 达成率计算明确分母
- 环比与同比同时呈现，避免单一视角
- 数值保留合理精度，不堆砌小数
- 异常指标必须标注并提示关注

## 数据亮点

- {亮点2}：{数据}，{解读}

## 数据痛点
- {痛点1}：{数据}，{影响}

### 2.1 指标状态判定标准

| 状态 | 达成率 | 环比 | 含义 |
|------|--------|------|------|
| ✅ 优秀 | ≥100% | 上升 | 达标且向好 |

| ⚠️ 预警 | 70%-90% | 下降 | 需关注 |

## 数据获取
```python
import pandas as pd
from sqlalchemy import create_engine

def fetch_data(period):
    engine = create_engine('{db_url}')
    sql = """
    SELECT metric, value, target
    FROM report_metrics
    WHERE date BETWEEN :start AND :end
    """
    return pd.read_sql(sql, engine, params=period)
```

## 模板渲染
```python
from jinja2 import Environment, FileSystemLoader

def render_report(data, template_name='monthly_report.md.j2'):
    env = Environment(loader=FileSystemLoader('templates'))
    template = env.get_template(template_name)
    return template.render(
        title='{报告标题}',
        period='{周期}',
        metrics=data.to_dict('records'),
        summary='{自动生成摘要}'
    )
```

def send_report(content, channel='email'):

## 使用技巧

| 技巧 | 说明 |
|------|------|
| 框架先行 | 先定报告结构与固定模块，再填充动态内容，保证一致性 |
| 摘要置顶 | 执行摘要放最前，3 秒内传达核心结论，方便高管快速浏览 |
| 模板变量化 | 用 `{变量名}` 标记可填充字段，便于自动化渲染与复用 |
| 异常前置 | 发现异常优先标注，避免淹没在常规数据中 |
| 建议可追踪 | 行动建议必须带责任人、时间、指标，否则无法落地 |
| 数据口径一致 | 报告内所有指标口径统一，附录说明定义，避免误解 |
| 自动化兜底 | 数据异常或为空时输出兜底内容，避免报告生成失败 |
