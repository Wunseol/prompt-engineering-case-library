## 一、图表选型

<small style="color:#888">适用场景：根据数据特征和表达目标，从众多图表类型中选出最契合的方案，避免"什么都用柱状图"的误区。</small>

<small style="color:#888">提示词：</small>

**你是一位资深数据可视化专家，精通图表选型决策，擅长把数据特征与表达目标精准匹配。**

**请为以下数据推荐最佳图表方案：**

**数据描述：{数据内容概述，如"某电商平台近12个月各品类销售额"}**
**数据结构：**
- 维度字段：{如时间、品类、地区}
- 度量字段：{如销售额、订单量、转化率}
- 数据规模：{行数 × 列数，类别数量}

**表达目标：{比较 / 趋势 / 分布 / 关系 / 构成 / 排名 / 流转}**
**受众：{高管 / 业务运营 / 技术人员 / 公众}**
**展示媒介：{大屏 / PC 看板 / 移动端 / 静态报告}**
**工具：{ECharts / Tableau / Matplotlib / Power BI / Excel}**

**请提供：**
1. 推荐主图表类型及选择理由
2. 备选方案（当主方案受限时使用）
3. 图表设计要点（轴、颜色、标注）
4. 应避免的图表类型及原因
5. 受众适配说明

**约束：**
- 遵循"数据特征 → 表达目标 → 图表类型"的决策链路
- 优先选择受众认知成本最低的图表
- 类别超过 8 个时给出聚合或分页建议
- 标注每条建议的依据

**输出格式：**
## 推荐图表：{图表名称}

**选择理由：**{为什么选这个图表}

**设计要点：**
- X 轴：{字段}
- Y 轴：{字段}
- 颜色编码：{字段}
- 标注重点：{需要突出的数据点}
- 排序方式：{按数值 / 按时间 / 按类别}

**避免使用：**{不推荐的图表}，原因是{原因}

## 备选方案
{当主方案不适用时的替代方案及触发条件}

## 受众适配
{该图表对当前受众的友好度及调整建议}

### 1.1 图表选型速查

| 表达目标 | 推荐图表 | 避免图表 |
|---------|---------|---------|
| 比较数值 | 柱状图、条形图 | 饼图（超过 5 类） |
| 展示趋势 | 折线图、面积图 | 柱状图（连续时间） |
| 显示分布 | 直方图、箱线图、小提琴图 | 折线图 |
| 展示关系 | 散点图、气泡图 | 柱状图 |
| 显示构成 | 饼图（≤5 类）、树状图 | 堆叠柱状图（类别多时） |
| 展示排名 | 条形图（降序） | 饼图 |
| 展示流转 | 桑基图、漏斗图 | 折线图 |

## 二、配色方案

<small style="color:#888">适用场景：为数据可视化选择合适的配色方案，包括数据配色（顺序/发散/分类型）、品牌配色适配、无障碍配色设计。</small>

<small style="color:#888">提示词：</small>

**你是一位数据可视化配色专家，精通色彩理论与无障碍设计，能为不同数据类型匹配最佳配色方案。**

**请为以下可视化场景设计配色方案：**

**数据类型：{分类型 / 顺序型 / 发散型 / 强调型}**
**图表类型：{柱状图 / 折线图 / 热力图 / 地图 / 散点图}**
**类别数量：{N 个类别}**
**品牌色：{如有品牌主色 #XXXXXX}**
**受众特点：{是否需要色盲友好 / 是否打印场景 / 是否大屏展示}**
**文化背景：{如中国场景红色代表上涨，欧美场景红色代表下跌}**

**请提供：**
1. 主配色方案（含具体 HEX 色值）
2. 配色逻辑说明（为什么选这些颜色）
3. 色盲友好性评估
4. 黑白打印效果评估
5. 扩展性方案（类别增加时如何延伸）

**约束：**
- 分类型数据使用对比鲜明但和谐的色板
- 顺序型数据使用单色渐变（如浅到深）
- 发散型数据使用双向色板（如红-白-蓝）
- 强调色仅用于需要突出的数据
- 遵循 WCAG 2.1 对比度标准（至少 4.5:1）

**输出格式：**
## 配色方案：{方案名称}

**色板色值：**
| 序号 | 颜色 | HEX | 适用类别 |
|------|------|-----|---------|
| 1 | ▢ | #XXXXXX | {类别1} |
| 2 | ▢ | #XXXXXX | {类别2} |

**配色逻辑：**{为什么这样配色}

**色盲友好性：**
- 红绿色盲：{是否友好，如不友好给出替代方案}
- 蓝黄色盲：{是否友好}

**打印效果：**{黑白打印下的区分度评估}

**扩展方案：**{类别数超过当前色板时的处理}

## 使用技巧

| 技巧 | 说明 |
|------|------|
| 先定目标再选图 | 明确"想表达什么"再选图表，避免"有什么数据画什么图" |
| 配色克制 | 单图颜色不超过 5 种，强调色只用一个 |
| 标注重点 | 用颜色/标注线直接指出关键数据点，减少用户查找成本 |
| 移动端优先简化 | 移动端去掉悬停交互，用点击替代，字号放大 |
| 提供数据样本 | 生成代码时给 5-10 行真实样本数据，准确率更高 |
| 区分探索与汇报 | 探索阶段用交互图，汇报阶段用静态图配文字解读 |
| 测试色盲友好 | 用 Coblis 等工具验证配色在色盲视角下的区分度 |

## 常见问题 FAQ

| 问题 | 解答 |
|------|------|
| AI 生成的 ECharts 代码不能直接运行？ | 通常是数据格式或容器未初始化，检查 DOM 是否存在、数据是否为数组 |
| 多少类别适合用饼图？ | ≤5 类，超过用条形图或树状图，避免切片过小难辨认 |
| 折线图 X 轴时间不连续怎么办？ | 用 category 类型避免折线断裂，或在数据中补 0 并标注 |
| 如何让看板响应式？ | ECharts 用 resize 事件监听容器；Tableau 用 Device Designer |
| 双 Y 轴会不会误导？ | 会，慎用。务必标注单位，避免双轴量纲差异过大造成视觉错觉 |
| 数据量太大图表卡顿？ | 数据采样、聚合、分页，或用 Canvas 渲染替代 SVG |
| 大屏配色和 PC 有什么不同？ | 大屏用深色背景 + 高饱和强调色，PC 用浅色背景降低视觉疲劳 |
