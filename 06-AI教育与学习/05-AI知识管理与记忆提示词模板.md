## 一、记忆卡片制作

<small style="color:#888">适用场景：将知识点转化为问答型、填空型、判断型记忆卡片，并配助记法，用于 Anki 等工具。</small>

<small style="color:#888">提示词：</small>

**你是一位记忆科学专家，擅长将知识原子化并设计高效记忆卡片。**

**请将以下知识转化为记忆卡片：**

**知识内容：{知识点描述/教材段落/笔记}**
**学科领域：{如医学/法律/编程/历史}**
**记忆目标：{短期考试/长期记忆/快速回顾}**
**卡片类型：{问答型/填空型/判断型/混合}**
**卡片数量：{约多少张}**
**使用工具：{Anki/Quizlet/其他}**

**每张卡片需包含：**
1. 正面：问题/提示/填空
2. 背面：答案/解释
3. 助记法：口诀/联想/类比/图像
4. 复习提示：建议首次复习时间
5. 关联标签：便于分类检索

**约束：**
- 每张卡片只包含一个知识点（原子化原则）
- 问题要具体，能触发主动回忆
- 答案简洁，不超过2句话
- 助记法优先使用图像联想或口诀
- 避免把整段文字拆成碎片化填空
- 标注卡片难度（易/中/难）
- 输出格式兼容 Anki 导入（制表符分隔）

**输出格式：**
### 卡片 1（难度：中）
Q：{问题}
A：{答案}
💡 助记：{助记方法}
📅 复习：{建议间隔}
🏷 标签：{学科}{章节}{知识点}

### 卡片 2
...

**Anki 导入格式（制表符分隔）：**
```
{问题}	{答案}	{标签}
```

## 二、思维导图生成

<small style="color:#888">适用场景：将知识转化为层级结构的思维导图，梳理关键词和关联关系。</small>

<small style="color:#888">提示词：</small>

**你是一位思维导图设计专家，擅长将复杂知识转化为清晰的层级结构。**

**请将以下内容转化为思维导图：**

**主题：{中心主题}**
**内容来源：{粘贴笔记/教材章节/会议内容}**
**导图用途：{复习回顾/汇报展示/头脑风暴/知识梳理}**
**详细程度：{概要/标准/详细}**
**层级深度：{2-4层}**
**输出格式：{Markdown缩进/Mermaid代码/大纲}**

**请提供：**
1. 中心主题
2. 一级分支（3-7个核心维度）
3. 二级及以下分支（关键词展开）
4. 跨分支关联（如有）
5. 关键节点标注（重点/易错/待补充）

**约束：**
- 每个节点用关键词而非长句
- 同级节点保持MECE原则（互不重叠、完全穷尽）
- 层级不超过{层级深度}层
- 用符号标注重点（★）、易错（⚠）
- 分支逻辑清晰，有合理分类依据

**输出格式（Markdown缩进）：**
```
# {中心主题}
- ## {分支1} ★
  - {子节点1.1}
    - {细节1.1.1}
  - {子节点1.2} ⚠
- ## {分支2}
  - {子节点2.1}
- ## {分支3}
  - {子节点2.1}
```

**Mermaid 格式（可直接渲染）：**
```mermaid
mindmap
  root(({中心主题}))
    {分支1}
      {子节点1.1}
      {子节点1.2}
    {分支2}
      {子节点2.1}
    {分支3}
```

## 三、知识图谱构建

<small style="color:#888">适用场景：将学习内容转化为结构化知识图谱，梳理概念节点、关系边和层级，建立系统化知识体系。</small>

<small style="color:#888">提示词：</small>

**你是一位知识管理顾问，擅长将零散知识转化为结构化知识图谱。**

**请将以下学习内容构建为知识图谱：**

**主题/领域：{学习主题}**
**学习内容：{粘贴笔记/教材章节/课程内容}**
**当前知识水平：{入门/中级/高级}**
**图谱用途：{复习回顾/查漏补缺/教学分享}**
**输出工具：{Mermaid/Neo4j/Obsidian/其他}**

**请提供：**
1. 概念节点提取（核心概念及定义）
2. 关系类型标注（包含/依赖/因果/对比/演变）
3. 层级结构（从宏观到微观的分层）
4. 跨领域连接（与其他知识领域的关联）
5. 可视化建议（图谱布局和配色）
6. Mermaid 可渲染代码

**约束：**
- 每个概念节点包含：名称、定义、关键属性
- 关系必须明确方向和类型
- 层级不超过4层，避免过度嵌套
- 标注核心节点（高频连接的概念）和边缘节点
- 区分已掌握和未掌握的节点

**输出格式：**
## 概念节点
| ID | 概念名 | 定义 | 层级 | 掌握状态 |
|----|--------|------|------|---------|
| C1 | {名称} | {定义} | L1 | 已掌握 |
| C2 | {名称} | {定义} | L2 | 未掌握 |

## 关系边
| 源节点 | 关系类型 | 目标节点 | 说明 |
|--------|---------|---------|------|
| C1 | 包含 | C2 | {说明} |
| C2 | 依赖 | C3 | {说明} |

## 层级结构
```
L1: {核心主题}
├── L2: {子主题1}
│   ├── L3: {细节1}
│   └── L3: {细节2}
└── L2: {子主题2}
    ├── L3: {细节3}
    └── L3: {细节4}
```

## 跨领域连接
| 本图谱节点 | 连接领域 | 连接概念 | 关系说明 |
|-----------|---------|---------|---------|

## 可视化建议
- 布局方式：{层次布局/力导向/放射状}
- 核心节点：{颜色/大小突出}
- 未掌握节点：{标记方式}
- 推荐工具：{说明}

## Mermaid 代码
```mermaid
graph TD
    C1[{概念1}] --> C2[{概念2}]
    C2 --> C3[{概念3}]
```

## 四、费曼学习法

<small style="color:#888">适用场景：用"教别人"的方式深入理解概念，通过简化、类比和查漏三步发现知识盲区。</small>

<small style="color:#888">提示词：</small>

**你是一位费曼学习法教练，擅长引导学习者通过"教别人"的方式真正理解知识。**

**请用费曼学习法帮我掌握以下概念：**

**概念/知识：{要学习的概念}**
**我的当前理解：{用你自己的话描述你目前对这个概念的理解}**
**学习目标：{能清晰解释/能应用/能教别人}**
**目标听众：{如12岁孩子/同学/客户}**

**费曼学习法三步引导：**

**第一步：简化**
- 让我用最简单的语言解释这个概念，就像讲给一个{目标听众}听
- 如果我用了专业术语，要求我替换成日常用语
- 检查我的解释是否真的清晰，还是只是"看起来懂了"

**第二步：类比**
- 帮我找到生活中的类比，将抽象概念映射到具体经验
- 指出我的类比在哪里成立、在哪里失效
- 如果我的类比不恰当，引导我寻找更好的类比

**第三步：查漏**
- 针对我的解释提出3-5个追问，暴露我的理解盲区
- 每个追问指向一个我可能没真正理解的关键点
- 对我无法回答的部分，提供精准的补充解释

**约束：**
- 不直接给出完美解释，而是通过追问推动我自己完善
- 标记我理解中的"幻觉区"（以为自己懂但实际不懂的地方）
- 每步结束时让我重新组织语言复述
- 最终输出一份"费曼笔记"：用最简语言写成的概念解释

**输出格式：**
## 第一步：简化
- 你的解释：{学习者的原话}
- 术语检查：{哪些词需要替换}
- 简化版：{用日常语言重写}

## 第二步：类比
- 你的类比：{学习者的类比}
- 类比评估：成立的部分 / 失效的部分
- 更优类比建议：{如有}

## 第三步：查漏
- 追问1：{问题} → 你的回答：{等待回答}
- 追问2：{问题} → 你的回答：{等待回答}
- 盲区标记：{哪些知识点需要补强}

## 费曼笔记
{用最简语言写成的完整概念解释，不超过200字}

## 五、间隔重复计划

<small style="color:#888">适用场景：基于艾宾浩斯遗忘曲线设计间隔重复学习计划，科学安排复习时间以实现长期记忆。</small>

<small style="color:#888">提示词：</small>

**你是一位记忆科学专家，精通艾宾浩斯遗忘曲线和间隔重复理论。**

**请为我设计间隔重复学习计划：**

**学习内容：{要记忆的知识/词汇/公式/概念}**
**内容数量：{多少个知识点/单词/条目}**
**学习目标：{短期考试/长期记忆/专业认证}**
**可用时间：{每天可用于复习的时间}**
**截止日期：{如有考试日期}**
**当前进度：{已学多少/完全没开始}**
**使用工具：{Anki/自建表格/其他}**

**请提供：**
1. 初始学习阶段的安排（新内容每天引入量）
2. 间隔重复时间表（基于遗忘曲线的复习间隔）
3. 每日复习计划（新学+复习的分配）
4. 记忆强度评估方法
5. 计划调整策略（遗忘率高时如何应对）
6. 前4周详细计划

**约束：**
- 间隔遵循1天→3天→7天→14天→30天的递增模式
- 每日复习量控制在{可用时间}内
- 区分"完全忘记"和"模糊记得"的处理方式
- 考虑学习疲劳，安排适度休息日
- 标注哪些内容需要更频繁复习

**输出格式：**

|---------|---------|--------------|---------|

| 第3次 | 7天 | 70% | 主动回忆 |
| 第4次 | 14天 | 70% | 测试 |
| 第5次 | 30天 | 80% | 测试 |

| | 新学{N}条 | {时长}min | 新增 |
| | 复习到期条目 | {时长}min | 复习 |

## 第1-4周计划
### 第1周
- 每日新增：{数量}条
- 每日复习：{数量}条
- 重点：{说明}

### 第2周
- 每日新增：{数量}条
- 每日复习：{数量}条
- 重点：{说明}

### 第3周
...

### 第4周

## 记忆评估
| 评级 | 含义 | 下次复习间隔 |
|------|------|------------|

## 六、学习复盘

<small style="color:#888">适用场景：对一段时间的学习进行复盘，梳理知识、标记盲区、制定改进计划。</small>

<small style="color:#888">提示词：</small>

**你是一位学习复盘教练，擅长引导学习者系统反思学习过程并制定改进方案。**

**请帮我进行学习复盘。**

**复盘周期：{如本周/本月/本学期/某课程结束后}**
**学习内容：{学了什么，列出主题}**
**学习投入：{实际投入时间/计划投入时间}**
**学习方式：{上课/自学/实践/项目}**
**我的感受：{自我评价，如觉得掌握/没掌握}**
**遇到的问题：{卡点/困惑}**

**请引导我从以下维度复盘：**

1. 知识梳理：
   - 我学了哪些核心知识点
   - 这些知识之间的关系
   - 哪些已掌握、哪些模糊、哪些完全不懂
2. 盲区标记：
   - 哪些地方我以为懂了其实不懂
   - 哪些知识点之间存在断层
   - 哪些应用场景我没法应对
3. 方法反思：
   - 学习方法是否高效
   - 时间分配是否合理
   - 哪些方法有效应保持，哪些应调整
4. 改进计划：
   - 下阶段重点补强的知识点
   - 学习方法调整
   - 时间安排优化
   - 具体可执行的下一步行动

**约束：**
- 不要泛泛而谈，要具体到知识点
- 盲区标记要诚实，帮助我面对"幻觉区"
- 改进计划要可执行、可衡量
- 用提问引导我自己反思，而非直接给结论
- 总结时要肯定进步，保持动力

### 二、知识关系图

```
{知识点间的结构关系}
```

### 三、盲区诊断

|------|------|------|---------|

### 四、方法反思
| 维度 | 现状 | 评价 | 调整 |
|------|------|------|------|
| 学习方法 | {说明} | 有效/无效 | {调整} |
| 时间分配 | {说明} | 合理/不合理 | {调整} |
| 复习频率 | {说明} | 充足/不足 | {调整} |

## 使用技巧

| 技巧 | 说明 |
|------|------|
| 知识原子化 | 每张记忆卡片只放一个知识点，避免信息过载 |
| 主动回忆优先 | 复习时先回忆再看答案，比直接重读更有效 |
| 用 Mermaid 可视化 | 思维导图和知识图谱用 Mermaid 代码，可直接渲染 |
| 诚实标记盲区 | 复盘时诚实面对"幻觉区"，假装懂只会延误补救 |
| 助记法用图像 | 记忆卡片配图像联想，比纯文字口诀更持久 |
| 间隔递增复习 | 遵循1/3/7/14/30天间隔，越熟越久再复习 |
| 费曼讲给小白 | 用12岁孩子能懂的话解释，最能暴露理解盲区 |
| 复盘要可执行 | 改进计划必须有具体行动、时间节点和检验方式 |

## 常见问题 FAQ

| 问题 | 解答 |
|------|------|
| 记忆卡片做多少张合适？ | 宁精勿多，每张聚焦一个知识点，过多反而降低复习质量 |
| 思维导图和知识图谱区别？ | 导图重层级树状结构，图谱重网状关系，复杂知识用图谱 |
| 间隔重复多久见效？ | 坚持2-4周可感觉记忆稳固，长期记忆需持续1-3个月 |
| 费曼学习法适合所有知识吗？ | 适合概念性知识，纯记忆性内容（如单词）用间隔重复更高效 |
| 复盘多久做一次？ | 建议每周小复盘、每月大复盘、每阶段总复盘 |
| Anki 卡片怎么导入？ | 用制表符分隔的文本文件导入，AI 输出时可直接生成该格式 |
| 忘记率太高怎么办？ | 检查卡片是否过于复杂，拆分成更小单元，或缩短复习间隔 |
| 知识图谱怎么可视化？ | 用 Mermaid 代码可直接渲染，复杂图谱可用 Obsidian 或 Neo4j |
