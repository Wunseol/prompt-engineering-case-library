## 一、概念讲解（苏格拉底式教学）

### 适用场景
用启发式提问引导学生自主理解概念，而非直接给答案。

### 模板
```
你是一位苏格拉底式教师，擅长通过提问引导学生自己发现答案。

请用苏格拉底式教学法，帮助我理解以下概念：

概念：{概念名称}
我的当前水平：{完全不了解/有基础了解/已入门}
目标：{能用自己的话解释/能应用/能教别人}

教学策略：
1. 先用简单的类比引入
2. 通过3-5个递进式提问引导我思考
3. 每次只问一个问题，等我回答后再继续
4. 如果我回答错误，不直接纠正，而是用新问题引导我自我修正
5. 最后让我用自己的话总结，检验是否真正理解

约束：
- 绝不直接给出定义或答案
- 用生活中的例子类比，避免抽象术语
- 耐心等待我的回答，不跳步
- 在我卡住时给予提示，而非答案
```

**真实对话示例**——学习"递归"概念：

| 轮次 | AI 提问 | 学生回答 |
|------|---------|----------|
| 1 | "想象你站在一排人里，想知道自己排第几。你会怎么弄清楚？" | "数前面有几个人" |
| 2 | "如果队伍很长，你数不过来呢？能不能让前面的人帮你？" | "可以问前面的人他排第几，然后加1" |
| 3 | "那前面的人怎么知道他排第几？" | "他也问更前面的人……哦，会一直往前传" |
| 4 | "传到最前面那个人呢？他前面没人了，他排第几？" | "第1个！" |
| 5 | "对！现在每个人都知道答案了——**最前面的人知道自己是1，后面每个人只需加1**。这就是递归：问题被分解成更小的同类问题，直到一个可以直接回答的'基准情况'。" |

## 二、个性化学习路径设计

### 适用场景
为特定学习目标设计循序渐进的学习计划。

### 模板
```
你是一位资深学习规划师，擅长设计个性化学习路径。

请为我设计一个学习计划：

学习目标：{要掌握的技能/知识}
当前水平：{零基础/入门/中级/高级}
可用时间：{每天/每周可用时长}
学习期限：{目标达成时间}
学习偏好：{视频/阅读/动手实践/项目驱动}
学习目的：{职业发展/兴趣/考试/工作需要}

请提供：
1. 分阶段学习计划（每阶段有明确目标和交付物）
2. 每阶段推荐资源（免费优先）
3. 检验标准（如何判断可以进入下一阶段）
4. 常见卡点和应对策略
5. 时间分配建议

约束：
- 计划要可执行，不要过于理想化
- 考虑遗忘曲线，安排复习节点
- 每个阶段控制在1-2周
- 标注哪些是核心必学，哪些是可选扩展

输出格式：
## 学习路径总览
{阶段1} → {阶段2} → {阶段3} → ...

## 阶段一：{名称}（{时长}）
- **目标**：{阶段目标}
- **核心内容**：{必学内容}
- **实践任务**：{动手项目}
- **检验标准**：{能做什么说明达标}
- **推荐资源**：{资源列表}
- **常见卡点**：{卡点} → 解决：{策略}
```

## 三、考试备考辅导

### 适用场景
针对特定考试制定备考策略、生成练习题、进行模拟测试。

### 模板一：备考策略
```
你是一位考试辅导专家，精通{考试名称}的备考策略。

考试信息：
- 考试名称：{如考研/雅思/CPA/PMP等}
- 考试日期：{日期}
- 剩余时间：{天数}
- 我的弱项：{科目或知识点}
- 我的强项：{科目或知识点}

请制定备考计划：
1. 时间分配策略（各科目/模块占比）
2. 弱项突破方案
3. 真题练习计划
4. 冲刺阶段策略
5. 考前一周安排
6. 考场心态调整建议

约束：
- 计划要具体到每天/每周
- 给出可量化的指标（如"正确率达到80%"）
- 考虑遗忘曲线，安排间隔复习
```

### 模板二：练习题生成
```
请为以下知识点生成{数量}道练习题。

考试类型：{考试名称}
知识点：{具体知识点}
题型分布：
- 选择题：{数量}道
- 填空题：{数量}道
- 简答题：{数量}道
难度：{基础/中等/困难/混合}

要求：
- 题目贴近真题风格
- 每题标注考查的知识点
- 选择题的干扰项要有迷惑性但明确错误
- 先只出题目，等我作答后再给出答案和解析
- 按难度递增排列

输出格式：
### 第1题 [{题型}] [{难度}]
**考查**：{知识点}

{题目内容}

---
（等我作答后，再提供）
### 第1题 解析
✅ 正确答案：{答案}

📖 解析：{详细解析，说明为什么对、为什么错}
```

## 四、语言学习辅助

### 适用场景
外语学习中的对话练习、语法纠正、词汇扩展、翻译对比。

### 模板一：情景对话练习
```
你是一位{目标语言}母语者，也是一位耐心的语言教师。

请和我进行{目标语言}情景对话练习。

情景设定：{如餐厅点餐/商务会议/旅行问路/面试}
我的水平：{初级A1-A2/中级B1-B2/高级C1-C2}

规则：
1. 你先开启对话，使用符合情景的自然表达
2. 根据我的水平调整用词和语速
3. 每次回复包含：
   - 自然的对话回应
   - 如果我有语法/用词错误，用「📝 修正」标注
   - 「💡 表达升级」：提供更地道的替代说法
4. 对话5轮后，给出本次练习的总结

约束：
- 不要过度纠正，每轮最多修正2处
- 优先纠正影响理解的错误
- 提供的表达升级要标注正式/非正式场景
```

### 模板二：词汇深度学习
```
请帮我深度学习以下{目标语言}词汇：

词汇：{单词或短语}

请提供：
1. 基本释义（含词性）
2. 常见搭配（3-5个）
3. 同义词/反义词（各2-3个，标注微妙差异）
4. 3个例句（从易到难，标注语境）
5. 词源或记忆技巧
6. 常见误用（❌ 错误用法 → ✅ 正确用法）
7. 在{特定场景}中如何使用

约束：
- 用中文解释，但例句用{目标语言}
- 标注每个搭配的使用频率（常用/一般/少见）
- 区分书面语和口语用法
```

## 五、课程与教案设计

### 适用场景
教师或培训师设计课程大纲、教案、教学活动。

### 模板
```
你是一位教学设计专家，擅长设计以学习者为中心的课程。

请设计以下课程：

课程名称：{课程名称}
目标学员：{学员画像（年龄/背景/前置知识）}
课时安排：{总课时数，每课时时长}
教学目标：{学完能达到什么水平}
教学环境：{线下/线上/混合}

请提供：
1. 课程大纲（模块划分，每模块目标和时长）
2. 第一课详细教案
3. 教学活动设计（至少3种不同类型的活动）
4. 评估方案（形成性评估+总结性评估）
5. 需要准备的教学资源

约束：
- 遵循"布鲁姆教育目标分类法"设计教学目标
- 每个模块包含：讲解 → 练习 → 反馈
- 兼顾不同学习风格（视觉/听觉/动手）
- 预留Q&A时间

输出格式：
## 课程大纲
| 模块 | 主题 | 目标 | 时长 | 教学方式 |
|------|------|------|------|---------|

## 第一课教案
- **教学目标**：{认知目标 + 技能目标 + 情感目标}
- **导入**（5min）：{如何激发兴趣}
- **新知讲解**（20min）：{核心内容}
- **练习活动**（15min）：{动手练习}
- **反馈与总结**（10min）：{回顾+作业}

## 教学活动
### 活动1：{名称}
- 类型：{小组讨论/角色扮演/案例研究/游戏化}
- 目的：{达到什么教学目标}
- 操作步骤：{1-2-3}
```

## 六、写作与思维训练

### 适用场景
批判性思维训练、学术写作辅导、逻辑论证练习。

### 模板一：批判性思维训练
```
你是一位批判性思维教练。

请对以下观点进行批判性分析：

观点：{要分析的观点或论断}
来源：{出处}
上下文：{背景信息}

分析框架：
1. **论点识别**：核心主张是什么？前提是什么？
2. **逻辑检查**：推理过程是否有效？有无逻辑谬误？
3. **证据评估**：支撑证据是否充分？是否选择性引用？
4. **反面论证**：最强的反驳是什么？
5. **隐含假设**：有哪些未明说的前提假设？
6. **综合判断**：这个论证的说服力如何（1-10分）？为什么？

约束：
- 中立客观，不预设立场
- 区分"事实"和"观点"
- 标注每个判断的依据
- 给出改进论证的建议
```

### 模板二：学术论文写作辅导
```
你是一位学术写作导师。

请辅导我撰写{论文类型}论文：

学科领域：{领域}
研究主题：{主题}
当前阶段：{选题/文献综述/研究设计/数据分析/撰写/修改}

请提供：
1. 当前阶段的具体指导
2. 常见问题和避免方法
3. 质量自检清单
4. 下一步行动建议

约束：
- 遵循学术规范
- 引用格式建议使用{APA/MLA/GB-T7714}
- 强调原创性和学术诚信
- 不代替写作，提供方法论指导
```

## 七、知识卡片与记忆辅助

### 适用场景
将知识点转化为高效记忆卡片、思维导图、知识图谱。

### 模板
```
请将以下知识转化为高效的记忆卡片：

知识内容：{知识点描述}
记忆目标：{考试/长期记忆/快速回顾}
卡片类型：{问答型/填空型/判断型/混合}

请生成{数量}张卡片，每张卡片包含：
- 正面：问题/提示
- 背面：答案/解释
- 助记法：{口诀/联想/类比}
- 复习提示：{何时复习}

约束：
- 每张卡片只包含一个知识点（原子化）
- 问题要具体，能触发主动回忆
- 答案简洁，不超过2句话
- 助记法优先使用图像联想

输出格式：
### 卡片 1
**Q**：{问题}
**A**：{答案}
**💡 助记**：{助记方法}
**📅 复习**：{建议间隔}
```

## 八、使用技巧

| 技巧 | 说明 |
|------|------|
| 指定学习阶段 | 告诉 AI 你的水平，避免内容过难或过易 |
| 要求解释后出题 | 学完一个概念后立即出题检验，巩固记忆 |
| 使用苏格拉底式 | 让 AI 用提问引导而非直接给答案，理解更深 |
| 追问"为什么" | 对 AI 的解释追问原因，迫使其更深入 |
| 模拟真实场景 | 语言学习时设定具体场景，比纯对话更有效 |
| 间隔复习提醒 | 让 AI 按1/3/7/14天间隔安排复习 |

## 九、常见问题 FAQ

| 问题 | 解答 |
|------|------|
| AI 教的知识可靠吗？ | AI 可能有"幻觉"，关键概念务必对照权威教材验证 |
| 如何避免 AI 直接给答案？ | 在提示词中明确要求"不直接给答案，用提问引导" |
| 语言学习如何练口语？ | 用语音对话模式，设定情景，要求 AI 纠正发音和语法 |
| 如何让出题更贴近真题？ | 提供2-3道真题样例，让 AI 模仿风格和难度 |
| 小学生可以用吗？ | 可以，但需降低复杂度，指定"用10岁小孩能懂的语言" |
| 如何评估学习效果？ | 让 AI 出测试题 + 要求学习者用自己的话复述（费曼技巧） |
