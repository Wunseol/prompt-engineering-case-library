## 一、课程大纲设计

<small style="color:#888">适用场景：设计完整课程的大纲，含模块划分、教学目标、时长安排和教学方式。</small>

<small style="color:#888">提示词：</small>

**你是一位教学设计专家，擅长设计以学习者为中心、目标导向的课程体系。**

**请设计以下课程的大纲：**

**课程名称：{课程名称}**
**目标学员：{学员画像（年龄/背景/前置知识）}**
**总课时：{数量}课时，每课时{分钟}分钟**
**课程目标：{学完能达到什么水平/能力}**
**教学环境：{线下/线上/混合}**
**课程性质：{必修/选修/培训/兴趣}**

**请提供：**
1. 课程总体目标（按布鲁姆教育目标分类法：认知/技能/情感）
2. 模块划分（每模块的主题、目标、时长、教学方式）
3. 模块间的逻辑关系（递进/并列/螺旋）
4. 每模块的核心知识点和技能点
5. 教学方式建议（讲授/讨论/实践/项目）
6. 课程评估方式概览
7. 所需教学资源清单

**约束：**
- 目标要具体可衡量（避免"了解""掌握"等模糊词）
- 模块难度循序渐进，有合理梯度
- 理论与实践时间比例合理（建议实践≥40%）
- 兼顾不同学习风格（视觉/听觉/动觉）
- 预留复习和答疑时间
- 标注每模块的"前置模块"

**输出格式：**
## 课程总体目标
- 认知目标：{学完知道什么}
- 技能目标：{学完能做什么}
- 情感目标：{学完的态度/价值观变化}

## 课程大纲
| 模块 | 主题 | 教学目标 | 课时 | 教学方式 | 前置模块 |
|------|------|---------|------|---------|---------|

## 模块详解
### 模块1：{名称}（{课时}课时）
- 核心知识点：{列出}
- 核心技能点：{列出}
- 教学方式：{说明}
- 评估方式：{说明}
- 教学资源：{列出}

### 模块2：{名称}
...

## 模块逻辑关系
```
模块1（基础）→ 模块2（进阶）→ 模块3（应用）→ 模块4（综合）
```

## 评估方式概览
| 类型 | 方式 | 占比 | 时间节点 |
|------|------|------|---------|

## 教学资源清单
| 资源类型 | 说明 | 用途 |
|---------|------|------|

## 二、教案设计

<small style="color:#888">适用场景：设计单节课的详细教案，含教学目标、导入、讲解、练习、反馈等环节。</small>

<small style="color:#888">提示词：</small>

**你是一位资深教案设计师，擅长设计结构完整、互动充分的高质量单课教案。**

**请设计以下课程的详细教案：**

**课程名称：{课程名称}**
**本次课题：{本节课主题}**
**所属模块：{在大纲中的位置}**
**课时：{时长}分钟**
**学员画像：{人数/年龄/水平/特点}**
**教学环境：{教室/实验室/线上}**
**教学重点：{必须掌握的内容}**
**教学难点：{学员易混淆/难理解的内容}**

**请提供完整的教案，包含：**
1. 教学目标（认知+技能+情感，可衡量）
2. 教学重难点及突破策略
3. 教学流程（含时间分配）：
   - 课前准备
   - 导入（激发兴趣，5-10分钟）
   - 新知讲解（核心内容）
   - 练习活动（动手实践）
   - 反馈与纠错
   - 总结与作业
4. 板书/PPT结构设计
5. 课堂互动设计（提问、讨论点）
6. 作业设计（分层作业）
7. 教学反思预设（可能的卡点）

**约束：**
- 每个环节标注具体时长，总和等于课时
- 讲解不超过总时长的40%，练习互动≥40%
- 导入要有趣味性或冲突感，快速抓住注意力
- 设计至少3个不同层次的问题（基础/进阶/挑战）
- 作业要分层（必做/选做/拓展）
- 考虑可能的教学意外和应对方案

**输出格式：**
## 教案：{课题}

### 一、教学目标
- 认知目标：{可衡量的目标}
- 技能目标：{可衡量的目标}
- 情感目标：{可衡量的目标}

### 二、重难点
| 重点 | 突破策略 |
|------|---------|
| 难点 | 化解策略 |

### 三、教学流程
| 环节 | 时长 | 教师活动 | 学生活动 | 设计意图 |
|------|------|---------|---------|---------|
| 导入 | {x}min | | | |
| 讲解 | {x}min | | | |
| 练习 | {x}min | | | |
| 反馈 | {x}min | | | |
| 总结 | {x}min | | | |

### 四、详细环节设计
#### 导入（{x}分钟）
- 方式：{情境/问题/故事/演示}
- 具体操作：{步骤}
- 预设学员反应：{说明}

#### 新知讲解（{x}分钟）
- 知识点1：{内容} —— 讲解方式：{说明}
- 知识点2：{内容} —— 讲解方式：{说明}

#### 练习活动（{x}分钟）
- 活动：{名称}
- 步骤：{1-2-3}
- 巡视重点：{关注什么}

### 五、板书/PPT结构
```
{板书布局示意}
```

### 六、课堂提问设计
| 层次 | 问题 | 目的 |
|------|------|------|
| 基础 | | 检验理解 |
| 进阶 | | 促进应用 |
| 挑战 | | 拓展思维 |

### 七、作业设计
| 层次 | 内容 | 目的 |
|------|------|------|
| 必做 | | 巩固基础 |
| 选做 | | 提升能力 |
| 拓展 | | 挑战拔高 |

- 可能卡点：{说明} → 应对：{方案}

## 三、教学活动设计

<small style="color:#888">适用场景：设计小组讨论、角色扮演、案例研究、游戏化等多样化教学活动。</small>

<small style="color:#888">提示词：</small>

**你是一位教学活动设计专家，擅长设计高参与度、促发深度学习的课堂活动。**

**请为以下教学需求设计活动：**

**课程/主题：{课程名称和主题}**
**活动目的：{达成什么教学目标}**
**活动类型偏好：{小组讨论/角色扮演/案例研究/游戏化/项目式/不限}**
**学员人数：{人数}**
**可用时间：{分钟}**
**场地条件：{教室/可移动桌椅/实验室/线上}**
**学员特点：{年龄/水平/活跃度}**

**请提供3种不同类型的活动设计，每个活动包含：**
1. 活动名称和类型
2. 教学目标对应（达成什么目标）
3. 适用人数和时长
4. 所需材料/道具
5. 详细操作步骤（教师如何组织、学员如何参与）
6. 分组方式建议
7. 互动和反馈机制
8. 评估方式（如何检验活动效果）
9. 常见问题与应对

**约束：**
- 活动要紧扣教学目标，不为热闹而热闹
- 操作步骤要具体到可执行，避免"让学生讨论"这种笼统描述
- 考虑时间可控性，给出时间节点
- 兼顾内向学员的参与机会
- 线上活动要考虑工具适配（如分组讨论室）
- 标注每个活动的"风险点"

**输出格式：**
## 活动1：{名称}（{类型}）

### 基本信息
| 项 | 说明 |
|------|------|
| 目标 | {对应教学目标} |
| 人数 | {人数} |
| 时长 | {分钟} |
| 材料 | {道具/资源} |
| 场地 | {要求} |

### 操作步骤
| 步骤 | 时长 | 教师动作 | 学员动作 |
|------|------|---------|---------|
| 1 准备 | {x}min | | |
| 2 进行 | {x}min | | |
| 3 分享 | {x}min | | |
| 4 总结 | {x}min | | |

### 分组方式
{建议}

### 互动与反馈
- 机制：{说明}
- 教师介入时机：{说明}

### 评估方式
{如何检验效果}

### 风险与应对
| 风险 | 应对 |
|------|------|

## 活动2：{名称}
...

## 活动3：{名称}

## 四、评估方案设计

<small style="color:#888">适用场景：设计形成性评估、总结性评估和评分量规（rubric），科学衡量学习成效。</small>

<small style="color:#888">提示词：</small>

**你是一位教育评估专家，擅长设计多元化的学习评估方案和科学的评分量规。**

**请为以下课程设计评估方案：**

**课程名称：{课程名称}**
**课程目标：{认知/技能/情感目标}**
**课程时长：{总课时}**
**学员人数：{人数}**
**评估目的：{改进教学/评定成绩/认证能力}**
**已有评估方式：{如有，列出}**

**请提供：**
1. 评估体系总览（形成性+总结性，占比合理）
2. 形成性评估方案（过程性评估，至少3种方式）
3. 总结性评估方案（期末/结业评估）
4. 核心评估任务的评分量规（rubric）
5. 评估结果反馈机制
6. 学员自评和互评设计
7. 评估与教学目标的对应关系

**约束：**
- 评估方式要覆盖认知、技能、情感三维目标
- 评分量规要具体到可操作（每个等级有清晰描述）
- 形成性评估占比不低于40%
- 避免单一依赖纸笔测试
- 评估要公平，照顾不同背景学员
- 量规等级建议4级（优秀/良好/合格/待改进）

**输出格式：**
## 评估体系总览
| 类型 | 方式 | 占比 | 时间节点 | 评估目标 |
|------|------|------|---------|---------|
| 形成性 | {方式} | {x}% | {何时} | {目标} |
| 总结性 | {方式} | {x}% | {何时} | {目标} |

## 形成性评估方案
### 方式1：{名称}
- 目的：{说明}
- 频率：{多久一次}
- 形式：{具体怎么做}
- 反馈：{如何反馈给学员}

## 总结性评估方案
### {期末项目/考试/作品}
- 形式：{说明}
- 时长：{说明}
- 覆盖目标：{说明}

## 评分量规（核心任务：{任务名称}）
| 维度 | 优秀(4) | 良好(3) | 合格(2) | 待改进(1) |
|------|---------|---------|---------|----------|
| 内容 | {描述} | {描述} | {描述} | {描述} |
| 结构 | | | | |
| 表达 | | | | |
| 创新 | | | | |

## 评估-目标对应表
| 教学目标 | 评估方式 | 评估维度 |

- 反馈频率：{说明}

## 五、差异化教学

<small style="color:#888">适用场景：针对不同水平学员设计分层教学、个别化方案和特殊需求支持。</small>

<small style="color:#888">提示词：</small>

**你是一位差异化教学专家，擅长为不同水平和需求的学习者设计个性化教学方案。**

**请为以下班级设计差异化教学方案：**

**课程名称：{课程名称}**
**学员构成：{人数、年龄、水平差异}**
**水平差异描述：{如部分零基础、部分有基础、个别拔尖}**
**特殊需求：{如有学习障碍/超常/语言障碍/ADHD等}**
**可用资源：{助教/设备/时间}**
**教学目标：{统一目标或分层目标}**

**请提供：**
1. 学员分层方案（分层标准和各组特点）
2. 分层教学目标（基础组/进阶组/挑战组）
3. 分层教学活动设计（同一课堂如何兼顾不同层次）
4. 分层作业和评估
5. 个别化支持方案（针对特殊需求学员）
6. 教师课堂管理策略（如何同时照顾多组）
7. 进阶/帮扶机制（如何让学员流动调整层次）

**约束：**
- 分层要基于客观标准，避免标签化
- 分层不等于降级，每层都有成长空间
- 课堂活动设计要可同时操作（教师分身有术）
- 特殊需求方案要具体可行
- 保护学员自尊，避免"差生"标签
- 定期评估分层是否合理，允许调整

**输出格式：**
## 学员分层方案
| 层次 | 标准 | 特点 | 占比 | 支持重点 |
|------|------|------|------|---------|
| A基础组 | {标准} | {特点} | {x}% | {重点} |
| B进阶组 | {标准} | {特点} | {x}% | {重点} |
| C挑战组 | {标准} | {特点} | {x}% | {重点} |

## 分层教学目标
| 层次 | 认知目标 | 技能目标 |
|------|---------|---------|

## 同堂分层教学设计
### 环节：{名称}（{时长}）
| 层次 | 学习任务 | 教师支持 | 材料 |
|------|---------|---------|------|
| A基础组 | {任务} | {支持} | {材料} |
| B进阶组 | {任务} | {支持} | {材料} |
| C挑战组 | {任务} | {支持} | {材料} |

## 分层作业
| 层次 | 必做 | 选做 | 拓展 |
|------|------|------|------|

## 个别化支持
### 学员类型：{特殊需求}
- 困难：{说明}
- 调整方案：{具体措施}
- 评估调整：{如何公平评估}

## 课堂管理策略
- 分组策略：{说明}
- 时间分配：{如何兼顾各组}
- 助教配合：{如有}

## 流动调整机制
- 评估周期：{多久评估一次}
- 调整标准：{升级/降级依据}
- 沟通方式：{如何与学员沟通}

## 六、在线课程设计

<small style="color:#888">适用场景：设计在线课程的视频脚本、互动环节和社区运营，提升线上学习体验。</small>

<small style="color:#888">提示词：</small>

**你是一位在线课程设计专家，擅长打造高完课率、强互动的线上学习体验。**

**请为以下在线课程设计方案：**

**课程名称：{课程名称}**
**平台形式：{录播/直播/混合/MOOC}**
**目标学员：{学员画像}**
**课程时长：{总时长，单节时长}**
**学员规模：{人数}**
**课程目标：{学完能达到什么}**
**可用工具：{如学习管理系统/弹幕/讨论区/直播工具}**

**请提供：**
1. 单节课的视频脚本设计（含分段、互动点）
2. 互动环节设计（弹题、讨论、小测等）
3. 学习社区运营方案
4. 防流失和促完课策略
5. 线上评估方案
6. 技术工具使用建议
7. 线上学习常见问题应对

**约束：**
- 单段视频不超过8-10分钟（注意力曲线）
- 每3-5分钟设置一个互动点
- 互动要低门槛、易参与
- 社区运营要有明确的节奏和激励机制
- 考虑学员自律性差异，设计督促机制
- 兼顾不同设备和网络条件

| 4:00-7:00 | 知识点2 | {画面} | {旁白} | {讨论} |
| 7:00-8:00 | 总结 | {画面} | {旁白} | {小测} |

| 讨论 | {何时} | {讨论区话题} | 深度思考 |

## 使用技巧

| 技巧 | 说明 |
|------|------|
| 用布鲁姆分类法 | 教学目标用"能列举/能分析/能创造"等可衡量动词 |
| 理论实践平衡 | 讲解不超过40%，保证充足的练习互动时间 |
| 设计分层作业 | 必做+选做+拓展，照顾不同水平学员 |
| 量规先行 | 评估前先给学员看评分量规，明确期望 |
| 预设教学卡点 | 教案中预设学员可能的困难及应对方案 |
| 单课聚焦 | 一节课重点不超过3个，避免贪多嚼不烂 |
| 互动低门槛 | 线上互动设计要易参与，降低学员心理负担 |
| 定期差异化调整 | 根据学员进展动态调整分层，不固定标签 |

## 常见问题 FAQ

| 问题 | 解答 |
|------|------|
| AI 设计的教案能直接用吗？ | 可作为框架参考，但需结合实际学情和教学风格调整 |
| 如何让教学目标可衡量？ | 用布鲁姆动词（列举/分析/设计）替代"了解/掌握" |
| 课堂活动冷场怎么办？ | 设计低门槛问题预热，先让学员两两讨论再公开分享 |
| 差异化教学会不会加重负担？ | 初期设计成本高，但可复用；借助助教和学员互助分担 |
| 在线课程完课率低怎么办？ | 缩短视频、增加互动、设计社区激励和督促机制 |
| 评估量规太复杂怎么办？ | 维度控制在4-5个，每级描述简明，必要时给范例 |
| 如何兼顾不同学习风格？ | 同一知识点用讲授+视觉+动手多种方式呈现 |
| AI 能设计所有学科教案吗？ | 通用结构可以，但学科特色内容需教师专业判断补充 |
