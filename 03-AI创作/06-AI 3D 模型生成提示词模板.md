## 一、几何形状与拓扑描述

<small style="color:#888">适用场景:需要精确控制模型几何结构、面数预算、拓扑流线和 LOD 层级的场景,适用于游戏资产、3D 打印、AR/VR 等对几何精度有要求的建模任务。</small>

<small style="color:#888">提示词(基础几何组合建模):</small>

**[OBJECT_TYPE]: {物体类型}, {整体形态描述}**
**[BASE_GEOMETRY]: composed of {基础几何体1}, {基础几何体2}, {基础几何体3}, combined via {布尔运算/融合方式}**
**[DIMENSIONS]: {长} x {宽} x {高} in {单位}, proportions {比例描述}**
**[TOPOLOGY]: {四边形面/三角面/混合}, edge flow following {拓扑流线方向}, {均匀分布/疏密过渡}**
**[POLY_COUNT]: target {面数预算} polygons, LOD{级别} standard, {高模/低模} specification**
**[SYMMETRY]: {对称轴描述}, {镜像对称/径向对称/不对称}**
**[DETAIL_LEVEL]: {细节等级}, {硬表面/有机曲面} predominant**
**[REFERENCES]: {参考图片描述}, view from {正视图/侧视图/俯视图}**

<small style="color:#888">填充示例:</small>

**[OBJECT_TYPE]: a medieval stone fountain, cylindrical central column with basin**
**[BASE_GEOMETRY]: composed of a wide cylinder basin, a tapered cylinder column, and a sphere finial on top, combined via smooth boolean union**
**[DIMENSIONS]: 3.0m x 3.0m x 2.4m in meters, proportions basin diameter : height = 5:4**
**[TOPOLOGY]: quad-dominant mesh, edge flow following vertical column loops, even distribution with denser loops at carved details**
**[POLY_COUNT]: target 12000 polygons, LOD1 standard, low-mid poly specification for real-time rendering**
**[SYMMETRY]: radial symmetry on Y axis (8-fold), mirror symmetric front/back**
**[DETAIL_LEVEL]: medium detail, hard surface predominant with carved ornament zones**
**[REFERENCES]: Romanesque garden fountain, view from front 3/4 angle**

<small style="color:#888">提示词(复杂拓扑与流线控制):</small>

**[OBJECT]: {复杂物体描述}**
**[TOPOLOGY_FLOW]: edge loops following { anatomical/structural } flow, {环线走向描述}, {极点位置}**
**[CREASES_AND_HARDSURFACE]: support loops at {硬边位置}, {倒角半径}, {锐利边缘/圆滑边缘}**
**[POLE_MANAGEMENT]: poles located at {极点位置}, minimized to {数量}, hidden in {隐藏区域}**
**[LOD_STRATEGY]: LOD0 {最高面数}, LOD1 {面数}, LOD2 {面数}, LOD3 {最低面数} for {距离/平台}**
**[OPTIMIZATION]: {删除内部面/合并顶点/简化背面}, {烘焙法线贴图来源}**

<small style="color:#888">💡 拓扑提示要点:明确对称轴、指出极点位置、说明边缘流线方向,有助于生成可动画化、可细分的优质网格。</small>

## 二、纹理与材质控制

<small style="color:#888">适用场景:需要精确控制模型表面材质质感、PBR 参数、UV 布局和贴图分辨率的场景,适用于产品可视化、游戏资产、影视道具等对材质真实度有要求的任务。</small>

<small style="color:#888">提示词(PBR 材质定义):</small>

**[MATERIAL_TYPE]: {材质类别}, {材质子类}**
**[BASE_COLOR]: {基础色/Albedo}, {色值或描述}, {色彩变化范围}**
**[METALLIC]: {金属度 0.0-1.0}, {金属/非金属判定}**
**[ROUGHNESS]: {粗糙度 0.0-1.0}, {光滑/磨砂/粗糙}, {表面磨损分布}**
**[NORMAL_MAP]: {法线贴图细节}, {凹凸程度}, {微观细节类型(划痕/颗粒/纹路)}**
**[SPECULAR]: {高光强度}, {高光颜色}, {F0 反射率}**
**[AO]: {环境光遮蔽强度}, {缝隙暗部程度}**
**[EMISSIVE]: {自发光颜色}, {自发光强度}, {是否启用}**
**[TEXTURE_RESOLUTION]: {贴图分辨率}, {PBR 贴图集/独立通道}**
**[UV_LAYOUT]: {UV 展开方式}, {UV 岛数量}, {接缝位置}, {像素密度}**

<small style="color:#888">填充示例:</small>

**[MATERIAL_TYPE]: weathered oak wood, plank surface with grain**
**[BASE_COLOR]: warm brown #6B4423, with darker grain lines and lighter sapwood streaks**
**[METALLIC]: 0.0, fully non-metallic**
**[ROUGHNESS]: 0.75 average, smoother on polished areas, rougher on weathered cracks**
**[NORMAL_MAP]: deep wood grain grooves, fine surface fibers, occasional knots and nail holes**
**[SPECULAR]: low intensity, neutral white highlights, F0 around 0.04**
**[AO]: strong occlusion in plank gaps and knot recesses**
**[EMISSIVE]: none, disabled**
**[TEXTURE_RESOLUTION]: 2048x2048, packed PBR set (BC+MRA+N)**
**[UV_LAYOUT]: automatic unwrap with 4 UV islands, seams at plank edges, 1024px/m density**

<small style="color:#888">提示词(多材质混合与贴图集):</small>

**[MULTI_MATERIAL]: {物体} consists of {材质1} on {区域1}, {材质2} on {区域2}, {材质3} on {区域3}**
**[MATERIAL_BLEND]: {硬边过渡/渐变过渡/蒙版混合}, {过渡宽度}**
**[WEAR_AND_TEAR]: {磨损位置}, {边缘掉漆程度}, {锈迹分布}, {污渍类型}**
**[TEXTURE_ATLAS]: {图集尺寸}, {材质 ID 通道}, {共享贴图/独立贴图}**
**[TILING]: {平铺次数}, {无缝贴图/独占贴图}, {方向性}**

<small style="color:#888">💡 材质关键词速查:wood(木)/stone(石)/metal(金属)/fabric(布料)/glass(玻璃)/ceramic(陶瓷)/leather(皮革)/concrete(混凝土)/marble(大理石)/rust(锈蚀)</small>

## 七、使用技巧

| 技巧 | 说明 |
|------|------|
| 提供参考图片 | 上传多角度参考图(正视图/侧视图/俯视图/3/4 视图),AI 能更准确还原形态,尤其是复杂角色和生物,纯文本描述难以传递精确比例 |
| 分部位分层描述 | 将模型拆分为多个部件分别描述(如角色拆为头部/躯干/四肢/服装/配饰),再说明组合关系,优于笼统的整体描述,细节可控性更强 |
| 指定面数与 LOD | 明确目标面数预算(如 LOD0=50000、LOD1=20000、LOD2=8000)和适用平台(移动端/PC/主机),有助于生成符合性能预算的资产 |
| 使用 PBR 专业术语 | 用 metallic/roughness/normal/AO/F0 等标准 PBR 术语描述材质,而非笼统的"金属感""磨砂感",生成的材质更准确且可直接用于引擎 |
| 多角度生成与验证 | 生成后从正视图、侧视图、俯视图、背面、3/4 视图分别检查模型,发现变形或拓扑问题及时迭代修正,避免单视角盲区 |
| 迭代优化策略 | 首轮用简洁提示词出草图,二轮针对不足补充细节描述,三轮微调材质与拓扑,逐步收敛至目标,优于一次性追求完美 |
| 善用对称性约束 | 对称物体(器皿、建筑、机械零件)明确声明对称轴和对称类型(镜像/径向),可显著提升拓扑规整度和生成效率 |
| 区分高模与低模 | 高模用于烘焙法线/AO 贴图,低模用于实时渲染,提示词中分开描述两者,并说明烘焙关系,符合标准游戏资产生成流程 |
| 指定 UV 与贴图策略 | 明确 UV 展开方式(自动/手动)、UV 岛数量、接缝位置、像素密度(px/m)和贴图分辨率(1024/2048/4096),避免后续返工 |
| 检查比例尺一致性 | 场景中多个资产应使用统一比例尺(如 1 单位=1 米)和参照物(如 1.8m 人物),提示词中声明,确保资产间比例协调 |

## 八、常见问题 FAQ

| 问题 | 解答 |
|------|------|
| AI 生成的 3D 模型能商用吗? | 取决于所用工具的许可协议。Meshy、Tripo3D 等付费计划通常允许商用,免费计划多为个人学习用途;另外需注意训练数据来源的版权风险,商业项目建议人工二次检查和修改拓扑后再使用 |
| 如何提升拓扑质量? | 一是明确指定四边形主导(quad-dominant)和边缘流线方向;二是声明极点位置并最小化数量;三是要求对称性约束;四是生成后用 Blender/Maya 等工具做重拓扑(retopology)处理,尤其是角色面部和关节区域 |
| 纹理分辨率不够怎么办? | 在提示词中显式指定贴图分辨率(如 4096x4096)和 PBR 通道完整集(Albedo+Normal+Metallic+Roughness+AO);若仍不足,可对关键区域单独生成贴图集,或用 AI 放大工具(如 Topaz、Stable Diffusion img2img)提升已有贴图分辨率 |
| 能导入 Unity/UE 吗? | 可以。导出时选择 FBX 或 glTF/GLB 格式,确保骨骼、材质、贴图一并导出;导入 Unity 时注意材质需转为 Standard 或 URP/Lit Shader;导入 UE 时需转换 PBR 通道映射(Metallic/Roughness 与 UE 的 Metallic/Specular 对应);建议导出前在 Blender 中检查轴朝向和单位 |
| 如何做动画绑定? | AI 生成的模型多为静态网格,需在 DCC 软件(Blender/Maya)中手动或半自动绑定骨骼;提示词中可声明"rig-ready A-pose"使模型处于便于绑定的姿态;工具如 Mixamo、AccuRIG、Auto-Rig Pro 可加速自动绑定;面部表情需额外制作 blendshape 并烘焙 |
| 生成模型的面数过多影响性能怎么办? | 提示词中明确目标面数和 LOD 策略;对静态远景资产使用 LOD 链(LOD0/LOD1/LOD2/LOD3)按距离切换;利用法线贴图烘焙高模细节到低模,以低面数维持视觉细节;对不可见面做背面剔除优化 |
| 如何让多个模型风格统一? | 建立风格指南文档,统一色板、材质参数、面数预算、比例尺和渲染设置;每个模型提示词引用同一套风格关键词和参考图;建议生成一个基准模型后,其他模型以此为参照迭代,保持视觉一致性 |
| 角色模型为什么常出现畸形肢体? | 多因提示词中比例和姿态描述不清。建议:明确头身比和体型、指定 A-pose 或 T-pose、声明对称性、提供多角度参考图;生成后从多视角检查关节和四肢,畸形部分单独迭代修正 |
