## 一、风格描述与流派控制

<small style="color:#888">适用场景:需要指定音乐流派、年代感、节奏速度与调性,用于在 Suno/Udio/Stable Audio 中精准锁定整体音乐风格。</small>

**提示词模板(流派+速度+调性+年代感):**

**[GENRE]: {音乐风格},融合 {子风格/融合元素}**
**[TEMPO]: {BPM} BPM, {节奏型描述}**
**[KEY]: {调性} {大调/小调}**
**[ERA]: {年代感},参考 {参考年代/年代标签}**
**[MOOD]: {情绪氛围}, {情绪强度}**
**[INSTRUMENTATION]: {核心音色/标志性乐器}**
**[PRODUCTION]: {制作风格}, {质感描述}**
**[REFERENCE]: 风格参考 {参考艺人/乐队}(仅用于风格倾向,不复制具体作品)**

<small style="color:#888">填充示例(80年代合成器流行):</small>

**[GENRE]: synth-pop, new wave,融合 retro-futurism**
**[TEMPO]: 118 BPM, four-on-the-floor beat**
**[KEY]: A minor**
**[ERA]: 1980s, vintage analog warmth**
**[MOOD]: nostalgic, dreamy, mid-intensity**
**[INSTRUMENTATION]: analog synths, gated reverb snare, fretless bass**
**[PRODUCTION]: lush reverb, wide stereo, tape saturation**
**[REFERENCE]: 风格参考 a-ha, Depeche Mode(仅用于风格倾向)**

<small style="color:#888">流派关键词速查:</small>

| 流派 | 英文关键词 | 典型 BPM | 标志性元素 |
|------|-----------|---------|----------|
| 流行 | pop, pop-rock, electropop | 100-130 | 朗朗上口的旋律、合成器 |
| 摇滚 | rock, alt-rock, indie rock | 110-140 | 失真吉他、强力鼓组 |
| 电子 | EDM, house, techno, trance | 120-140 | 四四拍、合成器 bass |
| 古典 | classical, orchestral, neoclassical | 自由 | 弦乐组、钢琴、木管 |
| 爵士 | jazz, smooth jazz, bebop | 90-180 | 即兴、swing 节奏、铜管 |
| 民谣 | folk, indie folk, acoustic | 70-110 | 木吉他、口琴、叙事 |
| 说唱 | hip-hop, trap, boom bap | 70-160 | 808 鼓机、flow、采样 |
| R&B | R&B, neo-soul, funk | 80-110 | 律动 bass、和声 |
| 国风 | Chinese folk, guzheng pop | 70-120 | 古筝、笛子、五声音阶 |
| Lo-fi | lo-fi hip-hop, chillhop | 70-90 | 柔和鼓组、环境噪音 |

## 二、歌词生成与押韵

<small style="color:#888">适用场景:基于主题、情感与结构生成完整歌词,控制押韵方案与段落结构,适用于 Suno 的 Custom Mode 或独立 LLM 生成歌词后导入。</small>

**提示词模板(主题→结构化歌词):**

**[ROLE] 资深作词人,精通 {目标语言} 流行歌词创作,擅长 {押韵风格} 与情感叙事。**
**[THEME] 主题:{歌词主题},核心意象:{核心意象}**
**[EMOTION] 情感基调:{情感基调},情感走向:{起始情绪} → {高潮情绪} → {收束情绪}**
**[STRUCTURE] 段落结构:{Intro} → {Verse 1} → {Pre-Chorus} → {Chorus} → {Verse 2} → {Chorus} → {Bridge} → {Chorus} → {Outro}**
**[RHYME] 押韵方案:主歌 {AABB/ABAB},副歌 {押韵方案},桥段 {押韵方案}**
**[METER] 字数/音节:主歌每行 {字数} 字左右,副歌每行 {字数} 字左右**
**[CONSTRAINTS] 约束:{禁忌词/必须包含的词/重复 hook}**
**请按上述结构生成完整歌词,副歌需有记忆点(hook),每段标注段落名。**

<small style="color:#888">填充示例(思乡主题华语流行):</small>

**[ROLE] 资深作词人,精通华语流行歌词创作,擅长 AABB 押韵与画面感叙事。**
**[THEME] 主题:异乡漂泊的思乡之情,核心意象:老家的窗、母亲的饭香**
**[EMOTION] 情感基调:忧伤而温暖,情感走向:孤独 → 渴望 → 释然**
**[STRUCTURE] 段落结构:Verse 1 → Pre-Chorus → Chorus → Verse 2 → Chorus → Bridge → Chorus → Outro**
**[RHYME] 押韵方案:主歌 AABB,副歌 ABAB,桥段自由**
**[METER] 字数/音节:主歌每行 8 字左右,副歌每行 10 字左右**
**[CONSTRAINTS] 约束:不出现具体地名,副歌需重复"回家"二字**
**请按上述结构生成完整歌词,副歌需有记忆点(hook),每段标注段落名。**

<small style="color:#888">押韵方案速查:</small>

| 方案 | 模式 | 适用 | 示例 |
|------|------|------|------|
| AABB | 两两押韵 | 民谣、轻快流行 | light/night, day/play |
| ABAB | 交替押韵 | 流行、抒情 | go/know, far/star |
| AAAA | 连续押韵 | 说唱、强节奏 | run/fun/sun/done |
| ABCB | 单押尾韵 | 民谣、叙事 | high/sky/walk/talk |
| 自由 | 不押韵/暗韵 | 摇滚、艺术摇滚 | 强调节奏与意象 |

## 三、编曲与乐器配置

<small style="color:#888">适用场景:控制歌曲的乐器选择、配器层次与段落编排,设计前奏/间奏/尾奏,适用于需要精细控制编曲走向的场景。</small>

**提示词模板(分段配器+段落编排):**

**[ARRANGEMENT] 编曲方案:{音乐风格} 编曲,总时长约 {时长}**
**[INSTRUMENTS] 核心乐器配置:**
**- 节奏组:{鼓组描述}, {贝斯描述}**
**- 和声组:{和声乐器1}, {和声乐器2}**
**- 旋律组:{主奏乐器}, {副奏乐器}**
**- 点缀组:{装饰性乐器/音效}**
**[LAYERING] 配器层次(由疏到密):**
**- 前奏:{乐器配置}**
**- 主歌 1:{乐器配置}(留白,突出人声)**
**- 副歌:{乐器配置}(全编制,能量顶点)**
**- 间奏:{乐器配置}(独奏/过渡)**
**- 桥段:{乐器配置}(变化/反差)**
**- 尾奏:{乐器配置}(渐弱/收束)**
**[DYNAMICS] 动态走向:{起始力度} → {高潮力度} → {收束力度}**
**[SPECIAL] 特殊设计:{转调/变速/停顿/合成器音效}**

<small style="color:#888">填充示例(抒情流行钢琴 ballad):</small>

**[ARRANGEMENT] 编曲方案:抒情流行 ballad 编曲,总时长约 3:45**
**[INSTRUMENTS] 核心乐器配置:**
**- 节奏组:轻柔 brush 鼓组, warm finger-style bass**
**- 和声组:grand piano, warm pad**
**- 旋律组:lead violin,electric guitar(clean tone)**
**- 点缀组:音乐盒音效、风铃、环境 pad**
**[LAYERING] 配器层次(由疏到密):**
**- 前奏:钢琴独奏 + 音乐盒**
**- 主歌 1:钢琴 + bass + 轻鼓(突出人声)**
**- 副歌:全编制,加入弦乐与电吉他(能量顶点)**
**- 间奏:小提琴独奏 + 钢琴伴奏**
**- 桥段:仅钢琴 + 弦乐(反差,弱化鼓组)**
**- 尾奏:钢琴渐弱 + 音乐盒收束**
**[DYNAMICS] 动态走向:pp(很弱) → ff(很强) → pp(渐弱)**
**[SPECIAL] 特殊设计:副歌后转调升半音,桥段前 1 小节完全停顿**

## 四、人声音色与情感控制

<small style="color:#888">适用场景:控制演唱者性别、音色特质、演唱技法与情感表达,适用于 Suno/Udio 中塑造特定人声形象。</small>

**提示词模板(音色+技法+情感):**

**[VOCAL] 人声设定:**
**- 性别:{男声/女声/童声/中性}**
**- 年龄感:{年龄感描述}**
**- 音色:{音色描述,如沙哑/清澈/温暖/空灵/磁性}**
**- 音域:{音域范围,如中低音/高音/假声}**
**[TECHNIQUE] 演唱技法:**
**- 咬字:{咬字风格,如清晰/慵懒/有力}**
**- 气声:{气声比例,如纯气声/实声为主/混合}**
**- 装饰音:{颤音/转音/滑音/怒音}**
**- 转换:{真假声转换/混声}**
**[EMOTION] 情感表达:**
**- 基调:{激昂/忧伤/平静/甜蜜/愤怒/释然}**
**- 走向:{起始情感} → {发展情感} → {高潮情感}**
**- 强度:{弱/中/强},副歌需 {增强方式}**
**[REFERENCE] 参考音色倾向:{参考歌手}(仅用于音色倾向,不模仿具体作品)**

<small style="color:#888">填充示例(温暖治愈女声):</small>

**[VOCAL] 人声设定:**
**- 性别:女声**
**- 年龄感:25-30 岁,成熟而温柔**
**- 音色:温暖、略带气声、清澈不刺耳**
**- 音域:中音区为主,副歌升至高音区**
**[TECHNIQUE] 演唱技法:**
**- 咬字:清晰、略带慵懒**
**- 气声:混合,副歌增加气声比例**
**- 装饰音:句尾轻微颤音、副歌转音**
**- 转换:副歌高音区使用混声**
**[EMOTION] 情感表达:**
**- 基调:温暖、治愈、带一丝忧伤**
**- 走向:诉说感 → 渴望 → 释然温暖**
**- 强度:中,副歌通过音域上扬和气声增强感染力**
**[REFERENCE] 参考音色倾向:陈绮贞、田馥甄(仅用于音色倾向)**

<small style="color:#888">音色关键词速查:</small>

| 维度 | 关键词 | 效果 |
|------|--------|------|
| 质感 | husky, raspy, gritty | 沙哑、有颗粒感 |
| 质感 | clear, pure, crystalline | 清澈、纯净 |
| 质感 | warm, mellow, velvety | 温暖、醇厚 |
| 质感 | airy, breathy, ethereal | 空灵、气声 |
| 质感 | powerful, belting, soaring | 有力量、穿透 |
| 技法 | falsetto, head voice | 假声、头声 |
| 技法 | vibrato, melisma | 颤音、转音 |
| 技法 | growl, vocal fry | 怒音、气泡音 |

## 五、混音与母带建议

<small style="color:#888">适用场景:为 AI 生成音乐的后期处理提供混音与母带方向,控制声场、频段、动态与响度,适用于 Stable Audio 输出后的人工精修或二次加工指导。</small>

**提示词模板(声场+频段+动态+响度):**

**[MIX_DIRECTION] 混音方向:{整体风格,如现代流行/复古模拟/电子清晰}**
**[STEREO_FIELD] 声场布局:**
**- 中间:{人声/底鼓/贝斯/snare}**
**- 左右:{和声/吉他/键盘}**
**- 纵深(前后):{前景元素} | {中景元素} | {背景元素}**
**[FREQUENCY] 频段平衡:**
**- 低频(20-250Hz):{低频处理,如紧实/饱满/切除浑浊}**
**- 中低频(250-500Hz):{处理方式,避免浑浊}**
**- 中频(500-2kHz):{人声清晰度处理}**
**- 中高频(2-6kHz):{亮度/刺耳频率处理}**
**- 高频(6-20kHz):{空气感/齿音处理}**
**[DYNAMICS] 动态范围:**
**- 整体动态:{压缩程度,如重度压缩/适度/保留动态}**
**- 人声压缩:{阈值/比率/启动释放}**
**- 鼓组处理:{平行压缩/瞬态增强}**
**[LOUDNESS] 响度标准:**
**- 目标响度:{-14 LUFS 流媒体 / -9 LUFS 响亮 / -23 LUFS 广播}**
**- 真实峰值:{-1 dBTP / -0.5 dBTP}**
**[EFFECTS] 效果器建议:**
**- 人声:{混响类型/延迟/和声}**
**- 鼓组:{房间混响/板式混响}**
**- 总线:{总线压缩/饱和/限制器}**
**[MASTER] 母带目标:{最终质感描述,如响亮 punchy / 温暖 vintage / 透明 clean}**

<small style="color:#888">填充示例(现代流行流媒体母带):</small>

**[MIX_DIRECTION] 混音方向:现代流行,清晰通透,人声突出**
**[STEREO_FIELD] 声场布局:**
**- 中间:主唱、底鼓、贝斯、snare**
**- 左右:和声、节奏吉他、合成器铺底**
**- 纵深:前景=主唱+底鼓 | 中景=乐器组 | 背景=pad+环境混响**
**[FREQUENCY] 频段平衡:**
**- 低频(20-250Hz):紧实,切除 30Hz 以下浑浊**
**- 中低频(250-500Hz):适度衰减 300-400Hz 避免浑浊**
**- 中频(500-2kHz):人声 1-3kHz 提升 2dB 增强存在感**
**- 中高频(2-6kHz):控制 4kHz 附近齿音**
**- 高频(6-20kHz):10kHz 以上轻提升增加空气感**
**[DYNAMICS] 动态范围:**
**- 整体动态:适度压缩,保留音乐性**
**- 人声压缩:阈值 -18dB,比率 3:1,启动 5ms,释放 50ms**
**- 鼓组处理:平行压缩增强 punch**
**[LOUDNESS] 响度标准:**
**- 目标响度:-14 LUFS(流媒体标准)**
**- 真实峰值:-1 dBTP**
**[EFFECTS] 效果器建议:**
**- 人声:板式混响 1.8s + 1/4 节拍延迟 + 轻和声**
**- 鼓组:房间混响 0.8s**
**- 总线:温和总线压缩 2:1 + 限制器**
**[MASTER] 母带目标:响亮 punchy,透明 clean,适合流媒体播放**

## 六、多版本对比与迭代

<small style="color:#888">适用场景:基于同一基础提示词生成多个差异化版本进行 A/B 测试,根据反馈聚焦优化方向,持续迭代逼近目标效果。</small>

**提示词模板(多版本生成+对比+迭代):**

**[TASK] 基于"基础版本"生成 {N} 个差异化版本用于 A/B 对比。**
**[BASE_VERSION] 基础提示词:**
**{粘贴基础版本完整提示词}**
**[BASE_FEEDBACK] 基础版本反馈:**
**- 优点:{保留的优点}**
**- 不足:{需要改进的点}**
**[VARIANTS] 差异化版本要求:**
**- 版本 A:改变 {变量1,如 BPM/调性/风格},其他保持不变**
**- 版本 B:改变 {变量2,如人声音色/情感}**
**- 版本 C:改变 {变量3,如编曲/配器}**
**[COMPARE] 对比维度:**
**1. {维度1,如风格契合度}**
**2. {维度2,如人声自然度}**
**3. {维度3,如编曲层次}**
**4. {维度4,如情感传达}**
**[ITERATE] 迭代策略:**
**- 从 {N} 个版本中选出最优,记录 {保留要素}**
**- 下一轮针对 {待优化点} 微调**
**- 最多迭代 {迭代轮数} 轮,每轮只改 1-2 个变量**
**请输出 {N} 个版本的完整提示词,并标注每个版本的差异点。**

<small style="color:#888">填充示例(电子流行多版本对比):</small>

**[TASK] 基于"基础版本"生成 3 个差异化版本用于 A/B 对比。**
**[BASE_VERSION] 基础提示词:**
**[GENRE]: electropop, [TEMPO]: 120 BPM, [KEY]: C major, [VOCAL]: 女声清澈**
**[BASE_FEEDBACK] 基础版本反馈:**
**- 优点:节奏感强,副歌记忆点好**
**- 不足:人声偏机械,编曲层次单薄,缺乏高潮推进**
**[VARIANTS] 差异化版本要求:**
**- 版本 A:将 BPM 调至 128,风格改为 future bass,测试节奏张力**
**- 版本 B:人声改为沙哑磁性女声,情感走向由平静改为激昂**
**- 版本 C:编曲加入弦乐组与 build-up,副歌前增加 riser**
**[COMPARE] 对比维度:**
**1. 风格契合度(是否符合电子流行定位)**
**2. 人声自然度(是否像真人演唱)**
**3. 编曲层次(动态推进是否到位)**
**4. 情感传达(是否能引发共鸣)**
**[ITERATE] 迭代策略:**
**- 从 3 个版本中选出最优,记录保留要素**
**- 下一轮针对"人声机械感"微调,尝试增加气声与颤音描述**
**- 最多迭代 4 轮,每轮只改 1-2 个变量**
**请输出 3 个版本的完整提示词,并标注每个版本的差异点。**

## 七、使用技巧

| 技巧 | 说明 |
|------|------|
| 提供参考曲目 | 给出风格参考艺人/乐队(非具体作品),帮助 AI 锁定流派特征,比单纯堆砌关键词更精准 |
| 指定 BPM 和调性 | 明确写出 BPM 数值与调性(如 A minor),直接影响节奏感与情绪基调,避免 AI 随机选择 |
| 分层描述 | 按"风格 → 乐器 → 人声 → 情感"分层组织提示词,信息结构清晰,AI 解析更准确 |
| 使用音乐术语 | 用 four-on-the-floor、brush drum、parallel compression 等专业术语,获得更专业的输出 |
| 限制时长 | 明确指定总时长(如 3:30),控制歌曲结构与段落比例,避免 AI 生成过长或过短的作品 |
| 多版本生成 | 同一基础提示词生成 3-5 个版本对比,扩大采样空间,再从中筛选最优并迭代 |
| 显式标注段落结构 | 写明 Verse/Chorus/Bridge 等段落与顺序,AI 会按结构组织内容,避免段落混乱 |
| 控制变量迭代 | 每轮只改 1-2 个变量(如只改 BPM 或只改人声),便于定位效果差异的成因 |
| 正向描述优于负向 | 优先用"想要什么"引导,而非堆砌"不要什么",Suno/Udio 对负向描述支持有限 |
| 复用优质 seed | 记录生成满意版本的随机种子,后续在此基础上微调可保持风格一致性 |

## 八、常见问题 FAQ

| 问题 | 解答 |
|------|------|
| AI 生成的音乐版权归属? | 各平台规则不同:Suno 免费版生成的作品通常不可商用,付费版可商用;具体归属以平台条款为准。商用前务必查阅最新协议,并保留生成记录作为凭证 |
| 如何避免风格雷同? | 1)混搭 2-3 个子风格(如 synth-pop + retro-futurism);2)指定独特乐器或调性(如五声音阶 + 古筝);3)提供差异化的人声与情感描述;4)多版本生成后筛选 |
| 如何提升歌词质量? | 1)明确主题与情感走向;2)指定押韵方案与字数约束;3)要求副歌有 hook 记忆点;4)用 LLM 先生成歌词再导入音乐工具;5)加入禁忌词与必含词约束 |
| 人声不自然怎么办? | 1)增加音色描述维度(质感+技法+气声);2)指定演唱技法(颤音/混声/气声);3)降低情感强度避免"过度演唱";4)更换音色参考倾向;5)尝试不同性别/年龄设定 |
| 能做商用吗? | 取决于平台:多数平台付费订阅允许商用生成内容,但禁止生成与现有作品高度相似的"克隆"。商用前需确认:1)订阅状态;2)是否含版权音乐采样;3)当地法律法规 |
| AI 音乐能上 Spotify 吗? | 可以,但需:1)拥有商用授权;2)标注为 AI 生成(部分平台要求);3)避免侵犯现有版权;4)建议人工后期混音提升质量;5)遵守分发平台的 AI 内容政策 |
| 如何让副歌更有记忆点? | 1)歌词中加入重复的 hook 词或短语;2)指定副歌转调或升调;3)要求副歌音域上扬;4)配器全编制、能量顶点;5)加入和声与 gang vocal |
| 生成纯音乐(无人声)怎么做? | 在提示词中明确写"instrumental, no vocals",并用乐器独奏替代人声旋律线,指定前奏/间奏/尾奏的乐器编排 |
