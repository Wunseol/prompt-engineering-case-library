## 一、音色描述与角色塑造

<small style="color:#888">适用场景:有声书角色塑造、虚拟主播形象配音、广告旁白、游戏NPC配音、纪录片解说等需要明确声音人物形象的场景。</small>

<small style="color:#888">音色描述五要素:年龄 + 性别 + 音色特征 + 口音/方言 + 职业感/身份感</small>

| 要素 | 说明 | 示例关键词 |
|------|------|-----------|
| 年龄 | 声音所呈现的年龄段 | 童声、少年、青年、中年、老年 |
| 性别 | 男声/女声/中性 | 男性、女性、中性嗓音 |
| 音色特征 | 声音质感 | 沙哑、清澈、浑厚、甜美、磁性、清亮、低沉、空灵 |
| 口音/方言 | 地域特征 | 标准普通话、京腔、东北话、粤语、台普、英式英语、美式英语 |
| 职业感/身份感 | 角色身份 | 播音员、教师、老人、少年、御姐、萝莉、暖男、霸总 |

<small style="color:#888">提示词(详细音色描述模板):</small>

**[VOICE_IDENTITY] 音色身份:{年龄段} {性别},身份设定为{职业/角色身份},声音气质{气质描述,如沉稳/活泼/威严/亲和}。**

**[VOICE_TEXTURE] 音色质感:音色{音色特征,如沙哑/清澈/浑厚},音域偏{高音/中音/低音},共鸣感{强/中/弱},气息感{明显/适中/干净},嗓音{明亮/柔和/低沉}。**

**[VOICE_DETAIL] 细节特征:带有{口音/方言}口音,语速节奏{描述},咬字{清晰/含糊/有力},尾音{上扬/下沉/干脆},笑声特征{描述},呼吸节奏{描述}。**

**[VOICE_PERSONA] 人物背景:这位说话者{背景故事一句话,如常年播讲悬疑故事的中年男主播/在山区支教多年的女教师},因此说话时带有{情感底色,如沧桑感/温暖感/书卷气}。**

**[OUTPUT_FORMAT] 输出要求:使用{工具名称,如 ElevenLabs/Azure TTS} 生成,语言为{语言},采样率{采样率},输出格式{MP3/WAV}。**

<small style="color:#888">填充示例(磁性男声悬疑主播):</small>

**[VOICE_IDENTITY] 音色身份:中年男性,身份设定为悬疑故事主播,声音气质沉稳神秘。**

**[VOICE_TEXTURE] 音色质感:音色沙哑浑厚,音域偏低音,共鸣感强,气息感适中,嗓音低沉有磁性。**

**[VOICE_DETAIL] 细节特征:标准普通话,语速偏慢且节奏多变,咬字有力,尾音下沉,笑声低沉短促,呼吸节奏缓慢。**

**[VOICE_PERSONA] 人物背景:这位说话者常年播讲悬疑推理故事,因此说话时带有沧桑感和神秘感,关键情节处会刻意压低声音制造紧张氛围。**

**[OUTPUT_FORMAT] 输出要求:使用 ElevenLabs 生成,语言为中文,采样率44100Hz,输出格式MP3。**

## 二、情感与语气控制

<small style="color:#888">适用场景:情感广告、故事配音、角色情绪演绎、客服语音、有声书高潮段落等需要精确控制情感与语速语调的场景。</small>

<small style="color:#888">情感控制三维度:情感类型 + 强度 + 表现方式(语速/语调/停顿/重音)</small>

| 情感类型 | 语速 | 语调 | 停顿 | 重音 | 适用场景 |
|----------|------|------|------|------|---------|
| 喜悦 | 偏快 | 上扬 | 少 | 关键赞美词 | 节庆祝福、好消息 |
| 愤怒 | 快,有爆发 | 起伏大 | 短促有力 | 动词、否定词 | 争吵、控诉 |
| 悲哀 | 偏慢 | 下沉 | 多,长 | 情感词 | 哀悼、伤感独白 |
| 恐惧 | 不稳定,时快时慢 | 颤抖 | 突然停顿 | 恐怖词 | 悬疑、惊悚 |
| 平静 | 适中平稳 | 平直 | 适中 | 弱 | 旁白、说明 |
| 激动 | 快 | 高昂 | 少 | 全句 | 演讲高潮、呐喊 |
| 温柔 | 慢 | 柔和起伏 | 多 | 亲昵词 | 情话、哄睡 |
| 神秘 | 慢 | 压低 | 多,刻意 | 悬念词 | 悬疑、预告 |
| 讽刺 | 适中 | 反语调 | 刻意 | 反义词 | 评书、戏剧 |
| 坚定 | 适中,有力 | 下沉有力 | 干脆 | 决心词 | 誓言、宣言 |

<small style="color:#888">提示词(情感控制详细模板):</small>

**[EMOTION_TYPE] 情感类型:{喜/怒/哀/惧/平静/激动/温柔/神秘/讽刺/坚定},情感强度{1-10,如 7/10 偏强}。**

**[SPEECH_RATE] 语速控制:整体语速{偏快/适中/偏慢},数值约{语速值,如 1.2x},关键句{加速/减速}以强调,情感爆发处{语速变化描述}。**

**[PITCH_TONE] 语调控制:基础音高{高/中/低},句末语调{上扬/下沉/平直},情感转折处音高{变化描述},整体语调走向{描述}。**

**[PAUSE] 停顿控制:句间停顿{长/中/短},约{X秒},段落间停顿{X秒},强调前停顿{X秒}制造悬念,情感爆发前{停顿描述}。**

**[STRESS] 重音控制:重读{需要强调的词},轻读{需要弱化的词},重音方式{加强音量/拉长音节/提高音高}。**

**[SSML] SSML标签(如使用 Azure TTS):**

**`<prosody rate="{语速}" pitch="{音高}" volume="{音量}">{文本}</prosody>`**

**`<break time="{停顿时长}"/>`**

**`<emphasis level="{strong/moderate/reduced}">{强调词}</emphasis>`**

**`<mstts:express-as style="{情感风格}" styledegree="{强度}">{文本}</mstts:express-as>`**

**[TEXT] 文本内容:{需要合成的文本}**

<small style="color:#888">填充示例(悲伤回忆段落):</small>

**[EMOTION_TYPE] 情感类型:悲哀,情感强度 8/10 偏强。**

**[SPEECH_RATE] 语速控制:整体语速偏慢,数值约 0.85x,回忆细节处减速以渲染情绪,情绪低落处长音拖沓。**

**[PITCH_TONE] 语调控制:基础音高中低,句末语调下沉,整体语调走向由平稳逐渐下沉,关键句音高微颤。**

**[PAUSE] 停顿控制:句间停顿长,约 0.8秒,段落间停顿 1.5秒,"那天"前停顿 1秒制造回忆感,哽咽处长停顿。**

**[STRESS] 重音控制:重读"再也""最后""永远",轻读连接词,重音方式为拉长音节并略带气声。**

**[SSML] SSML标签:**

**`<prosody rate="0.85" pitch="-10st" volume="medium">那天之后,我再也</prosody>`**

**`<break time="1s"/>`**

**`<emphasis level="strong">没有</emphasis>`**

**`<prosody rate="0.8" pitch="-12st">见过他。</prosody>`**

**`<mstts:express-as style="sad" styledegree="1.5">回忆涌上来的那一刻,眼泪止不住地流。</mstts:express-as>`**

**[TEXT] 文本内容:那天之后,我再也没有见过他。回忆涌上来的那一刻,眼泪止不住地流。**

<small style="color:#888">提示词(SSML情感控制通用模板):</small>

**`<speak version="1.0" xmlns="http://www.w3.org/2001/10/synthesis" xmlns:mstts="http://www.w3.org/2001/mstts" xml:lang="{语言代码}">`**

**`  <voice name="{语音名称}">`**

**`    <mstts:express-as style="{情感风格}" styledegree="{强度0.5-2.0}">`**

**`      <prosody rate="{语速}" pitch="{音高偏移}" volume="{音量}">`**

## 三、多角色对话配音

<small style="color:#888">适用场景:广播剧、有声书对话段、动画/短剧配音、游戏剧情对话、访谈节目模拟等多角色交替说话的场景。</small>

<small style="color:#888">多角色配音三原则:角色音色差异化 + 对话节奏自然 + 旁白与对话清晰切换</small>

| 角色类型 | 音色建议 | 语速建议 | 情感基调 |
|----------|---------|---------|---------|
| 主角(青年) | 清亮有朝气 | 适中偏快 | 积极主动 |
| 配角(智者) | 浑厚低沉 | 偏慢 | 沉稳睿智 |
| 反派 | 沙哑阴冷 | 时快时慢 | 阴险压抑 |
| 旁白 | 中性温和 | 适中 | 客观叙事 |
| 少年角色 | 清脆活泼 | 快 | 天真好奇 |
| 女性主角 | 甜美或清冷 | 适中 | 因剧情而异 |

## 四、有声书与长文本朗读

<small style="color:#888">适用场景:有声小说、文学作品有声化、知识付费课程、儿童绘本朗读、长篇文档语音化等需要保持长文本一致性与叙事连贯的场景。</small>

<small style="color:#888">长文本朗读四要素:章节衔接流畅 + 角色音色一致 + 场景氛围营造 + 旁白风格统一</small>

| 旁白风格 | 音色建议 | 语速 | 适用类型 |
|----------|---------|------|---------|

## 七、使用技巧

| 技巧 | 说明 |
|------|------|
| 提供参考音频样本 | 克隆或描述音色时,附上 30 秒以上的干净参考音频,比纯文字描述更能锁定目标音色,显著提升还原度。 |
| 用 SSML 控制停顿与重音 | 在 Azure TTS、Edge TTS 等支持 SSML 的工具中,用 `<break>` 控制停顿、`<emphasis>` 控制重音、`<prosody>` 控制语速音高,实现精细化节奏。 |
| 分层描述音色 | 按"身份+质感+细节+背景"分层描述(参考第一章模板),比笼统说"男声"更易得到精准音色。 |
| 指定语速与音调数值 | 用具体数值(如语速 1.0x、音高 +5st)替代"快一点""高一些"等模糊描述,结果更可控、可复现。 |
| 分段合成长文本 | 长文本按 300-500 字分段合成,段间停顿 1-2 秒,避免一次性合成导致音色漂移、情感衰减或超时失败。 |
| 多版本试听对比 | 同一段文本用不同参数(情感强度、语速、音色)生成 2-3 个版本,试听对比后择优,避免一次定稿。 |
| 固定角色音色表 | 多角色或多段落作品中,建立统一的"角色音色表"并贯穿始终,防止角色串音、音色不一致。 |
| 善用情感风格标签 | Azure TTS 的 `express-as style`、ElevenLabs 的风格强度等情感标签,比纯文字描述情感更精准,优先使用。 |
| 先定调再合成 | 先用一小段文本确定整体音色、语速、情感基调,确认满意后再批量合成全文,减少返工。 |
| 注意标点与断句 | 文本中的逗号、句号、省略号直接影响停顿与语调,合成前手动优化断句,可显著改善自然度。 |

## 八、常见问题 FAQ

| 问题 | 解答 |
|------|------|
| 克隆的声音能商用吗? | 取决于声音来源授权与工具条款。必须获得声音本人的书面授权,并确认所用工具(如 ElevenLabs、Azure Custom Voice)允许商用。名人、已故名人的声音涉及肖像权与公共利益,商用风险高,建议咨询法律意见。 |
| 如何提升情感自然度? | 优先使用支持情感风格标签的工具(如 Azure TTS 的 `express-as`);用 SSML 精细控制语速、音高、停顿、重音;提供带情感变化的参考样本;避免过度夸张的情感强度(建议从 0.5-0.7 起调)。 |
| 长文本如何保持音色一致? | 按 300-500 字分段合成;固定同一音色 ID/模型版本与参数(语速、稳定性);段间停顿 1-2 秒;合成后逐段试听,发现漂移立即用原参数重新生成;克隆音色时提高稳定性参数。 |
| 多角色对话如何区分? | 为每个角色设定差异化的音色特征、语速、情感基调(参考第三章角色表);音色差异要明显(如沙哑 vs 清亮、低沉 vs 甜美);旁白用中性音色与角色区分;逐角色分段合成后拼接。 |
| 支持哪些语言? | 主流工具均支持中文(普通话)、英文;ElevenLabs Multilingual v2 支持 29 种语言;Azure TTS 支持 100+ 语言/方言;OpenAI TTS 支持数十种语言;克隆音色可跨语言迁移,但韵律可能受目标语言影响。 |
| 为什么合成的声音有机械感? | 常见原因:情感强度过低、语速过于均匀、断句不当、缺少停顿变化。解决:加入适当停顿与重音、用情感风格标签、优化文本断句、避免长句一次性合成、适当加入呼吸声与语气词。 |
| 如何让旁白与对话清晰切换? | 旁白用中性温和音色、适中语速、客观情感;对话用角色专属音色与情感;旁白与对话间加 0.5-1 秒停顿;可在切换处加入轻微音效过渡。 |
| SSML 在哪些工具可用? | Azure TTS、Edge TTS、Google Cloud TTS、Amazon Polly 完整支持 SSML;ElevenLabs、OpenAI TTS、剪映等不支持或仅部分支持,需通过文字描述与标点控制节奏。 |
