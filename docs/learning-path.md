## 第1步：建立基础认知

**目标**：理解提示词工程的核心概念，能用正确的策略写提示词。

**预计时间**：1-2天

### 1.1 必读：OpenAI 提示词最佳实践

- **文件**：[01-OpenAI提示词最佳实践](../01-入门与理论/01-OpenAI提示词最佳实践.md)
- **阅读时间**：10分钟
- **为什么先读这个**：OpenAI 官方总结的6大策略是最简洁、最权威的入门框架
- **读完后你应该能**：
  - 知道"写出清晰指令"的6个技巧
  - 理解"给模型思考时间"的含义
  - 能写出基本合格的提示词

### 1.2 核心：提示词工程核心技术手册

- **文件**：[02-提示词工程核心技术手册](../01-入门与理论/02-提示词工程核心技术手册.md)
- **阅读时间**：45分钟（全读）/ 20分钟（前5章）
- **推荐读法**：
  1. **首次阅读**：只读前5章（零样本→少样本→CoT→ToT→自一致性），建立"推理增强"概念
  2. **按需查阅**：后续章节在遇到实际问题时回来查
- **重点章节**：
  | 优先级 | 章节 | 为什么重要 |
  |--------|------|-----------|
  | ⭐⭐⭐ | 三、链式思维（CoT） | 所有推理场景的基础 |
  | ⭐⭐⭐ | 十二、系统提示 | 理解AI工具"背后在做什么" |
  | ⭐⭐ | 二、少样本提示 | 最常用的输出控制手段 |
  | ⭐⭐ | 十一、结构化输出 | 保证AI输出可解析 |
  | ⭐ | 六、ReAct | Agent开发的理论基础 |
- **读完后你应该能**：
  - 理解17种技术各自的适用场景
  - 知道何时用CoT、何时用ToT
  - 能使用"四字段"标准结构写提示词

### 1.3 自检

- [ ] 能说出6大OpenAI策略中至少4个
- [ ] 能区分零样本、少样本、CoT的使用场景
- [ ] 能写出一个包含 Role / Task / Constraints / Output Format 的提示词

## 第2步：掌握编程场景

**目标**：能用提示词高效辅助编程开发，理解生产级系统提示词的设计。

**预计时间**：2-3天

### 2.1 实战：编程开发提示词案例

- **文件**：[01-编程开发提示词案例](../02-编程开发/01-编程开发提示词案例.md)
- **阅读时间**：40分钟
- **推荐读法**：不需要从头读到尾，按当前工作需要查阅对应章节
- **重点章节**：
  | 你的场景 | 看哪个章节 |
  |---------|-----------|
  | 需求拆解 | 一、项目规划与需求拆解 |
  | 调试代码 | 三、代码调试与Bug修复 |
  | 重构代码 | 四、代码重构与性能优化 |
  | 写测试 | 五、测试与质量保证 |
  | 开发AI应用 | 七、AI与大模型应用开发 |
  | 开发Agent | 十四、AI Agent开发 |

> 💡 **提示**：本文档中的 `/plan` 和 `/spec` 前缀是 Windsurf/Trae 的命令格式，使用其他工具请去掉前缀。

### 2.2 深度：AI编程助手系统提示词案例

- **文件**：[02-AI编程助手系统提示词案例](../02-编程开发/02-AI编程助手系统提示词案例.md)
- **阅读时间**：30分钟
- **为什么重要**：这是本项目的"深度"所在——逆向分析 Cursor/Windsurf/Claude Code/Devin 的系统提示词
- **推荐读法**：
  1. 先读第二节"设计模式总结"（7层架构）
  2. 选读1-2个工具的具体分析
  3. 直接使用第七节的通用模板
- **读完后你应该能**：
  - 理解系统提示词的7层架构
  - 能设计自己的AI编程助手系统提示词
  - 知道 Cursor 的"最小改动"和 Windsurf 的"Flow状态"核心差异

### 2.3 自检

- [ ] 能根据编程场景选择合适的提示词模板
- [ ] 能说出系统提示词7层架构中的至少5层
- [ ] 能修改通用模板来适配自己的编程助手需求

## 第3步：探索AI创作

**目标**：掌握AI图像和视频生成的提示词技巧。

**预计时间**：1-2天

### 3.1 图像生成

- **文件**：[01-AI图像生成提示词模板](../03-AI创作/01-AI图像生成提示词模板.md)
- **阅读时间**：20分钟
- **核心掌握**：
  - **万能公式**：`[主体] + [细节] + [环境] + [构图] + [风格]`
  - **风格控制**：10种艺术风格 + 6种渲染引擎 + 9种色彩调性
  - **镜头语言**：7种景别 + 5种视角 + 7种光线
  - **负面提示词**：排除不想要的元素

### 3.2 视频生成

- **文件**：[02-AI视频生成提示词模板](../03-AI创作/02-AI视频生成提示词模板.md)
- **阅读时间**：15分钟
- **核心掌握**：
  - **结构框架**：场景+主体+动作+环境+风格+运镜
  - **7个可复用模板**：通用/简洁/角色特写/产品/自然/Logo/转场
  - **14种运镜术语**：推拉摇移跟升降等

### 3.3 角色设定图

- **文件**：[03-人物图片转三视图提示词](../03-AI创作/03-人物图片转三视图提示词.md)
- **阅读时间**：10分钟
- **适用场景**：游戏/动画角色设定、IP形象设计
- **核心掌握**：8个专用模板 + 11种风格速查表

### 3.4 自检

- [ ] 能用万能公式写出一个图像生成提示词
- [ ] 能区分不同运镜术语（推/拉/摇/移）
- [ ] 能根据角色类型选择合适的三视图模板
