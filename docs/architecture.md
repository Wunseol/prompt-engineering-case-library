# 项目架构与源码导读

> 本文档为「提示词工程案例库」的架构说明和源码深度导读，让新成员能彻底读懂项目每个文件的定位、内容结构和交叉引用关系。

---

## 一、项目定位

**提示词工程案例库**是一个纯 Markdown 知识库项目，"源码"即 Markdown 文档本身。项目的核心价值在于：

1. **知识整合**：将分散在论文、官方文档、开源项目中的提示词知识系统化
2. **即用模板**：每个技术/场景都提供可直接复制使用的模板
3. **效果验证**：每项技术都有量化效果数据（来自论文和基准测试）
4. **生态关联**：与 50+ 开源项目建立引用关系
